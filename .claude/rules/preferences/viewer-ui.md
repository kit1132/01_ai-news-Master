**見た目の修正はこのファイルだけで完結する。** 既存ハッシュ ID（`#daily` `#weekly` `#master` `#copilot` `#industry`）は変えない。カテゴリは `#category`（目次）と `#category/<slug>`。

記録日: 2026-09-21

## ソース切替（親子ツリー）

```
AI NEWS
 ├ ホーム
 ├ 今日のまとめ
 │   ┗分野（小見出し・押せない）
 │     ┗開発ツール
 │     ┗業務 Copilot
 │     ┗市場・規制
 ├ 今週のまとめ
 │   ┗分野
 │     ┗開発ツール
 │     ┗業務 Copilot
 │     ┗市場・規制
 └ カテゴリ別まとめ
     ┗Claude / Anthropic
     ┗ChatGPT / OpenAI
     ┗Gemini / Google
     ┗GitHub Copilot
     ┗…（Cursor / xAI は1件。12件）
     ┗市場・企業
```

- ハッシュなしと `#home` はホーム。記事ページとは別のページ体裁（家のアイコン、大きな題、子ページ列）。先頭のサイトの構成は1つの図。左の3ページのうち今日から今週へ矢印が向き、その下に ▸ で開く3分野。右はカテゴリ別まとめから12の話題。図の下に、ページの開き方を文章で書く。その下が今日／今週／カテゴリ。いちばん下の「このサイトについて」で詳細ページへ移る。左の今日・今週の ▸ の小見出しは「分野」。集めている情報の表はホームに置かず、about.html の「集めている情報」にある。本文の入口は今日のまとめ。ホーム以外ではパンくず先頭の「ホーム」が戻り。PC は全階層。モバイルは途中を隠し、ホームと日付の直前（今日のまとめ、または話題名）と日付を残す。左の AI NEWS と「ホーム」も同じ戻り先。今日のまとめのカテゴリ見出しは、画面上だけカテゴリの表示名に合わせる
- **展開と選択は分離**する。親行の ▸（`.side-twist`）は枝の開閉だけ（本文は変えない）。親ラベルはまとめ本文へナビし、その枝を開く
- 複数の親枝を同時に開けてよい。葉を選んでも他枝を強制クローズしない（一覧が一気に消えて驚かせない）
- 今日・今週の子は同じ入れ子: 親 → 小見出し「分野」→ 3葉（二重レール＋┗）
- 親「カテゴリ別まとめ」は12件の目次（`#category`）。並びはモデル3社、Microsoft の4つ、Cursor / xAI、そのあと。Claude の本文は開かない。表示名は ChatGPT / OpenAI と Gemini / Google。ハッシュ `openai` と `google` は変えない。Cursor と xAI は1件（`#category/cursor`。`#category/xai` もそこへ開く）
- 子を押すとその話題。左は月／第N週／日付。右は月トグル（新しい月だけ開く）。中は週トグル。週を開くとその週の日付と更新が出る。開いた週・日は、別の週を開いても閉じない
- 左の日付はその月を開き、その日へジャンプする（1日だけ差し替えない）
- 記事ごとに畳まない。日付を開いたらその日の更新は閉じない。他の日を開いても、開いた日は閉じない
- 沈黙／「N日更新なし」系の報告タイトルは時系列に載せない。空状態は「この話題の更新はまだありません」
- 左の日付行にタイトルは付けない。日付の山を本文に無構造で積まない（日ごとに見出しで区切る）
- 日付／週を選んだときは、右ペイン先頭の共通クローム（文脈＋日時見出し＋一文概要）で「いま見ているもの」を出す（今日／今週／カテゴリ共通）
- 一文概要（`.page-overview`）: 今日＝当日差分、今週＝1週間の流れ、カテゴリ＝時系列で辿る、の短い日本語。沈黙日数は書かない
- 親・子の名前は **14px**（葉は 13px）。親4行の左に 22px のアイコン（ホームは家で下地だけ薄い青、今日・今週・カテゴリはホーム入口と同じ線画で灰色）。日付・話題・分野の葉には付けない。選択中は `is-active` / `aria-current`。左端に 2px の青（`--accent`）。背景はグレーのまま。日付行には青線を付けない。ホームのページアイコンも同じ家で、下地だけ同じ青を 14% 混ぜる（線は白）
- 小見出し「分野」は **12px・本文色・太字**。キャプション（11px muted）にしない。先頭に ┗
- 子は一段インデントし、左レール（2px）。葉の先頭にも ┗
- 表示名は 開発ツール / 業務 Copilot / 市場・規制（会社名は使わない）

### 日付一覧の土日色

`--dow-sat`（青）/ `--dow-sun`（赤）を、今日・今週・カテゴリの左日付リストで共通に使う。

- 日付行: `M/D` と曜の両方に着色（active でもトークンを保つ）
- 週行（今週のまとめ）: 範囲の月〜日のうち、土日にあたる端を同じクラスで着色（通常は末日＝日曜が赤）

使わない:

- トップレベルの「まとめ」「分野」2群ラベル
- 第6のソース ID（カテゴリは `#category/<slug>` で足す。5 ID は残す）
- 今日の `## カテゴリ別まとめ` への節ジャンプ（案C′）
- 余り箱 / その他 の第14ページ

## 日付一覧の週

月アコーディオン（例: 2026年9月）の中を、**その月の第N週**で区切る。

```
2026年9月
  4週
    9/21 月  今日
  3週
    9/20 日 … 9/14 月
  2週
  1週
```

### 番号の規則

- 週は月曜始まり（既存の `utcMonday`）
- **その月の1日を含む週が 1週**。以降、月曜ごとに +1
- 月末の端数も同じ番号（月によっては 5週・6週）

使わない:

- 「今週」「先週」「来週」を週見出しにする（日付行の「今日」バッジは残す）
- ISO 週番号（`W38`）を一覧に出す（ハッシュと `id` は `2026-W38` のまま）
- 週見出しを日付範囲だけにする（`9/7–9/13`）

### 日付ソース（今日のまとめ / 開発ツール / 業務 Copilot / 市場・規制 / カテゴリページ）

- `.week-sep` が「N週」
- その下に日付行（`M/D` + 曜）。土日色・今日バッジは従来どおり
- 1日をまたぐ ISO 週は、**日付の属する月**に分かれる（8/31 は8月、9/1 は9月の1週）

### 週次ソース（今週のまとめ）

1ファイルが1 ISO 週なので、行そのものが週。今日の日付行と同じ1行にする（週番号が上、範囲が下、にはしない）。

- 左列: **N週**（月内番号、日付の `M/D` と同じ 14px / 600）
- 右列: **M/D–M/D**（同じ行。土日の端は青・赤）
- パンくずもこの表記。`2026-W38` はハッシュと `id` だけ
- **1日を含む週は、月曜が前月でもその月の1週に入れる**（`weekBucketOf`）
  - 例: 8/31–9/6 は 9月の1週（9/1 を含む）
  - 例: 7/27–8/2 は 8月の1週（8/1 を含む）
- ファイルが無い週は出さない（5月1週など）

## 字の大きさ（サイドバー日付）

親が子より小さく見えないこと。

| 役割 | サイズ |
|---|---|
| 月トグル（2026年9月） | **16px / 700** |
| 週の区切り（1週 / 2週…） | **11px / 700**・字間広め |
| 日付（9/21 月） | **14px / 600** |
| 今週のまとめの週行 | 日付と同じ **14px / 600** の1行 |

右のカテゴリは一段大きい。月 **20px**、週 **18px**（範囲は 14px）、日付 **16px**。土は青、日は赤（`.content h2` より強い指定）。

週はトグル。開くとその週の更新が日付ごとに出る。

## 本文の見出し・カテゴリトグル

節 24 / カテゴリ 15 / 項目 14 / 本文 14。トグルが親で中身は一段落とす。

- `h2.sec-t` **24px / 700**
- `h3.sub-t` **15px / 600**（カテゴリ名のトグル）
- `.cat-k` **14px / 600**（項目見出し）。色箱（`.lbl`）にしない
- `.cat-v` 本文 **14px**。左レール＋一段インデント
- ハイライトは要約／詳細のコールアウト。カテゴリ項目まで枠を並べない
- 注目予定は日付列 `M/D` ＋週トグル（`weekTitle` は今週／来週／範囲のまま。「9月の1週」にしない）

## 掲載の読み先

作業ブランチが `main` より古いと、当日分は `../.content-main/<repo>/`（`origin/main` のミラー）から読む。`files.json` の先頭が作業ツリー以上なら、今までどおり `../<repo>/` を読む。ミラーが無いときは作業ツリーだけ。

## 触らないもの
