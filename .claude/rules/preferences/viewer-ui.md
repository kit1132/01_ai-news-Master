# ビューア UI（index.html）

実体は本リポジトリの `index.html` 1ファイル。02〜05 はここへのリダイレクト。
**見た目の修正はこのファイルだけで完結する。** 5ソース（今日のまとめ / 今週のまとめ / 開発ツール / Microsoft / 業界）は同じ描画経路を使う。

記録日: 2026-09-21

## ソース切替（まとめ / 元ソース）

- グループ見出しは **12px・本文色・太字**。キャプション（11px muted）にしない
- 「まとめ」と「元ソース」は `.side-block` で分け、間に区切り線
- ソース名は見出しの下にインデントし、左レール（2px `var(--border)`）
- ソース名は **14px**。選択中は `is-active`

使わない: グループ見出しをソース名と同じ大きさ・同じ色で並べる

## 日付一覧の週

月アコーディオン（例: 2026年9月）の中を、**その月の第N週**で区切る。

```
2026年9月
  4週
    9/21 月  今日
  3週
    9/20 日 … 9/14 月
  2週
  1週
```

### 番号の規則

- 週は月曜始まり（既存の `utcMonday`）
- **その月の1日を含む週が 1週**。以降、月曜ごとに +1
- 月末の端数も同じ番号（月によっては 5週・6週）

使わない:

- 「今週」「先週」「来週」を週見出しにする（日付行の「今日」バッジは残す）
- ISO 週番号（`W38`）を一覧に出す（ハッシュと `id` は `2026-W38` のまま）
- 週見出しを日付範囲だけにする（`9/7–9/13`）

### 日付ソース（今日のまとめ / 開発ツール / Microsoft / 業界）

- `.week-sep` が「N週」
- その下に日付行（`M/D` + 曜）。土日色・今日バッジは従来どおり
- 1日をまたぐ ISO 週は、**日付の属する月**に分かれる（8/31 は8月、9/1 は9月の1週）

### 週次ソース（今週のまとめ）

1ファイルが1 ISO 週なので、行そのものが週。

- 見出し: **N週**（月内番号）
- 副行: **M/D–M/D**（その週の月〜日）
- **1日を含む週は、月曜が前月でもその月の1週に入れる**（`weekBucketOf`）
  - 例: 8/31–9/6 は 9月の1週（9/1 を含む）
  - 例: 7/27–8/2 は 8月の1週（8/1 を含む）
- ファイルが無い週は出さない（5月1週など）

## 字の大きさ（サイドバー日付）

親が子より小さく見えないこと。

| 役割 | サイズ |
|---|---|
| 月トグル（2026年9月） | **14px** |
| 週（1週 / 2週…） | **12px** |
| 日付（9/21 月） | **13px** |

週番号は見出し、日付が本体。

## 触らないもの

- 本文の注目予定の週トグル（`weekTitle`）。ここは月の外なので「9月の1週」にしない。今週 / 来週 / 範囲のまま
- ダイジェスト Markdown
- `files.json` の形式

## 変更したときの確認

ローカルで親ディレクトリから静的サーバを立て、5ソースすべてで:

- 月が 14px、週が 12px
- 9月に 1週がある（日付または週次ファイルがある場合）
- 「今週」「W38」が週見出しに出ていない
