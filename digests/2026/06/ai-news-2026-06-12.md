### Microsoft が社内従業員の Fable 5 利用を制限 — 30 日 retention で legal review、外部には GA 継続
- **6/10-11 発覚**: Anthropic が Fable 5 / Mythos 5 の安全分類器運用のため **prompts/outputs を default で 30 日間保持**（policy 違反 flag 時は最大 2 年）。Microsoft 法務がこれを社内利用承認できず、**内部版 GitHub Copilot の model picker から Fable 5 を外す措置**
- **捻れ構造**: Microsoft は GitHub Copilot / Foundry 顧客向けには Fable 5 を 6/9 同日 GA 提供。**自社製品では即提供、自社従業員には禁止**という二重基準が CISO 議論の象徴的事例化
- **他 Claude モデルは継続利用可**: Opus 4.x / Sonnet 4.x は Anthropic の **Zero Data Retention (ZDR)** 規約下で運用されており Microsoft 社内でも利用許可継続。Fable 5 は ZDR 例外
- **意味合い**: 昨日のダイジェストで指摘した「**GitHub Copilot Enterprise/Business 管理者が Fable 5 policy を default off で明示的 enable 必要**」の延長線。Microsoft 法務すら通過できていない条件を CISO に通すのは構造的に困難

### 本日 6/12 が OpenAI macOS app cert revoke 期限 — 旧 ChatGPT Desktop / Codex App / Codex CLI / Atlas が動作停止
- **背景**: 5/11 UTC の **TanStack supply chain attack（Mini Shai-Hulud キャンペーン）** で OpenAI 社員 2 端末が侵害。**Windows / macOS / iOS / Android 用署名鍵全てが影響**、全アプリ再署名・新証明書で再リリース
- **6/12 期限**: 旧証明書での新規 download / launch が **macOS 標準保護機能でブロック**される。**ChatGPT Desktop、Codex App、Codex CLI、Atlas の旧バージョンが本日以降動作停止**または更新受信停止
- **対策**: 全 macOS ユーザは本日までに新証明書版へアップデート必須
- **被害範囲**: 顧客データ / 本番システム / IP / 公開ソフトウェアへの侵害は無し、限定的な credential material のみ流出と OpenAI 確認
- **意味合い**: AI dev ツールの **supply chain security が OS 級メンテナンスサイクルに組み込まれる**最初の大規模事例。同期間に Snowflake / GitHub / Microsoft も独自再署名キャンペーン進行中
- ソース: https://openai.com/index/our-response-to-the-tanstack-npm-supply-chain-attack/ / https://thehackernews.com/2026/04/openai-revokes-macos-app-certificate.html / https://www.securityweek.com/openai-hit-by-tanstack-supply-chain-attack/

### Apple Foundation Models 詳細補完 — AFM 3 Cloud Pro が Nvidia GPU on Google Cloud、AFM 3 Core Advanced は 20B sparse
- **AFM 3 ファミリー全 5 モデル**: on-device 2 種（**AFM 3 Core / AFM 3 Core Advanced**）+ Private Cloud Compute 3 種
- **AFM 3 Core Advanced**: **20B parameter on-device natively multimodal、sparse architecture で request 毎に 1-4B のみ activate**。iPhone 17 Pro 以降 / M 系 Mac で動作
- **AFM 3 Cloud Pro**: **Nvidia GPU 最適化、Google Cloud 上の Nvidia インフラで動作**（Apple × Google × Nvidia 3 社共同プロジェクト）。Private Cloud Compute を Nvidia GPU へ拡張、Gemini Frontier 級品質
- **Gemini との関係**: 訓練に **Google 貸与の Gemini からの distillation 使用**、ただし**推論時には Gemini 製モデルも Google client コードも Google Search infrastructure も使わない**（Craig Federighi 明言）
- **Siri 連携**: AFM 3 Cloud Pro が新 Siri の agentic tool use / 複雑推論バックボーン。年 $1B ライセンスの実体が「distillation 教師」「インフラ拡張」「Nvidia GPU 同居」の 3 層構造と判明
- **昨日からの差分**: 6/8 keynote 時点では「Siri = Gemini 1.2T カスタム」と単純化されていたが、**Apple ML Research 公式ブログ（6/10-11 詳細補完）**で 5 モデル構造と Gemini 距離が明確化

### Cursor Bugbot が 3x faster / 22% cheaper / 10% more bugs + `/review` コマンド導入
- **性能**: review 平均 ~5 分 → **~90 秒**、**90% の run が 3 分以内**、bug 検出率 **0.56 → 0.62 件/review（10% 向上）**、run コスト **22% 低下**
- **裏付け技術**: Bugbot 内部エンジンを **Composer 2.5（Moonshot Kimi K2.5 ベース）に置換**、harness 改良
- **`/review` 新コマンド**: push 前に Bugbot + Security Review を `/review` で同時起動可。`/review-bugbot` / `/review-security` 個別呼出も対応
- **増分 review 設定**: 「前回 review 以降の差分のみ」レビュー option 追加 — long-running PR の review noise 削減
- **対応版**: Cursor 3.7+ / cursor.com/agents、CLI 対応は近日中
- ソース: https://cursor.com/blog/bugbot-updates-june-2026 / https://www.startuphub.ai/ai-news/technology/2026/bugbot-gets-major-speed-and-cost-upgrades
