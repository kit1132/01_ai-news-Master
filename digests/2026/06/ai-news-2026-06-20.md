### Claude Code v2.1.183（6/19 stable）— auto mode が破壊的 git コマンドをブロック
- **auto mode の安全性強化**: ユーザーが明示要求していない限り、作業を破棄しうる破壊的コマンドを**ブロック**するようになった。対象は `git reset --hard` / `git checkout -- .` / `git clean -fd` / `git stash drop` / `git commit --amend`（当該セッションでエージェントが作成したコミット以外）/ `terraform destroy`・`pulumi destroy`・`cdk destroy`。
- **モデル非推奨警告を追加**: 要求モデルが deprecated / auto-update された場合、print モード（`-p`）と agent frontmatter 指定モデルで stderr に警告表示。
- **`attribution.sessionUrl` 設定追加**: Web / Remote Control セッションのコミット・PR から claude.ai セッションリンクを省略可能。`/config --help` で shorthand キー一覧も追加。
- 修正: subagent spawn 時の `thinking.disabled.display` 400 エラー、subagent 内 WebSearch 空応答、vim モードのカーソル、Windows Terminal のフルスクリーン TUI 破損、thinking ブロックのみでターンが無音完了する問題、認証付き MCP サーバーが auth-stub ツールをモデルへ露出する問題。
