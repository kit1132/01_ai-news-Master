### Claude Code v2.1.174 / v2.1.175（6/12）— managed model 制約強化 + model picker 改善 + VS Code usage attribution
- **v2.1.175（6/12 stable）**: **`enforceAvailableModels` managed 設定追加** — 有効時は `availableModels` allowlist が Default model を制約し、許可外に解決される Default は**先頭の許可モデルへ自動フォールバック**。**user / project 設定からは managed な `availableModels` リストを拡張（widen）できない**。enterprise の model ガバナンスを設定レイヤーで強制する仕組み
- **v2.1.174（6/12 stable）の新機能**:
  - **VS Code `/usage`（Account & usage ダイアログ）に usage attribution 追加** — cache miss / long context 使用 / subagent / **skill・agent・plugin・MCP 別の内訳**を直近 24h / 7d で表示
  - `wheelScrollAccelerationEnabled` 設定でフルスクリーン時のマウスホイール加速を無効化可
- **v2.1.174 の主なバグ修正**: `/model` picker が **Default の解決先 model family を隠す問題を修正**（Max/Team Premium/Enterprise で Opus が独立行、Pro/Team で Sonnet、pay-as-you-go API で Opus が表示）、`ANTHROPIC_DEFAULT_SONNET_MODEL` 指定時に picker が hardcode の Sonnet 版表示する問題、**enterprise の usage-based billing で「Fable 5 is now consuming usage credits」バナー誤表示**、Bedrock GovCloud（`us-gov-*`）の inference profile prefix 誤りによる 400 エラー、background session が daemon 起動 shell の provider 環境変数を継承する問題、git commit co-author に誤 model 名表示、Workflow tool `agent()` subagent の per-agent attribution ヘッダ欠落 等
- **位置付け**: 6/9 v2.1.170（Fable 5 picker 統合）→ 6/10 v2.1.172（5 段 sub-agent）→ 6/11 v2.1.173（`[1m]` 正規化）→ 6/12 v2.1.174/175 と **Fable 5 GA から 5 日連続で stable release**。本日 6/12 分は enterprise の model ガバナンス（`enforceAvailableModels`）と課金 UX（誤バナー修正）に重心

### Claude Corps — Anthropic が $150M で 1,000 fellows を米国 NPO に配置（6/11 発表）
- **概要**: Anthropic が **$150M** を投じ、**1,000 名の Claude Corps Fellows** を米国 NPO に **12 ヶ月フルタイム**配置する national fellowship。各 fellow に**年俸 $85,000 + 福利厚生 + 潤沢な Claude token budget**、host 組織（400+）には各 **$10,000 grant + 無償 Claude credits**
- **運営体制 3 社**: Anthropic が資金・設計、**CodePath** が募集・訓練・雇用、**Social Finance** が成果測定・grant 管理
- **応募要件**: 18 歳以上 / 米国就労資格 / フルタイム職歴 2 年以内、**学位不要**。**応募締切 7/17**、第 1 期 100 名は **10 月開始**、以降 2027 年 1 月・8 月コホート
- **意味合い**: Fable 5 GA・IPO 観測（post-money 推定 $965B）と並行する**社会実装・人材パイプライン投資**。「degree 不要 / generative AI 実務配置」という採用設計は AI スキル人材市場への直接介入
- ソース: https://www.anthropic.com/news/claude-corps / https://www.theregister.com/ai-and-ml/2026/06/11/anthropic-hires-1000-fellows-to-push-claude-into-nonprofits/ / https://www.washingtonpost.com/business/2026/06/11/anthropic-ai-claude-corps-daniela-amodei/
