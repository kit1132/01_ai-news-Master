### Claude Code v2.1.163 / v2.1.165（6/4-6/5 stable）
- **v2.1.165（6/5）**: バグ修正・信頼性向上のみ
- **v2.1.163（6/4）主要変更**
  - **Managed Settings**: `requiredMinimumVersion` / `requiredMaximumVersion` 追加。バージョン範囲外なら起動拒否＋承認バージョン誘導（組織ガバナンス強化）
  - **`/plugin list`** 追加。`--enabled` / `--disabled` フィルタ対応
  - `/btw` に **「c で markdown 生コピー」** ショートカット（書式維持ペースト用）
  - **Stop / SubagentStop hooks** が `hookSpecificOutput.additionalContext` を返せるように。フィードバックを与えてもエラー扱いされず turn 継続可能
  - Skills の command 内で **`\$` エスケープ**（リテラル `$` + 数字を扱える）
  - stdio MCP に `--resume` 時 `CLAUDE_CODE_SESSION_ID` 提供（hooks/Bash と同一値）
- **v2.1.163 バグ修正抜粋**
  - `claude -p` がバックグラウンドコマンド残存で永久ハング → 結果後 ~5 秒で background shell 停止
  - Bedrock/Vertex/Foundry の `CI=true` で誤って ANTHROPIC_API_KEY 要求した問題
  - `$TMPDIR` 上書きが全コマンドに波及していた問題（v2.1.154 リグレッション、bazel / EDR 保護 Go ワークフロー破綻）
  - Windows / OneDrive 配下の session-env ディレクトリ EEXIST
  - 起動中の managed settings fetch 完了タイミングで権限ルールが session 全体に適用されない問題
  - `claude agents` の background session がアップデート跨ぎで running task を失う問題
  - Esc で agent view 抜けたときの terminal 整列崩れ + 数秒ハング
  - hook `if: "Bash(...)"` が `$()` / `$VAR` 含む全コマンドで誤発火 → subshell / backtick 内も適切にマッチ
  - 自宅ディレクトリ deny rule（`Read(~/Desktop/**)` 等）が `$HOME` 参照 Bash で素通りした問題
- ソース: https://code.claude.com/docs/en/changelog

## 業界動向

- **Anthropic「pause button」提案 vs Microsoft / OpenAI の Build 直後攻勢** — IPO 提出済みの Anthropic が「商用最強 + Mythos + Services Track + 安全規制のリーダー」を同時主張。MSFT/OpenAI は「multi-agent + MAI 自前モデル + Copilot 大口契約」で商用速度を加速。「政策 × 商用」の主導権争いが今週の主軸
- **Copilot の OpenAI 依存度低下が「複数モデル picker」化で実装段階に** — GPT-4.1 廃止 + GPT-5.5 推奨 + Gemini 3.x 拡大 + MAI-Code-1-Flash 配備。Copilot は「特定モデルへの忠誠より下流価値」モデルに転換
- **Claude Enterprise の admin 権限粒度化 + Anthropic の pause 主張** が「規制対応コスト」を吸収可能な大企業契約に追い風。Compliance API（5/12）と合わせ「ガバナンス完全装備」訴求が完了
- **Cursor「Agents Window に Automations」+ Devin「Personal Automations」+ Copilot App「Canvases」** が同時期にローンチ — 「個人の自動化 × チームのマルチエージェント × 横断ダッシュボード」3 軸競争が継続激化
- **OpenAI Codex CLI が alpha リリースを別ライン提供** — stable v0.137 と並走で α が 0.138 系へ。Codex CLI が Claude Code に対抗する更新スピードを維持
