## 最優先

### Claude Fable 5 / Mythos 5 公開発表（6/9）— 初の公開 Mythos クラス・SWE-Bench Pro 80.3%
- **Fable 5 = Mythos クラスを安全分類器付きで一般公開した同一モデル**。Mythos 5 は同モデルから cyber / bio セーフガードを一部解除した版で、Project Glasswing パートナー＋検証済み生物学研究者のみに限定
- **ベンチマーク**: SWE-Bench Pro 80.3%（Opus 4.8 69.2% / GPT-5.5 58.6%）、Hex 分析ベンチで初の 90% 超え、ほぼ全ての公開ベンチで SOTA
- **コンテキスト**: 1M tokens 入力 / 128k tokens 出力 がデフォルト。Adaptive thinking が唯一の思考モードで `effort` パラメータで深さを制御
- **料金**: 入力 $10 / 出力 $50 per 1M tokens（Opus 4.8 の 2 倍、prompt caching の 90% 入力ディスカウントは継続適用）
- **配信プラットフォーム同時 GA**: Claude API / Claude Platform on AWS / Amazon Bedrock / Vertex AI / Microsoft Foundry / GitHub Copilot / Harvey
- **試食期間**: 6/9〜**6/22 まで Pro/Max/Team/seat-based Enterprise に追加料金なしで含む**。**6/23 以降は usage credits 必要**
- **安全分類器**: cybersecurity / 生物・化学 / モデル distillation 関連クエリは Opus 4.8 に自動ルーティング（全セッションの **<5%** で発動）
- **位置付け**: 公開直前に Anthropic Institute が「recursive self-improvement / pause button」を警告した直後の解禁。**「frontier モデルの危険性議論」と「商用 GA」を同週で同時実行する Anthropic の二段戦略**が鮮明化
