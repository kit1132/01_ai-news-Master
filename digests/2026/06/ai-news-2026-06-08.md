# AI News Digest 2026-06-08（日）

前日（6/7）からの 1 日差分。本日の山場は **Apple WWDC 2026 開幕**（米時間 6/8 10:00 PT / 日本時間 6/9 2:00）— Siri を Google Gemini 1.2T params カスタムモデルで再構築、Apple Intelligence Extensions で ChatGPT / Claude / Gemini を選択可能化という、Apple の「マルチプロバイダ AI マーケットプレイス」公式化が予定されている。同時に **Cursor Bugbot 従量課金化** と **Gemini 3.5 Flash トグル廃止** が同日施行。

## 最優先

### Apple WWDC 2026 開幕（6/8 米時間 10:00 PT）— Apple Intelligence Extensions で Claude/Gemini/ChatGPT 並走
- Tim Cook 最後の WWDC keynote。9 月以降 John Ternus が CEO 昇格予定
- **Siri 全面再構築** — Google Gemini ベースの 1.2T params カスタムモデルがクラウドバックボーン。Apple は年 $1B でライセンスと報道
- **Extensions システム新規導入** — iOS 27 / iPadOS 27 / macOS 27 で third-party AI chatbot を Siri に統合できる標準フレームワーク。設定画面でユーザが provider を選択（research = Gemini, coding = Claude, creative = ChatGPT 等の用途別ルーティング想定）
- Writing Tools / Image Playground など Apple Intelligence 機能の default provider も third-party に切替可能化
- **Siri スタンドアロンアプリ** — ChatGPT / Claude を競合に置く独立アプリ。Dynamic Island 統合、multi-step commands 対応
- **App Store AI Agent 階層新設** — アプリが現実世界タスクを agent として代行する新カテゴリ
- 注目点: Anthropic にとって「iOS 公式 backend」獲得は Mythos 拡張 + IPO 直前期の最重要ディール候補
- ソース: https://www.apple.com/newsroom/2026/05/apple-kicks-off-worldwide-developers-conference-on-june-8/ / https://www.macrumors.com/guide/wwdc-2026-what-to-expect/ / https://9to5mac.com/2026/05/05/ios-27-will-let-you-choose-between-gemini-claude-and-more-for-ai-features-report/

### Cursor Bugbot 従量課金化（本日 6/8 以降 renewal で適用）
- $40/月 seat fee 廃止、純粋 usage-based 課金へ。Teams は on-demand spend から、Individuals は included usage から消費
- 1 PR レビュー平均 $1.00–$1.50（500 行 = $1.20、5,000 行 = $4 程度）
- **Effort Level** 設定追加 — 深いレビュー指定や PR サイズに応じた動的決定ロジック構成可能
- 既存顧客は Dashboard で先行切替も可
- ソース: https://cursor.com/blog/may-2026-bugbot-changes

### Gemini Enterprise app: Gemini 3.5 Flash トグル廃止（本日 6/8 施行）
- 管理者向け feature management toggle を撤去。**既定有効・無効化不可** に変更。Global / US / EU 全 multi-region 同時
- 同時に **Gemini API の Interactions API legacy schema が 6/8 削除**
- ソース: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes / https://ai.google.dev/gemini-api/docs/changelog

- **Apple Intelligence Extensions = LLM ベンダの「OS-level distribution」獲得競争の幕開け** — Anthropic / OpenAI / Google が iOS ユーザの default を取り合う構造に。Claude が Anthropic IPO 直前期に勝ち取れるかが今後 1–2 週の論点
