### Google: Gemini CLI / Code Assist IDE 拡張が本日 6/18 で消費者向け終了
- **6/18 から Gemini CLI / Gemini Code Assist IDE 拡張が AI Pro / Ultra / 無償個人向けでリクエスト処理を停止**。**Gemini Code Assist for GitHub も新規インストール不可化＋数週内にリクエスト停止**。後継は closed-source・Go 製の **Antigravity CLI（バイナリ `agy`）**。
