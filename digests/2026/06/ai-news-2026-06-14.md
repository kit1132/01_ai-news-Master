## 最優先

### Claude Code v2.1.176（6/12）— `availableModels` 強制の抜け穴修正 + Fable 5 auto mode 修正
- **位置付け**: 昨日把握した v2.1.174 / v2.1.175 に続く同日（6/12）追加リリース。前日ダイジェスト時点では未取得だった分。Fable 5 GA（6/9）から **v2.1.170 → 172 → 173 → 174 → 175 → 176 と 6 連続 stable release** の最終分
- **新機能**:
  - **session title をセッションの会話言語で生成**（`language` 設定で制御可）— 日本語セッションのタイトルが日本語化
  - **`footerLinksRegexes` 設定**追加 — footer 行に regex マッチのリンクバッジを表示可
  - **Bedrock credential caching 改善** — 固定 1 時間ではなく `Expiration` まで credentials をキャッシュ
- **主要バグ修正**:
  - **`availableModels` 強制の抜け穴を修正** — alias の model pick が環境変数経由でブロック済みモデルへリダイレクトできない様に。v2.1.175 の `enforceAvailableModels`（managed model ガバナンス）の実効性を担保する補完修正
  - **Opus 4.8 を持たない組織で auto mode が Fable 5 で失敗する問題を修正** — Fable 5 のみ契約の組織で auto mode が機能する様に
  - hook の `if` 条件がファイルパス（`Edit(src/**)` / `Read(~/.ssh/**)` 等）で正しく評価される様に修正
  - Linux sandbox が `.claude/settings.json` が symlink の場合に失敗する問題、tmux over SSH で `/copy`・マウス選択コピーが clipboard に届かない問題、account サインイン時に Remote Control session が切断されない問題、`/cd`・worktree 移動後の git branch status 不正、`/bg` 後に background session が永久に "Working" 表示、Windows 固有（ネットワークパス / daemon 起動 / auto-update）多数
- ソース: https://code.claude.com/docs/en/changelog
