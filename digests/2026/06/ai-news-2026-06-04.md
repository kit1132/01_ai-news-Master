# AI ニュースダイジェスト 2026-06-04

Microsoft Build 2026 / AWS Bedrock OpenAI 提供開始の余波がもう一段落し、各社の地味な実機能リリースが目立つ日。Anthropic は **Claude Partner Network に「Services Track」と「Partner Hub」を追加**（6/3）し、エンタープライズ向け SIer エコシステムを階層化。Claude Code は **v2.1.161（6/2 stable）** で `/autofix-pr` の worktree バグ、MCP シークレット漏洩、OTel 初期化前ドロップ等を一括修正。Cognition は **Devin Desktop（旧 Windsurf）を正式ローンチ**（6/2）し、ACP（Agent Client Protocol）対応で Claude Agent / Codex / OpenCode を取り込む構え。OpenAI は **Codex に Annotations / Sites / 6 ビジネスプラグイン**を追加し非開発者層（既に 5M WAU の 20%）を強化。

## 最優先

### Anthropic「Claude Partner Network — Services Track」「Partner Hub」発表（6/3）
- 既存パートナーネットワーク（4月発足、$100M 投資）を**正式に3階層化**。デリバリ実績で階層判定:
  - **Select**: 認定者 10 名 / 本番デプロイ顧客 2 社 / 公開事例 1 件
  - **Preferred**: 認定者 100 名 / 顧客 15 社 / 公開事例 3 件
  - **Global Premier**: 認定者 1,000 名 / 顧客 100 社（3 リージョン以上）/ 公開事例 15 件 + ジョイントビジネスプラン
- **Partner Hub** ポータルで認定状況・案件マッチングを可視化
- 3月発足以降、**40,000 社が応募・10,000 名超が Claude Certification 取得**
- 昇格は年2回（1/1、7/1）、初年度のみ 10/1 追加レビュー
- 含意: KPMG / Deloitte / Accenture 級の SIer に Claude 専門デリバリ KPI が課された格好。 OpenAI 側の同等 GTM プログラム不在が比較対象に
- ソース: https://www.anthropic.com/news/services-track-partner-hub

### Claude Code v2.1.161（6/2 stable）
- **OpenTelemetry**: `OTEL_RESOURCE_ATTRIBUTES` をメトリクスデータポイントのラベル化（チーム/リポ次元で Usage スライス可能）。初期化前 OTel ログイベント（user_prompt / api_request / tool_result / tool_decision）ドロップ問題を修正
- **`claude agents`**: ファンアウト時に行ヘッダで `done/total` 表示、Peek で最長実行アイテム可視化
- **`/mcp`**: サインイン履歴のない claude.ai コネクタを「Show unused connectors」配下に折りたたみ
- **並列ツール呼び出し**: バッチ内 1 つの Bash 失敗が他をキャンセルしない独立化
- **Linux クリップボード**: フルスクリーンモードで `wl-copy`/`xclip`/`xsel` を使用、PRIMARY selection と CLIPBOARD 両方にコピー
- **アクセシビリティ**: `/effort` ダイアログ / Workflow アニメ / プロンプト shimmer が「Reduce motion」を尊重
- **管理セキュリティ修正**: `forceLoginOrgUUID` / `forceLoginMethod` が Bedrock / Vertex / Foundry / Mantle セッションをブロックしないように
- **バグ修正**: bg subagent 出力が `claude -p --output-format text/json` の stdout を破損する問題 / `/usage-credits` が Team/Enterprise 管理者に再ログイン要求 / `/autofix-pr` が git worktree で "cannot run on the default branch" / `--resume` ピッカーが jj ワークスペース等を表示しない / Windows Bash hooks 実行エラー / `claude mcp` list/get/add で `${VAR}` シークレットが平文で出る問題 / worktree isolation Workflow エージェントが編集禁止だった問題
- **パフォーマンス**: レイアウトエンジン JIT プロファイル安定化、大規模ファイル書込みレンダリング改善
- ソース: https://code.claude.com/docs/en/changelog

### OpenAI Codex — Annotations / Sites / 6 業界別プラグイン（6/2）
- **Annotations**: ドキュメント / スプレッドシート / スライドの**ピンポイント編集**。ファイル全体を再生成せず該当箇所のみ書き換え（従来は文字数膨張＆遅延の主因）
- **Sites**: アイデア・作業内容を**インタラクティブな Web サイト / 内部アプリに即変換**、URL でチーム共有。Business / Enterprise から rollout
- **6 業界別プラグイン**: 営業 / データ分析 / クリエイティブ制作 / プロダクトデザイン / 公開株式投資 / 投資銀行業務 — 62 ビジネスアプリ（Snowflake, Figma, Salesforce 等）+ 110 自動化スキルを内蔵
- 戦略: Codex を**「コーディング特化」から「業務 OS」へ**ピボット。週間 5M ユーザのうち**非開発者が既に 20%**、採用速度はエンジニアの 3 倍
- **ChatGPT 本体への Codex 統合**を「今後数週間以内」に展開予定
- ソース: https://9to5mac.com/2026/06/02/openai-putting-codex-inside-chatgpt-app-everywhere-releasing-6-business-plugins/ / https://venturebeat.com/orchestration/openais-codex-update-lets-agents-build-interactive-enterprise-workspaces-via-sites-and-role-specific-plugins
