### 1. Kimi K3 のオープンウェイトが実際に公開された — 予告より約 15 時間前倒し、技術レポートも同時公開

**要点**: 2.8T パラメータのウェイトが Hugging Face で公開。**MXFP4 で約 594GB**、vLLM / SGLang が day-0 で対応済み。

**詳細**: 昨日の時点で公開予告は 7/27 15:00 UTC（＝7/28 0:00 JST）だったが、実際には **7/26 約 19:30 EDT（＝7/27 8:30 JST 頃）**に前倒しで公開された。`moonshotai/Kimi-K3` に実体のある safetensors シャード・LICENSE・モデルカードが揃い、**技術レポートも同時公開**。構成は 896 エキスパート中 16 個を選択する MoE で、総 2.8T に対し**アクティブ 104B**、コンテキストは **1,048,576 トークン**、ネイティブ画像入力あり。アーキテクチャの新規要素は Kimi Delta Attention と Attention Residuals で、Moonshot は K2 比で**スケーリング効率が約 2.5 倍**と主張している。量子化は SFT 段階以降の quantization-aware training で、**重み MXFP4 / 活性化 MXFP8**。7/27 の AMA で共同創業者が「配布ウェイトの MXFP4 はホスト API と完全に同一」と明言しており、自前ホストと API で精度差が出ない建て付けになっている。ライセンスは Hugging Face 上の表記が `other / kimi-k3` で、素の MIT ではなく**商用条件付きの MIT ライク**（Moonshot 自身の API と競合する用途は別途交渉が必要という解釈が優勢）。推論基盤は SGLang が `lmsysorg/sglang:kimi-k3`（CUDA）と `lmsysorg/sglang-rocm:rocm720-mi35x-k3`（AMD）の Docker イメージを公開済み、vLLM も 7/22 時点でプレビュー実装・デプロイレシピを準備していた。Together AI と Modal が day-0 のホスティングを提供。

**意味**: 「オープンウェイト最大」の実物が出たが、**自前ホストの現実的な下限が高い**。Moonshot 自身の推奨が 64 アクセラレータ以上のスーパーノードで、4bit でも約 1.4TB という試算がある以上、ワークステーションや単一 GPU サーバでの検証は成立しない。組織として触るなら Together AI / Modal のホスト経由か、既存 GPU クラスタに SGLang の Docker を載せる経路になる。llama.cpp / Ollama / LM Studio 系は新アーキテクチャ対応待ちで、DeepSeek V4 の前例では mainline 対応まで数週間かかっている。

### 2. Devin Outposts（7/21・初報） — エージェントループはクラウド、コマンド実行は自社インフラという分離

**要点**: Devin Cloud のセッションを**自社が管理するマシン上で実行**できるようになった。推論と計画はクラウド、実行系は手元。

**詳細**: Cognition が 7/21 に alpha で公開。Outpost は「名前付きキュー」で、Devin Cloud のセッションと自分が運用するマシン群を紐づける。**Devin のエージェントループ（推論・プランニング）は Devin のクラウドで動き続ける**一方、**コマンド実行・ファイル編集・リポジトリアクセスは自分のマシン**で行われる。対応先はラボの GPU ボックス、プライベートネットワーク内の VM、社内サービスの隣に置いた Kubernetes クラスタ、机上の Mac mini など。手順は Devin Cloud 側で Outpost を作成し、Devin CLI で自マシンに Outpost worker を追加、セッション開始時にランタイム環境として選択する。インフラパートナーとして Modal・E2B・Daytona 等の統合が用意されており、Modal 経由なら学習・推論と同じ GPU 基盤上で Devin に障害再現やプロファイリングをさせて、終了後ゼロにスケールダウンできる。

**意味**: 社内サービスやプライベートネットワーク内のリソースに触れる必要がある作業を、コードや実行環境を外に出さずにエージェントへ渡せるようになる。ただし**エージェントループ自体は Cognition のクラウドに残る**ため、完全なオンプレ化ではない。評価する際はこの境界線がセキュリティ要件を満たすかが判断軸になる。

- https://devin.ai/blog/introducing-devin-outposts
- https://modal.com/blog/devin-outposts-run-devin-in-modal-sandoxes
