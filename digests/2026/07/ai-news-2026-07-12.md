# AI News Digest 2026-07-12

日曜で新規発表は少なく、動きは前日に続き**開発ツールのリリース**に集約。Claude Code が v2.1.207 に到達（Bedrock/Vertex/Foundry で Auto mode がデフォルト有効化、既定モデルを Opus 4.8 に）、**Cursor 3.11 が Side Chats を追加**、Copilot CLI・Codex CLI も pre-release/alpha を刻む。モデル面では **Anthropic が Fable 5 の有料プラン無償提供を本日 7/12 まで延長**。

## 開発ツール — Claude Code v2.1.207 / Cursor 3.11 / Copilot CLI v1.0.71-0 / Codex alpha

- **Claude Code v2.1.207（7/11）※新規** — **Bedrock / Vertex AI / Foundry で Auto mode が `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in なしでデフォルト有効化**（無効化は settings の `disableAutoMode`）、**Bedrock / Vertex / Claude Platform on AWS の既定モデルを Opus 4.8 に変更**。セキュリティ修正として **プラグイン hooks/monitors/MCP の shell-form コマンドで `${user_config.*}` を拒否（shell-injection 対策）**、非対話実行（`claude -p`/SDK）のリモート管理設定が同意ダイアログ非表示のまま consent 済み記録される不具合を修正。ほか長文ストリーミング時の端末フリーズ、agent teams の mailbox 不正メッセージによるクラッシュループ、auto-updater が `~/.local/bin/claude` のカスタムランチャーを上書きする不具合、Remote Control の状態消失、Deep research の Fetch フェーズが全 agent を "unknown" 表示する不具合等を修正
- **Cursor 3.11（7/10）※新規** — **Side Chats**（メインの agent 会話を止めずに脱線調査できる並走チャット。`/side`・`/btw`・チャットパネル上部の + から作成、メインの文脈を引き継ぎ後から本流へ at-mention で戻せる）、**agent transcript の検索強化**（名前/PR 番号を超えた検索、会話内 Cmd+F でマッチ間ジャンプ）、project/repo ピッカーの簡素化。前日ダイジェスト時点では未反映だったため新規計上
- **GitHub Copilot CLI pre-release v1.0.71-0（7/10）※新規** — `/settings` に pinned prompts 設定（プロンプトのピン留め制御）、設定ダッシュボードにリポジトリスコープのタブ追加、セッション終了が Ctrl+X→X・サイドバー非表示が Ctrl+X→H に変更。interactive shell の再設定エラーを "reconfiguring" のリトライ扱いに（従来の `unknown shellManager handle` 失敗を解消）。安定版は v1.0.70（7/10）のまま
- **OpenAI Codex CLI alpha 0.145.0-alpha.4（7/11）※新規** — alpha が 7/9〜7/11 で alpha.1→alpha.4 まで急速に反復（installer 信頼性・code-mode まわり）。安定版は 0.144.1（7/9）据え置き
