# AI News Digest — 2026-07-19

## Claude / Anthropic

- **Claude Code v2.1.214（7/18）** — セキュリティ・権限周りの修正が中心。`dir/**` 許可ルールがツリー内のどこでもネストディレクトリへの書き込みを自動承認していた不具合、Windows PowerShell 5.1 セッションでの権限チェックバイパス、ファイルディスクリプタリダイレクト・超長コマンド（>10,000字）での Bash 権限チェック漏れを是正。新機能として、濫用・脱獄試行に対処する `EndConversation` ツール、長時間ツール呼び出し中の定期進捗ハートビート、メモリファイル frontmatter への ISO `modified` タイムスタンプ、OpenTelemetry 拡張（`message.uuid` / `client_request_id` / `tool_source`）を追加。Docker/Podman はデーモンリダイレクト系フラグ（`--url` / `--connection` / `--identity`）で権限プロンプトを出すよう変更。
  https://code.claude.com/docs/en/changelog

- **Fable 5 無償提供が本日 7/19 で終了** — Pro/Max/Team＋対象 Enterprise 向けの無償提供（週次上限の最大50%）と Claude Code の週次上限 +50% 促進が本日 23:59 PT で終了。7/20 以降は前払いクレジット運用（$10 / $50）に移行し、利用上限は標準水準に戻る（プラン・課金の変更はなし）。
  https://www.anthropic.com/news
