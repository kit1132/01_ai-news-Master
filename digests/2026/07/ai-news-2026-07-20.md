# AI News Digest — 2026-07-20

## Claude / Anthropic

- **Claude Code v2.1.215（7/19）** — `/verify` と `/code-review` スキルの自動実行を廃止し、ユーザーが `/verify` / `/code-review` を明示的に呼び出したときのみ起動するよう変更。あわせて Windows で Group Policy が PowerShell 5.1 をブロックする環境で `/background`・`claude --bg` が `uv_spawn` エラーで失敗する不具合（デーモンが PowerShell 7 を優先するよう修正）、パス補完ポップアップ表示中にシェルモード（`!`）がパス入りコマンドを実行しない不具合、`/ultrareview` が `#123`・`PR 123`・貼り付けた PR URL を拒否する不具合を是正。
  https://code.claude.com/docs/en/changelog

- **Claude Enterprise Admin API のユーザー管理機能が beta 提供開始** — Claude Enterprise（claude.ai）組織のメンバーを Admin API から管理可能に。メンバー一覧・メールアドレス検索、ロール変更、削除、招待の送信・取消、グループとそのメンバーシップ管理、カスタムロールの読み取りに対応。グループ／カスタムロール系リクエストは `anthropic-beta: ce-user-management-2026-07-13` ヘッダーが必要（メンバー・招待系はヘッダー不要）。`read:org_audit` スコープの Admin API キーで全 GET エンドポイントを呼べる。
  https://platform.claude.com/docs/en/manage-claude/admin-api

- **Fable 5 が本日 7/20 から前払いクレジット運用へ** — 7/19 23:59 PT で無償提供（週次上限の最大50%）と Claude Code 週次上限 +50% 促進が終了。7/20 以降は前払いクレジット（$10 / $50）で利用し、上限は標準水準に復帰。モデル仕様（1M context / 128k output）とプランの変更はなし。
  https://platform.claude.com/docs/en/about-claude/models/introducing-claude-fable-5-and-claude-mythos-5
