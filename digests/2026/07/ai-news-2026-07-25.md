# AI News Digest — 2026-07-25

## AI モデル / プロダクト

- **Anthropic「Claude Opus 5」を GA 公開（7/24）** — 新しい既定モデル。フラッグシップ Fable 5 に迫る知能を「半額」で提供する位置づけで、多くのユーザー向けの標準モデルに昇格。タスクに費やす推論量を **low / medium / high の3段階でトグル**でき、コストと能力のバランスをユーザー側で調整できる。コーディング・知識労働ベンチ（Frontier-Bench、GDPval-AA）で新 SOTA を主張する一方、サイバーセキュリティ課題では Mythos 5 に及ばず。料金は Opus 4.8 から据え置きの **$5 / $25 per Mtok（fast mode は $10 / $50）**、1M コンテキスト。Mythos 5・Fable 5・Sonnet 5 に続き **2ヶ月弱で4本目**という異例の投入ペース。
  https://www.anthropic.com/news/claude-opus-5

- **OpenAI「Health in ChatGPT」を全米ユーザーに GA（7/23）** — 健康記録と ChatGPT を統合する専用体験。Apple Health（運動・睡眠・アクティビティ）に加え、米病院システム・One Medical・Function Health の医療記録を連携でき、投薬・検査結果・受診履歴などを会話に引き込める。18歳以上の Free / Go / Plus / Pro（EEA・スイス・英国を除く）が対象、Web と iOS で提供。2026年1月のパイロットが不発だったのを数ヶ月かけて作り直しての再ローンチ。あわせてデスクトップアプリで ChatGPT Voice を Work / Codex に展開。
  https://openai.com/index/health-in-chatgpt/

## コーディングエージェント / 開発ツール

- **Claude Code v2.1.219（7/24）** — **Claude Opus 5（`claude-opus-5`）を既定の Opus モデルに採用**（1M コンテキスト、fast mode $10/$50）。fast mode から Opus 4.7 を除外し、`/fast` は Opus 5 / 4.8 に適用。新設定 `sandbox.network.strictAllowlist`（許可リスト外ホストをプロンプトなしで拒否）、`/add-dir`・SDK での作業ディレクトリ追加後に発火する `DirectoryAdded` フック、Dynamic workflow サイズ推奨を制御する `workflowSizeGuideline`、サブエージェントの入れ子生成を既定で深さ3まで許可（`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` で変更）。修正: `claude -p` がストリーム中の API エラーで回答を落とす問題、self-hosted runner 再起動時に承認済み権限がセッション再開で失われる問題ほか。
  https://code.claude.com/docs/en/changelog

- **GitHub Copilot CLI v1.0.74 を安定版リリース（7/23）** — pre-release 系列（v1.0.74-0〜-4）が安定版に昇格。Open Plugin Spec v1 のプラグインマニフェスト対応、Gemini 3.6 Flash サポート、MCP サーバの確実な再接続を含む IDE 連携安定化、サブエージェント タイムラインでのプロンプト由来（メイン/サブ）識別、`/model plan`（プランモードでのモデル選択）を統合。従来の安定版 v1.0.73（7/20）から更新。
  https://github.com/github/copilot-cli/releases

- **Cursor「Cursor Router」を導入（7/22）** — Auto モードを、リクエストごとに内容を解析して最適なモデルへ振り分けるインテリジェント ルーターで駆動。チームは **Intelligence / Balance / Cost** の3モードを選べ、管理者が既定モデルとアクセスを制御できる。既報の /loop・Jira 連携・プラグインリーダーボード（3.11 系）に続くエージェント運用面の強化。
  https://cursor.com/changelog

- **OpenAI Codex CLI 0.146.0-alpha.7 進行中（7/24）** — 安定版は 0.145.0（7/21）据え置き。0.146.0 に向けた alpha ビルド（alpha.1〜.7）が日次で刻まれているが、公開リリースノートに具体的な変更記載はなく、0.145.0（ページネーション付きスレッド履歴・Cursor/Claude Code 設定インポート・Bedrock ログイン・音声入力・マルチエージェント V2）からの漸進ビルドの段階。
  https://github.com/openai/codex/releases
