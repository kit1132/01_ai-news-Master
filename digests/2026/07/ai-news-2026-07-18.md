## Claude / Anthropic

- **Claude Code v2.1.212（7/17）** — `/fork` が会話を新規バックグラウンドセッションへコピーする方式に変更（現行作業を維持）、セッション内サブエージェント起動は `/subtask` に置き換え。`claude auto-mode reset`（確認プロンプト付き）を追加。WebSearch のセッション全体上限（既定200・`CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`）とサブエージェント生成のセッション上限（既定200・`CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`）を新設。2分超の MCP ツール呼び出しは自動でバックグラウンド移行（`CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`）。`/resume` が削除済みを含む過去セッションのピッカーを表示。セキュリティ修正として、plan モードが権限プロンプトなしにファイル変更 Bash を自動実行する不具合、worktree 作成時の symlink 脆弱性を是正。ほか Windows print/SDK モードで SIGTERM がプロセスを孤児化する不具合、`/ultrareview` が `#123`／`PR 123` 形式の PR 参照を拒否する不具合、hosted セッションの mTLS 証明書・OAuth スコープ不具合、ストリーミング制御リクエストがセッション再起動でデータ欠落する不具合を修正。
