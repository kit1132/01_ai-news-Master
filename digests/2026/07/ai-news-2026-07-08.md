大型モデル発表はなし。開発ツールが主役で、GitHub が Copilot デスクトップアプリを全プランに開放（7/7）、Claude Code は v2.1.202（7/6）で動的ワークフローのサイズ制御設定を追加。CLI 各種の小刻み更新が続く。

## 開発ツール — Copilot アプリ全プラン開放 / Claude Code v2.1.202

- **GitHub Copilot App を全プランに開放（7/7）** — デスクトップアプリ（macOS/Windows/Linux）が Free・Education を含む**全 Copilot プラン**で利用可に。GitHub アカウントでサインインし、デスクトップからエージェント駆動開発を開始できる。CLI に続きアプリ本体も一般化
- **Claude Code v2.1.202（7/6）※新規** — `/config` に「Dynamic workflow size」設定を追加（動的ワークフローが生成するエージェント数を制御）、テレメトリに `workflow.run_id`/`workflow.name` OTel 属性を追加。`/review <pr>` を高速単一パスレビューに戻す（多エージェントは `/code-review <level> <pr#>` を使用）。Ctrl+R 履歴検索のクラッシュ・mTLS ハンドシェイク失敗・Remote Control 経由の画像/ファイル処理・音声ディクテーションのリトライループなどを修正
- **GitHub Copilot CLI**: pre-release **v1.0.69-3（7/7）※新規** — 承認済みの組込みファイル編集がサンドボックスをバイパス可能に、`/sandbox add-path` サジェスト・`/chronicle cost-tips` 強化、大規模 diff での `/diff` 描画性能改善、自動承認タイムラインにリクエスト詳細を表示。v1.0.69-1（7/4）で `/mcp list` と auto allow-all モード（既報）。安定版は v1.0.68（7/1、kimi-k2.7-code 対応）のまま
- **OpenAI Codex CLI**: pre-release **0.143.0-alpha.38（7/7）※新規** — alpha は日次更新で機能追加は小粒。安定版 0.142.5（7/1）のまま
- 出典: [GitHub Copilot app changelog](https://github.blog/changelog/2026-07-07-github-copilot-app-available-to-all/) / [Claude Code Changelog](https://code.claude.com/docs/en/changelog) / [Copilot CLI releases](https://github.com/github/copilot-cli/releases) / [Codex releases](https://github.com/openai/codex/releases)
