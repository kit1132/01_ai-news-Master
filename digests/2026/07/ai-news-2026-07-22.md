## コーディングエージェント / 開発ツール

- **OpenAI Codex CLI 0.145.0 安定版リリース（7/21）** — 0.144.6（7/18）から alpha を経て 0.145.0 が GA。目玉は「実験的なページネーション付きスレッド履歴」— 効率的な resume・検索・名前の永続化・サブエージェント対応・メモリ（memories）を搭載。あわせて他社ツールからの設定インポート拡充、Amazon Bedrock ログイン対応、音声入力を追加。長い会話でのターミナル応答性も改善。
  https://github.com/openai/codex/releases

- **GitHub Copilot CLI v1.0.73 安定版（7/21）＋ v1.0.74-0 pre-release（7/21）** — v1.0.73: Anthropic サブエージェントが追加ディレクトリ（`--add-dir`）でも動作するよう修正、カスタムエージェント指示内の相対リンク解決を改善。pre-release v1.0.74-0: `/model plan`（plan モード用モデル選択）追加、セッション resume がタイトルの空白揺れを吸収してマッチするよう改善。
  https://github.com/github/copilot-cli/releases

- **Claude Code v2.1.216（7/20）** — `sandbox.filesystem.disabled` 設定を追加（ネットワーク egress 制御は維持したままファイルシステム分離のみスキップ可能に）。長時間セッションでメッセージ正規化コストがターン数に対し二次関数的に増大し数秒のストール・resume 遅延を招く問題を修正。OAuth トークンの期限切れ/ローテーション後に auto モードが「HTTP 401」分類エラーでコマンドを誤って拒否する不具合、worktree 分離サブエージェントが `git -C`／`GIT_DIR` 等で共有チェックアウトに書き込む問題、クラウドセッションのコンテナ再起動でターン途中のメッセージが失われる問題などを是正。
  https://code.claude.com/docs/en/changelog

## 企業導入 / 運用

- **Amazon CloudWatch「Coding Agent Insights」提供開始（7/20）** — AI コーディングエージェントの利用状況を監視する専用ダッシュボード。各エージェントが emit する OpenTelemetry メトリクスをベースに、Claude apps gateway 経由で Claude Code のテレメトリを追加計装なしで収集（Codex・GitHub Copilot も対応）。個人・小規模はベアラートークンで CloudWatch ネイティブ OTLP エンドポイントに直接送信、企業規模は Claude apps gateway で集中管理（Bedrock / Claude Platform on AWS / Google Cloud / Microsoft Foundry の複数バックエンド対応）。「どのチームに拡大すべきか」「エージェントがどこで開発を加速しているか」「部門横断でトークン予算をどう最適化するか」といったチーム導入の意思決定を支援。中東（UAE / Bahrain）・イスラエル（Tel Aviv）を除く全 AWS 商用リージョンで利用可能。
  https://aws.amazon.com/about-aws/whats-new/2026/07/cloudwatch-coding-agent-insights/
