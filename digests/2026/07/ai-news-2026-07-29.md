### 1. MCP 仕様 `2026-07-28` が最終版として公開 — launch 以来最大の改訂で、ステートレス化という破壊的変更を伴う

**要点**: MCP からハンドシェイクとセッションが消えた。自社運用のリモート MCP サーバーは移行作業が要る。

**詳細**: RC は 5/21 にロックされ、10週間の検証期間を経て **7/28 09:00 UTC**（7/28 18:00 JST）に最終仕様が公開された。中核の変更はプロトコルのステートレス化で、`initialize` / `initialized` ハンドシェイクと `Mcp-Session-Id` ヘッダが**廃止**され、各リクエストが自分でプロトコルバージョン・クライアント識別・ケーパビリティを宣言する形になった。付随して、双方向ストリームを開いたままにせず確認や不足パラメータの問い合わせを行う Multi Round-Trip Requests、メソッド名とツール名を `Mcp-Method` / `Mcp-Name` ヘッダに載せて JSON をパースせずゲートウェイでルーティングできる仕組み、`ttlMs` と `cacheScope` を付けた一覧結果のキャッシュが入った。認可は RFC 9207 の issuer 検証必須化と、Dynamic Client Registration から Client ID Metadata Documents への移行が中心。Tasks・MCP Apps・Enterprise Managed Authorization は正式な Extensions 枠組みに移り、reverse-DNS 識別子と独立バージョニングを持つ。Roots・Sampling・Logging・レガシー HTTP+SSE トランスポートは非推奨となったが、**12ヶ月以上**の猶予が保証される。SDK は TypeScript・Python・Go・C# の Tier 1 4種が対応済みで、Rust は beta。Python は PyPI の `mcp 2.0.0b1`、TypeScript は `@modelcontextprotocol/server` と `@modelcontextprotocol/client` という新パッケージ名の `2.0.0-beta.1` として配布される（旧パッケージは v1 のまま）。Tier 1 SDK の月間ダウンロードは平均約 5億、TypeScript と Python は累計それぞれ 10億超。

**意味**: 社内で MCP サーバーを立てている場合、スティッキーセッションと共有セッションストアが不要になり、素のラウンドロビン LB の背後に置けるようになる。運用コストは下がる方向だが、セッション ID に依存した実装は書き直しが必要で、TypeScript はパッケージ名ごと変わるため単なるバージョン上げでは済まない。Claude Code・Copilot CLI・Codex CLI がいずれも依存する基盤仕様なので、クライアント側の対応時期も併せて追う必要がある。

### 2. GitHub が 7/30・7/31 に廃止を2件実行 — GitHub Models 全廃と Copilot からの Gemini 2機種削除

**要点**: GitHub Models は 7/30 に全廃され、Copilot の Gemini 2.5 Pro / Gemini 3 Flash は 7/31 に廃止される。

**詳細**: GitHub Models は **7/30** に playground・モデルカタログ・推論 API・BYOK エンドポイント・関連 UI がすべて利用不可になる。予告として 7/16 と 7/23 にブラウンアウト（リクエストが一時的にエラーを返す時間帯）が実施済み。もう1件は Copilot 側で、**7/31** に Gemini 2.5 Pro と Gemini 3 Flash が Copilot Chat・インライン編集・ask / agent モード・コード補完のすべてから削除される。移行先として Gemini 3.1 Pro と Gemini 3.5 Flash が案内されている。いずれも 7/1・7/2 に github.blog changelog で告知されていたもので、当ダイジェストでは未掲載だった。

**意味**: GitHub Models を検証用のモデル比較に使っている場合、7/30 以降は同じ手段が残らない。Copilot 側は、既定モデルではなく Gemini を明示指定している設定やワークフローが 7/31 に無効化されるため、リポジトリの Copilot 設定と CI に埋めたモデル指定を確認しておく必要がある。
