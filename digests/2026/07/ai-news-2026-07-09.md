## 開発ツール — Claude Code v2.1.205 / Codex CLI 0.143.0 / Copilot

- **Claude Code v2.1.203〜205（7/7〜7/8）※新規** — v2.1.202（7/6）から連日更新。目玉は **v2.1.205（7/8）**: auto mode がセッション transcript 改ざんをブロック／解決できない変数への `rm -rf` を実行前に確認、`/doctor` をセットアップ総合診断に格上げ（`/checkup` はエイリアス）、agent view 刷新（色付き state 語 + headline 表示・PR 自動リンク）、auto-update のピークメモリ約 400MB 削減、"Claude Browser" MCP サーバー名を予約。**v2.1.204** は headless セッションの SessionStart hook 未ストリーミング不具合を修正、**v2.1.203** は login 期限切れ警告・manual permission mode の⏸バッジ・背景エージェント/worktree 周りの大量安定性修正
- **OpenAI Codex CLI 安定版 0.143.0（7/8）※新規** — Remote plugins をデフォルト有効化、macOS/Windows のシステムプロキシ対応。安定版 0.142.5（7/1）から更新。alpha は 0.144.0-alpha.2（7/8）まで進行
