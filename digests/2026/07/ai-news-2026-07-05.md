# AI News Digest 2026-07-05

## ⚡ 最重要: Claude apps gateway 提供開始 — Claude Code をセルフホスト gateway 経由で企業運用

- **Anthropic が「Claude apps gateway」を提供開始**（Sonnet 5 ローンチ期に併せて公開、当ダイジェスト未報の catch-up）。`claude` バイナリ内蔵のセルフホスト型サービスで、開発者は API キー/クラウド資格情報を持たず**社内 IdP（OIDC）で SSO ログイン**する。`claude gateway --config gateway.yaml` で起動、単一ステートレス Linux コンテナ + PostgreSQL 構成
- **提供する統制**: ①上流資格情報を自社インフラに封じ込め（短命 bearer トークン、IdP 停止で最長 1 時間内に失効）②IdP グループ単位のモデル allowlist・managed settings 強制（サーバ側で非許可モデルを拒否）③OTLP テレメトリ（Datadog/Splunk/ClickHouse 等）へトークン数・モデル・利用者・レイテンシを送出 ④日次/週次/月次の spend 上限（組織/グループ/ユーザ単位）
- **上流ルーティング**は Amazon Bedrock / Claude Platform on AWS / Google Cloud Agent Platform / Microsoft Foundry / Anthropic API を切替・フェイルオーバー対応。データ所在（data residency）要件で自社クラウド経由を強制したい組織向け。要 Claude Code v2.1.195 以降（Claude Platform on AWS 上流は v2.1.198+）
- **制約**: サーバサイド web 検索・1 時間キャッシュ TTL・first-party 最適化（global cache scope 等）は gateway セッションでは無効。SAML/LDAP 非対応（OIDC のみ）、Windows サーバ非対応、Admin UI なし（YAML のみ）。CI 用サービストークン無し（ブラウザ device flow 必須）
- 出典: [Claude Code Docs（Claude apps gateway）](https://code.claude.com/docs/en/claude-apps-gateway) / [Claude Blog](https://claude.com/blog/introducing-the-claude-apps-gateway)
