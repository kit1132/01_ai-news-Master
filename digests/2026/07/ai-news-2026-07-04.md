# AI News Digest 2026-07-04

## ⚡ 最重要: Claude Code v2.1.200（7/3）— デフォルト権限モードが「Manual」に、AskUserQuestion の自動継続を廃止

- **デフォルト権限モードが "default" → "Manual" に変更**（CLI / VS Code / JetBrains 共通、v2.1.200）。加えて **`AskUserQuestion` ダイアログが既定で自動継続しなくなった**（アイドルタイムアウトは `/config` でオプトイン）。エージェントが勝手に進む挙動を絞り、承認を明示操作に寄せる安全側の既定変更
- **背景セッション・サブエージェントの安定性を集中的に修正**（v2.1.199/200）— sleep/wake 後の無言停止、stall 再起動後のキャンセル済みターン再実行、レート制限で打ち切られたサブエージェントが空結果を返す問題、`claude stop` が背景エージェント再起動で無効化される問題を修正。ストリーミング中の API エラーで部分出力を破棄しない改善、`CLAUDE_CODE_MAX_RETRIES` の上限拡張（`CLAUDE_CODE_RETRY_WATCHDOG`）、サブスクライバ向け自動リトライ（バックオフ）追加
- **スタック実行のスラッシュスキルが先頭 5 個までロード**（`/skill-a /skill-b do XYZ`、v2.1.199）。スクリーンリーダー出力・SSL エラー案内の改善も
- 出典: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Claude Code — Anthropic が「競合検出用の隠しコード」を削除（修正 7/1）

- Anthropic が 3 月に Claude Code へ仕込んでいた **steganography による隠しマーカー**（base URL の環境変数を検査し、中国系 AI ラボ・他 AI 企業・アカウント転売業者・ゲートウェイのホスト名一致を検出する仕組み）を削除。エンジニアが「7/1 に修正が入る」と表明。転売・distillation 対策の実験だったが、開発者ツールに隠蔽実装を入れたことへの批判を受け、より強力な代替策への移行を理由に撤去
- 出典: [The Register](https://www.theregister.com/ai-and-ml/2026/07/01/anthropic-is-removing-its-covert-code-for-catching-chinese-competitors/5265366) / [AI Weekly](https://aiweekly.co/alerts/anthropic-to-remove-claude-code-marker-that-flagged-china-users)
