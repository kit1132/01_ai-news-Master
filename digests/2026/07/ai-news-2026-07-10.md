# AI News Digest 2026-07-10

昨日 7/9（米時間）に大型発表が集中した。**OpenAI が「ChatGPT Work」エージェント**と Codex 統合の新デスクトップアプリを公開、**旧 xAI が「SpaceXAI」へ改称し Grok 4.5 を一般公開**、さらに **Anthropic が使用状況ダッシュボード「Reflect」** を beta 提供開始。開発ツール側も Codex CLI が安定版 0.144.0 に。

## 製品 — OpenAI「ChatGPT Work」+ Codex 統合デスクトップアプリ（7/9）

- **ChatGPT Work 公開（7/9）※新規** — GPT-5.6 を基盤に、アプリ・ファイル・ワークフローから文脈を集め、**数時間にわたり自律実行**して文書/スプレッドシート/プレゼン/Web アプリまで完成物を作るエージェント。スケジュール実行に対応し、Web/モバイル/デスクトップ・スマホからも起動管理可。ローカルファイル/アプリ、または新内蔵ブラウザで Web を操作、Plugins で外部アプリ連携
- **Codex を ChatGPT デスクトップアプリに統合（7/9）※新規** — macOS/Windows で **Codex アプリと ChatGPT アプリを統合**。既存 Codex ユーザーはプロジェクト/設定/ワークフローを維持したまま更新でき、Codex をデフォルトビューに設定可。Mac は Chat/Work/Codex を1アプリに集約
- **Sites（beta）※新規** — レポートやライブダッシュボード用にインタラクティブなサイト/Web アプリを生成するホスティング機能
- **提供範囲** — ChatGPT Work は Pro / Enterprise / Edu で先行提供、数日内に Plus / Business へ拡大。GPT-5.6 Sol/Terra/Luna は 7/9 グローバル GA（既報）
- 出典: [OpenAI — Introducing the Codex app](https://openai.com/index/introducing-the-codex-app/) / [9to5Mac](https://9to5mac.com/2026/07/09/openai-announcing-the-next-chapter-for-chatgpt-today-watch-here/) / [The Decoder](https://the-decoder.com/openai-pairs-its-gpt-5-6-public-rollout-with-chatgpt-work-a-new-agent-that-handles-entire-workflows/)

## モデル — SpaceXAI「Grok 4.5」一般公開（7/9）

- **Grok 4.5 公開（7/9）※新規** — SpaceXAI（旧 xAI）が「最も賢いモデル」と位置づける、コーディング/エージェント/知識作業（スプレッドシート・文書）特化モデル。汎用チャットボットではなく実務向けと明言。**Cursor と共同訓練**（Cursor-Trained）。実エンジニアリング性能・トークン速度の向上を強調
- **価格 $2/$6（キャッシュ入力 $0.50）※新規** — Opus 4.8（$5/$25）を大幅に下回る。SpaceXAI 自称で「Opus クラス性能」。長コンテキスト/ツール多用時は上振れあり
- **提供** — Grok Build・Cursor（全プラン）・SpaceXAI コンソールで即日提供。EU は未提供で 7 月中旬めど
- 出典: [SpaceXAI — Introducing Grok 4.5](https://x.ai/news/grok-4-5)（WebFetch 403・WebSearch 経由） / [MarkTechPost](https://www.marktechpost.com/2026/07/08/spacexai-releases-grok-4-5/) / [Axios](https://www.axios.com/2026/07/08/spacexai-grok-new-model)

## Anthropic — 使用状況ダッシュボード「Reflect」beta（7/9）

- **Claude Reflect 公開（7/9）※新規** — Claude の利用状況を可視化する内蔵ダッシュボード。過去 1/3/6/12 ヶ月のチャット活動を振り返り、主要トピック・最も活発だった日/時間帯・作業傾向を月次レコードで提示。**quiet hours 設定や一定時間後の休憩ナッジ**などウェルネス機能も内蔵
- **提供範囲** — Free / Pro / Max（memory 有効が前提）。Web と Claude Desktop の設定から生成。incognito チャット・連携ツールの元ファイル・健康連携の会話は insights から除外
