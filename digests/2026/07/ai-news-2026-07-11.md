- **Claude Code v2.1.206（7/9）※新規** — `/cd` にディレクトリパス補完追加（`/add-dir` と同等）、`/doctor` が「コードから導出可能な `CLAUDE.md` 記述の削減」を提案、**`/commit-push-pr` が `remote.pushDefault`（単一リモート時はそれ）への `git push` も自動許可**、gateway `/login` が Anthropic 運用の公開ゲートウェイに対応、`.claude/worktrees/` 外の worktree 進入時に確認、Claude Code 更新後は背景エージェントを即時アップグレード、**opus-4-8 での `/code-review` 品質を全 effort で改善**。期限切れ login が「モデルの問題」と誤表示されるバグ等を修正
- **GitHub Copilot CLI 安定版 v1.0.70（7/10）※新規** — pre-release v1.0.70-0（7/9）を安定版に昇格。**GPT-5.6 対応**、`/refine`（プロンプト精緻化）、プラグインの commit SHA ピン留め、`--sandbox`/`--no-sandbox` フラグ、**リポジトリ単位設定 `.github/copilot/settings.json`**（model/effort/context tier のピン留め）。安定版は v1.0.69（7/7）から更新
