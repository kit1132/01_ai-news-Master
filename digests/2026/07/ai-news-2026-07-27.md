# AI News Digest — 2026-07-27

## AI モデル / プロダクト

- **Kimi K3 のオープンウェイトが本日 9:00 JST 公開予定（7/27 00:00 UTC）** — Moonshot AI が 7/16 に API 提供を開始した **2.8T パラメータ MoE**（1M context・ネイティブ画像入力）の重みを、公開から11日で Hugging Face に降ろす。**公開ウェイトとしては過去最大**。配布は MXFP4（4bit 浮動小数点＋ブロック単位スケール）で、それでも重みだけで**約 1.4TB** あり、KV キャッシュや実行時オーバーヘッドは別枠。自前ホストの現実的なハードルは高いが、API を中国側に通さずに frontier 級コーディングモデルを動かせる選択肢が初めて出てくる点が組織導入上の意味。**本稿執筆時点（4:00 JST）では未公開**。
  https://huggingface.co/blog/ResterChed/kimi-k3-model-overview-mxfp4-quantization-open-wei

## コーディングエージェント / 開発ツール

- **Claude Security プラグインが public beta（7/22・当ダイジェスト未報告分）** — Claude Code のターミナルから脆弱性スキャンを走らせるプラグイン。`/claude-security` で **Scan codebase / Scan changes / Suggest patches** の3モードを選ぶ。複数エージェントがコードベースのマッピング→脅威の洗い出し→ファイル横断・業務ロジック横断の関連付け→**findings の独立再検証**→修正パッチ付きレポート、という分業構成を取るため、パターンマッチ型ツールが取りこぼす injection・認証バイパス・メモリ破壊・ロジック欠陥を狙う。導入要件は**有料プラン＋Claude Code v2.1.154 以降**、`/config` で dynamic workflows 有効化、PATH 上に `python3`（3.9.6+）と Git。組織単位の有効化は管理コンソール（`claude.ai/admin-settings/claude-code`）から。
  https://claude.com/product/claude-security

- **Claude API 7/24 分に破壊的変更2件と beta 2件（モデル発表の陰で未報告）** — Opus 5 リリースと同日の Platform release notes に、モデル本体以外の実務直結項目が入っていた。
  - **破壊的変更**: ① Opus 5 では `thinking: {"type":"disabled"}` を effort `xhigh` / `max` と併用すると **400 エラー**（Opus 4.8 からの挙動変更。無効化できるのは effort `high` 以下）。② **Opus 4.7 の fast mode を廃止**。`claude-opus-4-7` に `speed:"fast"` を投げるとエラーになり、Opus 4.6 と違って標準速度へのフォールバックもしない。
  - **beta 追加**: ③ **会話途中のツール差し替え**が Fable 5 / Mythos 5 / Opus 4.8 / Opus 5 で beta 提供。**プロンプトキャッシュを保持したまま**ターン間でツールを追加・削除できる（`mid-conversation-tool-changes-2026-07-01` ヘッダ）。長いエージェントループでツール構成を切り替えるとキャッシュが飛ぶ問題への直接の回答。④ `fallbacks` パラメータに `"default"` モード追加。拒否カテゴリ別に Anthropic 推奨のフォールバックモデルを自動適用する（`server-side-fallback-2026-07-01` ヘッダ）。
  https://platform.claude.com/docs/en/release-notes/api

- **Claude Code v2.1.220（7/25）据え置き / GitHub Copilot CLI v1.0.75（7/24）据え置き** — いずれも新バージョンなし。Codex CLI も安定版 0.145.0（7/21）のままで、`0.146.0-alpha.10.1`（7/25 20:29 UTC）以降の新規ビルドはなく、公開リリースノートに具体的な変更記載も出ていない。
