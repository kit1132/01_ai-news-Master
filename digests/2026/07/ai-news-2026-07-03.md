# AI News Digest 2026-07-03

## ⚡ 最重要: Claude Code v2.1.198（7/1）— Claude in Chrome が GA、バックグラウンドエージェントが自律 push・draft PR 化

- **Claude in Chrome が一般提供（GA）** — ブラウザ拡張が正式版に。加えて `Notification` hook にバックグラウンドエージェント用イベント（`agent_needs_input` / `agent_completed`）が追加され、完了・入力待ちを通知でき、常駐運用が実用段階に
- **バックグラウンドエージェントがコード作業完了時に自動で commit・push・draft PR 作成**（従来は都度確認）。承認待ちのボトルネックが外れ、非同期のエージェント運用が既定挙動へ。`claude --bg` と `--print`/`-p` の競合フラグは今後拒否
- **Explore サブエージェントが親セッションのモデルを継承**（従来 haiku 固定 → opus 上限で継承）、サブエージェント・コンパクションが extended thinking 設定を継承。`/dataviz` skill（配色バリデータ付き）、Gateway に Claude Platform on AWS を upstream 追加（model-not-found でフェイルオーバー前進）
- 出典: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## GitHub Copilot — VS Code の Browser tools GA、CLI に自動モデル選択と kimi-k2.7-code

- **Browser tools for GitHub Copilot in VS Code が GA（7/1）** — エージェントが実ブラウザを操作し、ライブ Web アプリを操作・巡回して結果をチャットに反映。Claude Code の Claude in Chrome GA と同日で、主要コーディングエージェントのブラウザ操作対応が一斉に本格化
- **Copilot CLI に自動モデル選択（7/1）** — 稼働率・モデル健全性・タスク特性（推論/コード生成の複雑さ/バグ診断難度/ツールオーケストレーション需要）から最適モデルへルーティング
- **CLI 安定版 v1.0.68（7/1）※新規** — **kimi-k2.7-code モデル対応**、slash コマンドのエイリアス表示改善、切断中の IDE ツール可用性、サブディレクトリからの git 操作改善。**pre-release v1.0.69-0（7/2）** で `/sandbox` パス補完・大規模モノレポの tgrep メモリ改善
- 出典: [GitHub Changelog](https://github.blog/changelog/label/copilot/) / [GitHub releases](https://github.com/github/copilot-cli/releases)

## Devin — Security Swarm を提供開始（7/1）、脆弱性バックログ狙いの新プロダクト

- **Devin Security Swarm 発表** — セキュリティチーム向けに、脆弱性の発見・実行時での実証（validate at runtime）・低コスト修正を担う。実世界 50 件のベンチで **36 件を検出（テスト対象 AI スキャナ中最多）**、検出あたりコストは次点比 30% 低いと主張
- 併せてエンタープライズ機能（ACU 可視性制御、MCP レジストリの allowlist 強制、ビルドのピン留め・ロールバック、企業レベル secret 共有）を追加。classic 環境設定は 6/30 廃止済みで declarative blueprints へ移行（read-only 参照は 7/31 まで）
- 出典: [Devin Docs Release Notes](https://docs.devin.ai/release-notes/overview) / [Cognition（Security Swarm）](https://www.prnewswire.com/news-releases/cognition-launches-devin-security-swarm-to-tackle-the-vulnerability-backlog-302814800.html)
