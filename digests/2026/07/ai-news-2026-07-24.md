# AI News Digest — 2026-07-24

## コーディングエージェント / 開発ツール

- **Anthropic「Claude Security」プラグインを Claude Code に beta 提供（7/22、7/23 アクセス拡大）** — ターミナルから、コミット前の変更差分スキャンやリポジトリ全体の深掘りセキュリティレビューを実行できるマルチエージェント型の脆弱性スキャナ。複数ファイルにまたがるデータフローを追跡し、インジェクション・認証バイパス・メモリ破損・ロジック欠陥など重大な脆弱性を、パターンマッチ型ツールが見落とす複合的なパターンごと検出する。各指摘は独立の敵対的検証パス（Claude が自らの結果に反証を試みる）を通してから提示。既に契約している Claude 推論をそのまま使う。全 Claude Code ユーザー向け beta（有料プラン＋Claude Code v2.1.154 以降・`/config` で dynamic workflows 有効化が必要）。
  https://claude.com/product/claude-security

- **Claude Code v2.1.218（7/22）** — `/code-review` をバックグラウンドのサブエージェントとして実行するよう変更。テキスト削除時のスクリーンリーダー読み上げ、`claude mcp list` / `/mcp` に HTTP ステータス・エラーテキスト表示を追加。修正は、Windows で `\u` 始まりのパスセグメントが CJK 文字に化ける問題、左矢印がアンドゥなしに会話を破棄する問題、`/ultrareview` が説明的な引数で失敗する問題、IDE 選択がマルチバイト絵文字の途中で切れると文字化けする問題など。既報 v2.1.217（7/21 絵文字ショートコード補完・サブエージェント同時実行上限 既定 20）。
  https://code.claude.com/docs/en/changelog

- **GitHub Copilot CLI v1.0.74-4 pre-release（7/23）** — Open Plugin Spec v1 マニフェストと `mcp.json` 設定のサポートを追加。サブエージェントのタイムラインで、プロンプトがメインエージェント由来か別のサブエージェント由来かを識別表示。CLI が MCP サーバを再読み込み・ディレクトリ変更した際に確実に再接続するよう IDE 連携の安定性を改善。既報 v1.0.74-1（7/22 サンドボックス オプトイン スプラッシュ・Gemini 3.6 Flash サポート・セッション多重化のダイアログ漏れ修正）。安定版は v1.0.73（7/20）据え置き。
  https://github.com/github/copilot-cli/releases

- **OpenAI Codex CLI 0.146.0-alpha.4 進行中（7/23）** — 安定版は 0.145.0（7/21）据え置き。0.146.0 に向けた alpha ビルド（alpha.1〜.4）が日次で刻まれているが、公開リリースノートに具体的な変更記載はなく、0.145.0（ページネーション付きスレッド履歴・Cursor/Claude Code 設定インポート・Bedrock ログイン・音声入力・マルチエージェント V2）からの漸進ビルドの段階。
