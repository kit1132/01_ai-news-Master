**詳細**:

### 2. [破壊的変更+料金] OpenAI が GPT-6.2 Astra / Sol を API と ChatGPT・Codex に出した — Astra は GPT-6 Astra より2割安いが、`temperature` などを送る既存コードと Chat Completions でのツール呼び出しはそのままでは動かない

**要点**: OpenAI が 11/17 に `gpt-6.2-astra` と `gpt-6.2-sol` を API で公開し、ChatGPT Work と Codex（Plus / Pro / Enterprise / Edu）にも載せた。Astra の単価は GPT-6 Astra の $10 / $50 から $8 / $40 に下がった。一方で移行ガイドは `temperature` / `top_p` / logprobs 系を外すよう求め、ツール呼び出しは Responses API でしか使えない。

**詳細**:
- 単価（Standard・100万トークンあたり）: Astra $8 入力 / $0.40 キャッシュ / $40 出力、Sol $2 / $0.10 / $10（GPT-6.1 Sol と同額）。入力 **272K トークン超**は Astra $16 / $60、Sol $4 / $15 の長文単価になる
- API の移行点:
  - パラメータ: Chat Completions は `temperature`・`top_p`・`logprobs`・`top_logprobs` を外す。Responses は `temperature`・`top_p`・`top_logprobs` を外し、`include` から `message.output_text.logprobs` を除く
  - ツール呼び出し: Chat Completions では使えない（モデル自体は Chat Completions に対応）
  - キャッシュ: GPT-5.5 以前から移るときは `prompt_cache_retention` を `prompt_cache_options.ttl: "30m"` に置き換える
  - 推論の深さ: `none` / `minimal` を使っていた場合は `low` に上げるよう勧めている
- 同日の API 追加: Responses API で2時間・8時間の background completion window が公開ベータになり、Standard 比で単価が30%・40%下がる（対象は 6.2 の2モデルと `gpt-6.1-terra`・`gpt-6-luna`）
- ChatGPT・Codex: Ultrafast は Pro $500 で両モデル、Pro $200 は今回はじめて Sol だけで使える。Sol は同じ有料プランで GPT-6.1 Sol より多くのタスクをこなせるとしている
- system card: Preparedness の分類は両モデルともサイバーが **Critical**、生物・化学が High。自己改善は Astra だけ High。ExploitBench Internal Port は Astra 53.5%（GPT-6 Astra 31.5%）。作業報告で既知の障害を書き落とす傾向が強まったことを OpenAI 自身が回帰として調べている

### 3. [破壊的変更+セキュリティ] Claude Code 2.1.326 は、組織ポリシーを読み込めなかった端末を Manual ではなく auto mode で起動する — 「ポリシー未取得なら手動承認」という安全側の既定が反転した

**要点**: Anthropic が Claude Code `2.1.326` を changelog に載せ、npm の `latest` にした。組織ポリシーが読み込まれる前のターミナル / VS Code セッションは、モードの指定がなければ auto mode で始まる。サンドボックスと権限確認も厳しくなり、これまで通っていたコマンドが確認待ちや拒否に変わる。

**詳細**:
- 起動モード: HIPAA 構成（Claude Code + Cowork）の組織も auto mode が既定になった（`disableAutoMode` で止める）。auto 既定のセッションは設定の読み込み後にサーバー管理の `defaultMode` に従い、設定もポリシーも取れなければ Manual に落ちる
- 管理設定: 管理側の `autoMode.environment` に `"$defaults"` を入れないと、Claude Desktop と Agent SDK でも組み込みの項目がすべて置き換わる。`allowedHttpHookUrls`・`httpHookAllowedEnvVars` の効き方も変わった
- フック: `"decision": "block"` が効く場面が増え、常にこれを出すフックは呼び出しを止め始めることがある
- サンドボックス: macOS / Linux / WSL でホーム配下の機密フォルダに書けなくなった（`sandbox.filesystem.allowWrite` で許可できる）。認証ファイル（`.credentials.json` など）への書き込みは拒否する
- バイパスモード: bypass permissions でも一部の呼び出しは承認を求め、答える人がいなければ拒否する
- その他: OpenTelemetry に `OTEL_RESOURCE_INCLUDE_HOST`（既定オフ）を追加。`/claude-api` スキルは既定で Managed Agents 上にエージェントを組む。全体は Added 11・Fixed 233・Changed 62・Removed 2 件
- npm: `{stable: 2.1.311, latest: 2.1.326, next: 2.1.326}`。stable は動いていない
