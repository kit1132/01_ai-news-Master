## 今日のハイライト

### 1. [新機能] Messages API に message threads（beta） — 長い会話でも毎回全文を送り直さなくてよくなった

**要点**: Anthropic が Messages API に、会話をサーバー側に保持して新しいメッセージだけを送る message threads を beta で追加した。Claude Code の大半のユーザーでは既に既定で有効になっている。ステートレスな API に全文を毎回送る前提が崩れた。一方、ZDR の対象外である。

**詳細**:
- beta ヘッダは `message-threads-2026-08-12`。初回で会話全体を送ってスレッドを作り、以後は新しいメッセージと前回応答の ID だけを送る
- スレッドは最後のリクエストから5分で失効し、最後の利用から1時間以内に削除される。中身は暗号化してメモリに置き、ディスクには書かない
- 課金と rate limit は従来どおりで、トークン使用量も減らない（Claude は毎ターン会話全体を読む）。トップレベルの `cache_control` でプロンプトキャッシュと併用できる
- Anthropic によると、50万〜100万トークンのリクエストで TTFT の中央値が約35%下がった
- 提供先: Claude API、Claude Platform on AWS、Claude Models on Google Cloud（Anthropic managed）、Microsoft Foundry。対応モデルは Fable 5.1 / Mythos 5.1 から `claude-sonnet-4-5-20250929` まで17本
- ⚠️ docs の ZDR 区分は **not-eligible**。ZDR 契約の組織がこの機能を使っても、他の ZDR 対象機能の扱いは変わらない
