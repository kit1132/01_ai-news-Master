## 今日のハイライト

### 1. [新機能] Claude の computer use が Team / Enterprise で beta になった — 組織でも画面操作を任せられるが、既定はオフで、有効化は Owner がアプリ単位の許可リストとあわせて決める

**要点**: Anthropic が 11/20、Claude Desktop の computer use を Team / Enterprise プランで beta にした（組織ごとに段階展開）。これまで Pro / Max / Ultra 限定だった機能を、管理者が有効化すれば組織の利用者も使える。サンドボックスは無く、HIPAA 対応・ZDR・顧客管理鍵の組織では有効にできない。

**詳細**:
- 有効化: Owner / Primary Owner が Organization settings > Capabilities の Claude Desktop で **Computer use** をオンにする。先に「Chat and Cowork unified」がオンである必要がある。Enterprise はロールで絞れ、Team は全員に一律で効く
- アプリ制御: 「Block these apps」（拒否リスト）か「Allow only these apps」（許可リスト）。Mac は bundle ID、Windows は実行ファイル名か AUMID で指定し、入力した ID は検証されない。許可リスト運用中は最新でない Claude Desktop の利用者は使えない
- 対応: macOS 14 以降（Accessibility と Screen Recording の権限。MDM の PPPC プロファイルで事前付与できる）と Windows。Web / モバイルからも、Claude Desktop を動かすコンピューターをつなげば使える
- 有効化できない構成: HIPAA-ready、Claude Code の Zero Data Retention、顧客管理の暗号鍵、FERPA / K-12。別の Cowork タスクと Claude Code では動かない
- 制約: スクリーンショットはチャットに保存され、操作レビューの記録として Anthropic が写しを持つことがある。アプリ一覧は Chrome 拡張・Web サイト・リモートデスクトップには効かない。変更が利用者に届くまで約1時間かかる。端末単位の停止は MDM キー `computerUseEnabled: false`（Claude Desktop 5.1231.0 以降）

- https://support.claude.com/en/articles/18483812-set-up-computer-use-for-team-and-enterprise-plans

### 2. [破壊的変更+新機能] Claude Code 2.1.329 は以前の版で保存した予約タスクを再登録させ、`max_tokens` 上限での自動再試行を取り下げた — ゲートウェイ経由の運用では出力上限の環境変数を自分で決める必要がある

**要点**: Anthropic が Claude Code `2.1.329`（11/20）で、以前の版が保存した予約タスクの多くを新しいサインイン済みセッションで再登録が必要にし、2.1.326 で入れた `max_tokens` エラー時の自動再試行を外した。管理設定まわりでは、管理フックの読み込み失敗を会話内で警告するようになった。

**詳細**:
- 何もしないと変わるもの:
  - 予約タスク: 以前の版で保存したものは多くが再登録になる（自分のセッションを `--resume` すれば動く）。「Exit and stop tasks」は予約タスクも終了させる
  - 出力上限: 出力トークンの少ないモデルを返すゲートウェイの背後では、`CLAUDE_CODE_MAX_OUTPUT_TOKENS` をその上限に設定する
  - Code Mode: テレメトリや feature flag をオフにしていても起動する（止めるのは管理設定）。一部のツールだけを並べた mod では止まらなくなった。エラーを出した PreToolUse フックはスクリプトのツール呼び出しを拒否しない（拒否させるには `"onFailure": "block"`）
  - `/code-review`: 対象未指定ならブランチ全体を既定ブランチと比べる。PR 番号指定は `gh pr diff` で PR を読み、取れなければ止まる
  - auto mode: `git status` の実行を減らし、変更を捨てる git コマンドは作業ツリーを確かめるまで止めることがある
- 追加: フォルダーのフックの宣言場所を示す信頼ダイアログの警告、管理設定のフックが読み込めないときの会話内の警告（Claude Desktop など非対話ホスト）、`/status` の「Marketplace auto-update」行（自動更新されない管理マーケットプレイスと理由）、`/mcp` の「Server message」行、OpenTelemetry 有効時の Code Mode
- 修正: ネットワーク停止やファイルロックで `~/.claude.json` が既定に戻ることがある不具合、macOS で Keychain に書けない場合のサインアウトの繰り返し
- npm: `{stable: 2.1.311, latest: 2.1.329, next: 2.1.329}`。stable は据え置き

出典:
- https://code.claude.com/docs/en/changelog
- https://registry.npmjs.org/@anthropic-ai/claude-code
