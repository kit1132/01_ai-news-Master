### 1. [破壊的変更+新機能] Claude Code 2.1.318 — `deniedMcpServers` の URL 指定が Anthropic 提供のコネクタまで止めるようになり、IDE 拡張の自動導入が終わった

**要点**: Anthropic が Claude Code `2.1.318` を 11/3 に出した。管理設定 `deniedMcpServers` の URL エントリが、上流 URL の一致する Anthropic 提供サーバーとクラウド / self-hosted runner のコネクタにも効くようになった。URL で書いた拒否リストが、これまで素通りしていたコネクタも止める前提に変わった。IDE のターミナルで起動しても拡張は入らなくなった。

**詳細**:
- 拒否の範囲: URL エントリはコネクタ自身の URL を渡されるクラウドセッションと self-hosted runner でも一致判定する。それ以外の環境でコネクタを止めるには名前で拒否する
- IDE 拡張: IDE 内のターミナルから起動しても、拡張のインストール・更新をしない。外部ターミナルの `/ide` か、エディタの拡張ビューから入れる
- サインイン期限: `claude auth status` に `loginExpiresAt`、`claude -p` の JSON 結果に `credential_expires_at` が加わった。`claude -p` のテキスト出力は、保存した claude.ai サインインの期限10日前から stderr に1行警告を出す
- gateway: `mantle` upstream に `assume_role` が加わり、別 AWS アカウントのロールを使える。開発者ごとの AWS 費用の按分にも使える
- 挙動の変更:
  - subagent: 「Switch models when a message is flagged」が「Ask each time」のとき、モデルを切り替えずに止まる
  - background subagent: シェルコマンドを3分でバックグラウンドへ移す動作が全プロバイダに広がった（プロンプトキャッシュの失効防止）
  - Managed Agents: `/claude-api managed-agents-onboard` が新しいエージェントの組み込みツールに `auto` 権限ポリシー（Judge risky actions）を既定で付ける
- self-hosted runner: orchestrator のログで `nack session=…` の末尾に `reason=…` が付く。`retryable=true:` / `retryable=false:` に一致させているスクリプトは直す必要がある
- npm は `{stable: 2.1.311, latest: 2.1.318, next: 2.1.318}`

出典:
- https://code.claude.com/docs/en/changelog
- https://registry.npmjs.org/@anthropic-ai/claude-code
