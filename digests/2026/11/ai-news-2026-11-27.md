## 今日のハイライト

### 1. [料金+破壊的変更] GitHub が Copilot code review の課金先の既定を 12/30 から組織に変える — 何も選ばないと、メンバーの Copilot 枠で賄っていたレビューが組織の AI Credits 従量課金に乗る

**要点**: GitHub が 11/25、Copilot Business / Enterprise で課金先が未設定のとき、ライセンスを持つメンバーの code review を 12/30 から「メンバーの Copilot 枠」ではなく「リポジトリを所有する組織」へ請求すると告知した。従来どおりにするには、期限までに管理者が **Member** を保存する必要がある。

**詳細**:
- 今の既定: 選択を保存していなければ、メンバー自身の Copilot の利用枠を使う。設定画面には期限まで **Default (Member)** と変更の告知が出る
- 12/30 以降の既定: リポジトリを所有する組織に請求する。組織側は AI Credits の従量課金が前提で、支出が増えうる
- 例外: AI Credits の従量課金が無効・請求ロック中・請求先が無いアカウントは Member に設定される。すでに Member / Organization を保存した組織はその選択が残る
- ライセンスの無いメンバー向けの別設定は変わらない。Enterprise が管理している場合は Enterprise オーナーが選ぶ
- 単価はページに書かれていない

出典:
- https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization

### 2. [破壊的変更+新機能] Stably AI が Orca `v1.4.278` で Gemini CLI の対応を外した — Antigravity のチャットは全て `agy` で動くようになり、新しい bot の既定エージェントも Claude 固定ではなくなった

**要点**: Stably AI が 11/26 に Orca `v1.4.277` と `v1.4.278` を続けて出した。`v1.4.278` で Gemini CLI の対応を削除し、Google 系のエージェントは Orca 内でサインインできる Antigravity の `agy` に一本化した。Gemini CLI を Orca から使っていた環境は Antigravity へ移す必要がある。

**詳細**:
- `v1.4.278`（11/26・Latest）:
  - エージェント: Antigravity のチャットは全て `agy` で動く。Gemini CLI は削除。新しい bot は常に Claude ではなく既定のエージェントで始まる
  - 表示: Claude と Codex の長い返答を滑らかにストリーミングし、サブエージェントはチャット上のシートで開く
  - 連携: ClickUp / Airtable / Todoist / Zapier / Granola / Intercom をワンクリックで接続できる
  - その他: サーバー側ワークスペースのファイルを手元に保存できる。New bot の選択から WSL ディストリビューションを足せる（実験的）
- `v1.4.277`（11/26）:
  - Antigravity: インストール済みプラグインのスキルが最初のメッセージ前から `/` メニューに出る。`agy` ターミナルに「Approve for me」
  - Claude: 位置引数のプロンプトの扱いと、再開したチャットの開始を直した
  - Codex: Windows でチャットごとにサーバーを持ち Stop が正しく効く。スロットリングで偽の利用上限が出なくなった
  - Google アカウントをエージェントごとに選べる

出典:
- https://github.com/stablyai/orca/releases
