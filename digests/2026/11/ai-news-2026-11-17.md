## 今日のハイライト

### 1. [セキュリティ+予定] Anthropic が脆弱性の開示期限を 90日から30日に縮める — 修正は人の速さで進み、同じバグはまず再発見されない、という CVD の前提を Anthropic 自身が捨てた（2027-01-01 以降の報告から適用）

**要点**: Anthropic が 11/16 に、自社が見つけた脆弱性をベンダーやメンテナに報告してから公開するまでの期限を、高・重大度で90日から30日に縮めると公表した。AI が同じバグを短期間で再発見できるため、90日の非公開期間はもう安全ではないという判断である。2027-01-01 以降に報告する分から適用する。

**詳細**:
- 高・重大度: 開示期限が 90日 → **30日**。その他の脆弱性は45日
- 無応答時のエスカレーション: メンテナが初回報告に応答しない場合、外部コーディネーターへ回すまでの目標が 30日 → 15日
- 技術詳細の公開: パッチ提供後に詳細を出すまでの待機が 45日 → 30日
- 据え置き・例外: 悪用が確認済みの脆弱性の7日期限は変えない。2027-01-01 時点で対応中の報告は旧期限のまま。重要インフラや仕様・RFC の変更が要るものは個別に日程を調整する。人のレビューを経ていない AI の発見（OSS Scanner など）は対象外
- 期限切れの未公開分: 90日を過ぎた高・重大度の脆弱性は、メンテナに30日を追加で与えたあとダッシュボードで公開する
- 支援策: OSS Scanner（主要 OSS を最上位モデルで定期スキャンし結果を送る無償サービス）、Claude for Open Source Program（資格のあるメンテナに Claude Ultra を6か月無償）、Cyber Verification Program を案内している

出典:
- https://www.anthropic.com/research/coordinated-vulnerability-disclosure-timelines

### 2. [破壊的変更+新機能] Orca 1.4.261 がチャットの保存先を SQLite に移し、Android アプリを別パッケージに分けた — Android は上書き更新できず再インストールが要る形に変わった

**要点**: Stably AI が 11/16 に Orca `v1.4.261` を出した。チャットの保存先が SQLite に移り、旧 Android アプリは新しいパッケージ `dev.orca.app` に更新できないので入れ直しが要る。完了したエージェントの表示を保持する設定は削除され、プロセスの終了や SSH の切断で一覧から消えるようになった。

**詳細**:
- 互換性: 元のチャットファイルは本版では消さない。ダウングレードして再アップグレードすると、旧版で続けた会話が新旧2つ並ぶことがある。メモリ節約で解放したブラウザページは再読み込みされ、スクロール位置がリセットされうる（未保存の編集があるページは解放しない）
- Claude / Codex: どちらもチャットから `/mcp` で MCP サーバーを管理できる。Claude は steer で作業を中断しても同じターンに残り、Stop フックが失敗しても回答を消さない。Codex は `/new` で新しい会話を始め、goal 実行中は完了通知を保留する。利用量画面は Codex の個人支出上限を月次枠として表示する
- 対応エージェント: Cursor が ACP サーバー経由でチャットに対応した。Pi は起動時に `--model` / `--effort` を受け付け、Antigravity は Windows でチャットを使える
- 版番号: `v1.4.260` は出ておらず、比較は `v1.4.259...v1.4.261`

出典:
- https://github.com/stablyai/orca/releases/tag/v1.4.261
