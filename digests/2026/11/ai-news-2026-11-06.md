## 今日のハイライト

### 1. [新機能] Claude Enterprise にセキュリティセンターと inference hooks の GA が来た — IP 許可リストとメンバーの強制サインアウトを管理者が自分で操作できるようになった

**要点**: Anthropic が 11/5、Claude Enterprise にセキュリティ・管理機能をまとめて追加した。DLP 連携の inference hooks は GA、セキュリティセンターと親組織の一括管理は beta である。IP 許可リストは Anthropic への依頼が要る設定から、Console と Admin API で管理者が自分で操作する設定に変わった。

**詳細**:
- セキュリティセンター（beta）: chat / Cowork / Claude Code の設定を1ページで推奨構成と比べ、現在値・推奨値・設定へのリンクを並べる。監査向けのレポートを出力でき、Compliance API からも同じ結果を読める。認証や法令準拠の保証ではないと明記している
- inference hooks（GA）: プロンプトを送る前の prompt hooks と、ツール呼び出しを実行する前の pre-tool-call hooks の2種。既存の DLP・セキュリティ製品のポリシーをそのまま当てる
- 一括管理（beta）: 親組織の管理コンソール `admin.claude.com` で、SSO / SCIM / ドメイン検証 / グループ / Compliance API キーを配下の組織に一括で設定する。IdP は複数つなげる。⚠️ 設定を始めると元に戻せない。親で作った Compliance API キーは組織をまたいでデータを読める
- アクセス制御（beta）:
  - IP 許可リスト: Claude Console で IPv4 / IPv6 アドレスと CIDR を組織あたり1,000件まで登録できる。許可外のアドレスからのリクエストは拒否され、漏れた API キーを使える場所が限られる
  - 強制サインアウト: `POST /v1/organizations/users/{user_id}/sign_out`（beta ヘッダー `admin-user-sign-out-2026-10-08`）で、メンバーの全デバイスのセッションと組織の OAuth トークンを無効にする。API キー、実行中のクラウドセッション、スケジュール済みの routine は止まらない
  - Claude Desktop: 管理対象の端末で個人アカウントなど組織外の Claude アカウントを止められ、よく使う Desktop 設定を MDM なしで配れる
- EDR（beta）: Cowork と統合版 Claude のローカル VM の中で組織の EDR センサーを動かす。検知のみでブロックはしない。macOS / Windows で、Team / Enterprise と Bedrock / Vertex AI / Foundry 経由の Desktop が対象

出典:

- https://support.claude.com/en/articles/12138966-release-notes

### 2. [セキュリティ+料金] OpenAI が GPT-6-Cyber を API で提供した — サイバーで Critical 判定のモデルが、Daybreak Red の審査と IP 許可リストを条件に $20 / $100 で使えるようになった

**要点**: OpenAI が 11/5、GPT-6 Astra をセキュリティ用途向けに後学習した `gpt-6-cyber` を API に出した。9月から報じられていた限定テストが、価格つきの正式なモデルになった。Preparedness の判定は Astra と同じサイバー Critical で、使えるのは Daybreak Red で承認された組織だけである。

**詳細**:
- 用途: 脆弱性の調査、承認済みテスト環境での再現、修正の確認。強化学習でクラッシュの再現・exploit の作成・コードベースの脆弱性探索を学習し、承認されたセキュリティ作業での拒否を減らした
- 判定: サイバー Critical、生物・化学 High、AI 自己改善は High 未満（GPT-6 Astra と同じ）。GPT-5.6 Cyber より能力とアライメントがともに上がったとしている
- 利用条件: 本人確認、利用制限、SSO・多要素認証・API の IP 許可リストなどの組織要件。Zero Data Retention の API 顧客は、原則として Private Safety Processing による自動の安全審査が要る
- 料金: 入力 $20.00 / 出力 $100.00（100万トークンあたり）、キャッシュ入力 $2.00。料金ページで同じ表に載る `gpt-5.6-sol` は $4.00 / $20.00
- 入出力: テキストと画像の入力、テキスト出力
