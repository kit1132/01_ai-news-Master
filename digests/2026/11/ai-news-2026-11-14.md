### 1. [破壊的変更+新機能] Claude Code 2.1.323 が v1 の MCP クライアントを削除し、知らないモデル ID の前提を 200K から 1M に変えた — 組織のプロキシ設定やサンドボックス内の git 操作が、更新しただけで通らなくなることがある

**要点**: Anthropic が 11/12 に Claude Code 2.1.323 を出した。Claude が JavaScript を書いてツールを呼ぶ実験機能 Code Mode を追加したほか、v1 の MCP クライアントを削除し、組織設定の取得で `ALL_PROXY` を使わなくなった。サンドボックス内の `git worktree` 操作も読み取り専用で失敗する。更新すれば挙動が変わる前提で設定を見直す版になった。

**詳細**:
- 新機能: Code Mode（オプトイン。組織単位で止める方法も docs にある）。`plugin.json` の `engines["claude-code"]` で対応版の範囲を書けるようになり、範囲外の版にはプラグインを入れない。管理設定で Claude Desktop のサードパーティ経由セッション向けに `CLAUDE_CODE_AUTO_MODE_MODEL` を置ける
- 破壊的変更:
  - MCP: v1 クライアントを削除した。`MCP_SDK_GENERATION=v1` は v2 クライアントの互換モードで動く
  - コンテキスト: 知らないモデル ID は 1M と見なす。窓の小さい他社モデルは満杯後に毎ターン失敗しうるので、`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で 200K に戻す
  - プロキシ: 組織設定とポリシーの取得は `ALL_PROXY` だけでは通らない。`HTTPS_PROXY` が要る
  - サンドボックス: `git worktree add` / `move` / `remove` と、セッション外の worktree へのコミットが読み取り専用で失敗する。シンボリックリンク経由の書き込み許可も無視する
  - 削除: `subagentStatusLine` 設定（キーが残っていても読み込みは通る）。プラグインの `agent` 設定は deprecated
- 権限: `/security-review` は実行前に確認を取る。MCP のサインイン完了は auto / bypass モードでも確認を取る。秘密を含みそうな許可ルールは「今後確認しない」を選んでもそのセッション限りになる
- 版: changelog の 1版で変更が約300行。npm は `{stable: 2.1.311, latest: 2.1.323, next: 2.1.324}`。`2.1.324`（11/13）は changelog にまだ無い

出典:

- https://registry.npmjs.org/@anthropic-ai/claude-code

### 2. [新機能] Anthropic が Claude を Google Meet の通話に参加させる Claude Meetings を Team / Enterprise 向けにベータで出した — 議事録づくりだけでなく、通話中にコネクタを使った作業まで Claude に頼めるようになった

**要点**: Anthropic が 11/12、Claude を参加者として Google Meet の通話に入れる Claude Meetings を Team / Enterprise でベータ展開し始めた。通話中の質問に答え、ドキュメントやホワイトボードを作り、議事録と次の作業を残す。ZDR・HIPAA 構成・CMEK の組織はベータ中は使えない。

**詳細**:
- 対応: Google Meet のみ（ほかの会議ツールは今後）。Claude と Claude Desktop から使う
- 保存: 会議ごとのページにメモ・文字起こし・要約・画面の説明・作成物を残す。音声は保存しない。外部ゲストの発言も文字起こしに入る
- 管理: Team は既定でオン（管理者が止められる）。Enterprise は管理者が全体または一部で有効にする。外部の招待者がいる通話には既定で入らず、途中で外部の人が来たら退出する（管理者が許可を変えられる）
- 料金（ベータ中）: 議事録・文字起こし・通話中の回答は無料。コネクタを使う回答はプランの利用量に数える。成果物は **2027-02-10** まで無料

出典:
- https://claude.com/resources/articles/claude-meetings
- https://support.claude.com/en/articles/12138966-release-notes
