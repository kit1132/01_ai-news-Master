## 今日のハイライト

### 1. [新機能] Anthropic が Claude Managed Agents を自社環境で丸ごと動かせる self-hosted 版を private beta で出した — サンドボックスだけでなくサーバーとセッション履歴も社外に出さずに済むようになった

**要点**: Anthropic が 11/12、Managed Agents のサービス全体（サーバー・データベース・ワーカー）を自社クラウドやオンプレミスで動かせる self-hosted 版を private beta で公開した。これまで自社に置けたのはサンドボックスだけで、エージェント定義とセッション履歴は Anthropic 側にあった。モデルへの送信先も Anthropic 直・Bedrock・Google の Agent Platform・Microsoft Foundry・自社ゲートウェイから選べる。

**詳細**:
- 提供: private beta。申し込みは Anthropic のアカウントチーム経由。対象プランと料金は記事に書かれていない
- 自社に置くもの: Managed Agents サーバー、そのデータベース（エージェント・セッション・セッション履歴）、シェルやファイル操作をするワーカー
- 送信先: 既定は Anthropic。ZDR 契約がある組織では、通常の Messages API 呼び出しと同じく ZDR が適用される
- セキュリティ: ハーネスとサンドボックスを分け、認証情報はサンドボックス外のプロキシで付与する（自社のシークレットマネージャーも使える）。許可ホスト以外への通信を止められ、全ステップを OpenTelemetry で出力できる
- 数値の上限（同時セッション数・保存容量など）は書かれていない

出典:
- https://platform.claude.com/docs/en/release-notes/overview#self-hosted-managed-agents
- https://claude.com/resources/articles/self-hosted-claude-managed-agents
