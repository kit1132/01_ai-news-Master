### 2. [料金+新機能] Google が Gemini Decisions API を出し、選択肢を確率つきで採点する `gemini-decision-1` を入力 $0.10 / 100万トークン・出力無料で提供した — 型付き判断の API が OpenAI・TypeSafe に続き Google にも並んだ

**要点**: Google が 11/11、文章を生成せず候補を1回の forward pass で採点し、確率と confidence を返す Gemini Decisions API を Google AI Studio で公開した。単価は OpenAI の Decisions API（`gpt-6-luna`）と同じ入力 $0.10・出力 $0 で、画像・音声・動画・PDF も入力にできる。ツール選択やルーティングの前段判定を、3社の同価格帯から選べるようになった。

**詳細**:
- 質問の型: `noul`（Yes / No の確率）、`choice`（2〜255 個の選択肢から勝者と各確率）、`score`（順序つきルーブリックの加重スコアと各段階の確率）
- 上限: 入力 256K トークン、1リクエスト最大 1,000 問。共通の入力は問数にかかわらず1回だけ課金する
- レイテンシ: エンドツーエンド 150〜250ms（モデル計算の中央値 50〜100ms）。1〜100 問でほぼ一定（16K トークンまでで計測）
- 料金: 思考トークン・音声の文字起こし・OCR の別料金は無い。Gemini 3.5 Flash-Lite で同じ判定をするより約5分の1のコストと Google は書いている
- 提供: Gemini API（Google AI Studio、無料枠あり）。Google Cloud の Gemini は「近日」。preview / GA の別とレート制限は記事に書かれていない

出典:
- https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/

- [予定] MCP の File Uploads Working Group が、ファイルの受け渡しを扱う拡張 `io.modelcontextprotocol/files` の草案を出した（11/10）。2026-07-28 版以降が対象で、年内に安定版にする予定。参照実装はまだ無く、対応は任意
  - アップロード: クライアントはメタデータだけで `tools/call` を送り、サーバーが `upload_required` を返したら HTTPS の `PUT` で直接送ってから同じ呼び出しを再送する
