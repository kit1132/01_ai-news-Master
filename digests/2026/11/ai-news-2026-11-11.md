### 1. [破壊的変更+セキュリティ] Anthropic が Claude Code 2.1.321 で Fable 5.2 を既定にし、MCP OAuth の秘密情報の漏れとサンドボックスの抜け道を直した — 更新すると保存済みの Fable 5.1 の選択が 5.2 へ移り、管理設定の効き方も一部変わる

**要点**: Anthropic が Claude Code `2.1.321` で Fable 5.2 を既定の Fable モデルにした。Pro / Max では保存済みの Fable 5.1 の選択がすぐ `fable`（5.2）に移る。同じ版で、MCP OAuth のリフレッシュトークンが別ホストへ送られる不具合と、読み取り専用の Bash が確認なしでサンドボックスの外で動く不具合を直した。管理設定で mods を止めていた組織は、auto / bypass モードで mods が自動でオンになる点を見直す必要がある。

**詳細**:
- 版: changelog の最上位が `2.1.319` から `2.1.322` に進んだ（`2.1.320` は欠番）。npm は `{stable: 2.1.311, latest: 2.1.322, next: 2.1.322}` で、stable は動いていない
- モデル: Fable 5.2（`claude-fable-5-2`、1M コンテキスト、$8 / $40、キャッシュ読取 $0.20）を追加し、既定の Fable にした。Team / Enterprise では組織が許可したときに 5.1 の選択が移る。戻すときは `/model claude-fable-5-1`
- セキュリティ修正:
  - MCP OAuth: サーバーがリダイレクトしたとき、リフレッシュトークンなどの秘密情報を別ホストへ送っていた
  - サンドボックス: 読み取り専用の Bash コマンドが、確認なしでサンドボックスの外で動くことがあった
  - 権限: `cp` / `mv` でディレクトリへ書き込むファイルに、deny ルールと保護ファイルの確認が効いていなかった。`/bin/cp` のようにパスで書いた `cp` / `mv` も同じ確認にかけるよう変えた
- 管理設定・組織ポリシーに関わる変更:
  - mods: Claude が書く mods は、auto / bypass モードでは確認なしでオンになる。managed の `allowUnsandboxedCommands: false` や `allowManagedDomainsOnly` があっても同じ。`dontAsk` モードでは読み込まない。mods 自身のツール呼び出しは確認を出さない（deny ルールと組織ポリシーは効く）
  - managed `extraKnownMarketplaces`: 宣言した名前を別のソースから足せなくなり、宣言したマーケットプレイスが載せるプラグインはそこから入れ直す
  - Claude apps gateway: `policy_mode: layered` では、条件に合うすべてのポリシーの managed MCP サーバーを足し合わせる。更新後は配られるサーバーが増えうる。Bedrock / Vertex / Foundry の上流は `ANTHROPIC_*_BASE_URL` を無視するようになり、別のエンドポイントは `base_url` で指定する
  - Claude in Chrome: Claude Desktop の Code タブなどが渡すツールにも、組織の Claude in Chrome ポリシーが掛かる
- その他: `claude remote-control --settings <file>` を追加。Remote Control のセッションは開始したフォルダーから動かせなくなった
- `2.1.322`: Vertex の global / us / eu リージョンで fast mode を使えるようにした。Vertex が断ると標準速度へ戻る

出典:
- https://code.claude.com/docs/en/changelog

### 2. [新機能+予定] GitHub が Copilot で Claude Fable 5.2 を GA にした — Business / Enterprise は既定オフのポリシーを入れると Anthropic のデータ保持に同意したことになり、ZDR の例外は年末で終わる

**要点**: GitHub が 11/9、Copilot Pro+ / Max / Business / Enterprise で Fable 5.2 を使えるようにした。Business / Enterprise では管理者がポリシーを入れるまで使えず、入れると Anthropic がプロンプトと出力を保持することに同意したことになる。審査を通った企業は ZDR で使えるが、その例外は 2026 年末までで、以後は Enterprise Frontier Safeguards（EFS）が必要になる。

**詳細**:
- 使える場所: VS Code・Visual Studio・Copilot CLI・coding agent・Copilot app・github.com・GitHub Mobile・JetBrains・Xcode・Eclipse の model picker。順次展開
- 課金: 従量課金で、プロバイダーの定価で請求する
- データ保持: Fable 5 / 5.1 / 5.2 だけは安全分類器のために Anthropic がデータを保持する（学習には使わない）。他の Claude モデルは ZDR のまま
- ZDR の例外: 審査を通った企業は、Fable 5.2 / 5.1 / 5 を暦年末まで ZDR で使える。資格は GitHub の担当チームに問い合わせる（Support では判定できない）。承認後も管理者がポリシーを入れる必要がある
- 2027 年以降: EFS が必要になる。EFS では自動の安全監視を行い、顧客が管理する保存先と暗号鍵も選べる
- Copilot CLI でも、11/10 の安定版 `v1.0.109` で model picker に Fable 5.2 が入った（下の GitHub Copilot 節）

### 3. [新機能] Anthropic が Claude に Whiteboards・Sheets・Data を加え、パートナーのアプリを会話の横で開けるようにした — Enterprise では Claude Data が 11/19 に既定でオンになる

**要点**: Anthropic が 11/10、有料プランの Claude に、共有ボードの Whiteboards（beta）、表計算の Sheets（beta）、旧 Dashboards の Claude Data（GA）を加えた。あわせて、Notion や Confluence などのアプリを会話の横で開き、Claude がその中を編集できるようにした。Enterprise の管理者は、11/19 に Claude Data が既定でオンになる前に設定を決める必要がある。

**詳細**:
- 3機能（Web・デスクトップ・モバイル、有料プラン）:
  - Whiteboards: チームで共有するボードでブレインストーミングし、担当者と期日つきのタイムラインを作る。Lucid・Miro・Vani by Zoho へ書き出せる
  - Sheets: タブ・数式・書式・ドロップダウンつきの表をプロンプトで作る。変更は差分で示し、共同編集できる。Excel の全機能が要るときは .xlsx / CSV で書き出すか Claude for Excel を使う
  - Claude Data: データコネクタが前提。認定クエリと、接続権限のない人に最新の数値を見せるライブ共有は beta。対応パートナーは Amplitude・Mixpanel・Omni・PostHog・Sigma
- 管理者設定（Organization settings > Artifacts）: Team は3機能とも既定でオン。Enterprise は Whiteboards と Sheets が既定でオフ、Claude Data は 2026-11-19 にオンになる
- アプリの埋め込み: 対応コネクタを会話の横か全画面で開け、Claude がそのページ・行・ファイルを変更できる（実行前に承認する）。全プランで Web とデスクトップに段階展開する
  - 対象例: Asana・Canva・Carta・Dropbox・monday.com・Smartsheet・Vercel・Webflow・Adobe・Atlassian・Box・HubSpot・Notion。Figma・Harvey・Shopify は開発中
  - 基盤は MCP の拡張 MCP Apps（開発者向けにパブリックプレビュー）。管理者は従来どおりコネクタのツールを制限できる
- 料金・利用上限は記事に書かれていない

出典:
- https://claude.com/resources/articles/sheets-whiteboards-data
- https://claude.com/resources/articles/interactive-connectors-full-tool
