### 1. [料金+新機能] Anthropic が Claude Fable 5.2 / Mythos 5.2 を出し、単価を $10/$50 から $8/$40 に下げた — 最上位モデルが安くなったが、5.1 からの移行で400になる変更が4つある

**要点**: Anthropic が 11/9、Claude Fable 5.2（`claude-fable-5-2`）と、検証済み組織だけが使える Mythos 5.2 を出した。単価は入力 $8・出力 $40 / 100万トークンで、5.1 より2割安い。出力は最大30%速い。最上位モデルの試算は引き直しになる。ただし API で5.1から乗り換えると、履歴の編集や旧 computer use ツールが 400 になる。

**詳細**:
- 仕様: 1M コンテキスト（既定かつ最大）、出力 128k、adaptive thinking は常時オン。トークナイザーは Opus 4.7 と同じ。effort は5段階で API の既定は `high`
- 料金（USD / 100万トークン）:
  - 標準: 入力 $8 / 5分キャッシュ書込 $10 / 1時間キャッシュ書込 $16 / キャッシュ読取 $0.20 / 出力 $40
  - Batch: 入力 $4 / 出力 $20
  - fast mode（最大2.5倍速）: 入力 $16 / 出力 $80。Claude API ではベータヘッダーなしで `speed: "fast"`。Claude Code でも使える
  - US 内だけの推論は 1.1倍
- 提供先: Claude API、Claude Platform on AWS、Claude Models on Google Cloud（Anthropic 管理・Google 管理）、Microsoft Foundry。Pro / Max / Ultra / Team / Enterprise で使える。Mythos 5.2 は Cyber / Life Sciences Verification Program の検証済み組織だけ
- 5.1 から API で乗り換えると壊れる4点（what's new ページ）:
  - prefix check: system・tools・過去のメッセージを書き換えて thinking block を送り返すと、アカウントの作成日を問わず 400 になる（Fable 5.1 は 2026-08-31 以降に作ったアカウントだけだった）。Claude Code・claude.ai・Managed Agents・Agent SDK が組むリクエストは影響を受けない
  - thinking block: 5.2 の block は 5.2 と Mythos 5.2 しか読まない。Opus 5.5 や 5.1 へ戻すとその分の推論は落とされる（リクエストは成功する）
  - computer use: `computer_20251124` を宣言すると 400。`computer_toolset_20260801` へ移す
  - advisor tool（beta）: 5.2 の executor は 5.2 か Mythos 5.2 の advisor しか受けない
- 5.1 から変わらず 400 になる2点: `thinking` の `enabled` / `disabled` 指定と、強制 tool use（`tool_choice` の `any` / `tool`）
- データ保持: 2モデルとも30日保持の Covered Models で、ZDR では使えない（Anthropic が明示に認めた場合を除く）。Privacy Center の記事も 11/9 に更新された。発表は、保存プロンプトを顧客の基盤に置いたまま監視する Enterprise Frontier Safeguards（private beta）なら ZDR と両立するとしている
- ベンチマーク（Anthropic 発表）: FrontierCode 2.0 49.1%（5.1 32.4%・Opus 5.5 45.5%・GPT-6 Astra 42.8%）、FrontierSWE v2 69.9%、OSWorld 2.1 89.3%、Humanity's Last Exam（ツールあり）74.2%。High effort で Opus 5.5 の最高点並みを約半分のコストで出したとする
- 安全性: 不要なブロックが 5.1 比で約55%減（サイバー約60%減・生物約40%減）。拒否時の server-side fallback 先は Opus 4.8 と Opus 5
- 退役一覧: 2モデルが Active に加わり 17件になった。暫定退役日はどちらも「Not sooner than November 9, 2027」（確定日ではない）
- ローンチ特典（support 記事）: Pro と Team の標準席は Fable を 11/16 23:59 PT まで週の上限の50%まで含め、リセットが1回付く。Max / Ultra と premium 席は契約期間に応じて1〜3回のリセットが付き、期限は 2027-03-08 23:59 PT。対象は 11/9 10:00 PT までに有料契約があるアカウント

### 2. [破壊的変更+新機能] GitHub が Copilot CLI の安定版 v1.0.108 を出し、JSON 出力とローカル MCP の環境変数の扱いを変えた — 出力を機械で読むスクリプトと MCP 設定が、更新後に動かなくなりうる

**要点**: GitHub が 11/9、Copilot CLI の安定版 `v1.0.108` を出した。`-p --output-format json` の出力にセッションの開始・再開・モデル変更のイベントが加わった。ローカル MCP の環境変数の値は、対話セッションでは書いたまま渡すようになった。イベントの種類が固定だと前提にしたパーサーや、値にホストの環境変数を書いた MCP 設定は、見直しが要る。

**詳細**:
- 挙動が変わるもの（releases 本文。ページ上で本文は途中までしか表示されない）:
  - JSON 出力: `-p --output-format json` にセッションの開始・再開・モデル変更のイベントが入る
  - ローカル MCP: 対話セッションでは環境変数の値を書いたまま渡す。ホストの環境変数は `${NAME}` で参照する
  - SDK: 同じ名前のカスタムツールを2つ渡してセッションを作成・再開・ツール差し替えすると、エラーになる
  - headless resume: 別の Copilot プロセスが使っているセッションを再開しようとするとエラーを返す
  - Autopilot: MCP の入力・同意の要求を自動で断らず、ユーザーの応答を待つ
  - `/mcp disable`: セッションをまたいで保たれる
- 非推奨（削除はまだ）: `/experimental on|off` と `/theme <mode>`。`/settings` に移る
- 追加: Windows 向けの設定 `sandbox.userPolicy.filesystem.enumeratePaths`、`/index` コマンド。対象リポジトリでは共有の tgrep 索引が既定でオンになる。Grok 4.7 / 4.6 では PDF 添付をファイル参照に切り替え、ターンを失敗させない

出典:
- https://github.com/github/copilot-cli/releases
