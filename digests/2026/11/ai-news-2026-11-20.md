### 2. [破壊的変更+新機能] Claude Code 2.1.328 は他社クラウド上の Opus 4.6 / Sonnet 4.6 で auto mode を既定にした — Bedrock・Agent Platform・Foundry で権限モード未指定の対話セッションは、確認なしで分類器が判断する状態で始まる

**要点**: Anthropic が Claude Code `2.1.328`（11/19）で、Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude apps ゲートウェイの Opus 4.6 / Sonnet 4.6 に auto mode を足した。権限モードを決めていない対話セッションは auto mode で始まる。止めるには `disableAutoMode` を使う。管理フックの発火条件も変わった。

**詳細**:
- 既定の変更:
  - plan mode と Bash の確認も、他社クラウドの Opus 4.6 / Sonnet 4.6 で auto mode を使い、提案する（新しいモデルと同じ扱い）
  - 管理された `PostToolUse` フックは、実行前に拒否された呼び出しでは発火しない（ログ・書き換え・ブロックが行われない）。`PostToolBatch` には拒否の印なしで届く
  - Code Mode はスクリプトの出力に UserPromptSubmit フック（管理フックを含む）を走らせない。出力を伏せるには `PostToolUse` の `updatedToolOutput` を使う
  - `deniedMcpServers` の `claude.ai <name>` 形式が、クラウドと self-hosted runner のセッションのコネクタにも効く
  - self-hosted runner: 設定が Claude の GitHub ツールを名前で守っている環境では、組み込みの `gh api` が既定でオフになる（`--use-anthropic-gh true` で戻す）
- 追加: `mcp_tool` フックに `"onFailure": "block"`。埋め込みアプリがポリシープラグインの `allowManagedModsOnly` を有効にでき、管理設定が優先する
- `/code-review` は多くのモデルでバグと CLAUDE.md 違反だけを報告し、各指摘に Important / Pre-existing / Nit を付ける。整理系の指摘は `/simplify` に分けた
- npm: `{stable: 2.1.311, latest: 2.1.328, next: 2.1.329}`。`2.1.329` は changelog に未掲載

出典:
- https://code.claude.com/docs/en/changelog
- https://registry.npmjs.org/@anthropic-ai/claude-code
