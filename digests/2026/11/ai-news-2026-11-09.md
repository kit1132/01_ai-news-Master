## 今日のハイライト

### 1. [新機能] Microsoft が Intelligent Terminal 0.3 を出し、タブ・エージェントセッション・端末を縦のサイドバーで管理できるようにした — エージェントの入力待ちがタブに出て、閉じた後も動かし続けられる

**要点**: Microsoft が 11/4、Windows 向けの Intelligent Terminal 0.3 を公開した。サイドバーが既定でオンになり、各タブにエージェントの状態と入力待ちの印が出る。エージェントのタブは「headless mode」にすると、端末を閉じてもマシンが止まるまで動き続ける。Copilot CLI や Claude Code は、端末で1本ずつ動かすものから、並べて状態を見張るものに変わった。

**詳細**:
- サイドバー: 横のタブバーに代わり、タブ・エージェントセッション・端末を縦に並べる（既定でオン。右クリックか Settings > Appearance > Tab Layout で横に戻せる）。Ctrl+Shift+S で畳める。分割ペインは親タブの下に入る
- タブ管理:
  - エージェントの状態: タブごとに出て、入力待ちのときは印が付く。動いているエージェントはシェルのアイコンがエージェントのアイコンに替わる
  - 検索: 開いているタブと最近のエージェントセッションを横断して探せる（閉じたものと他のウィンドウのものも含む）。「Agents only」フィルターでエージェントの CLI タブだけを出せる
  - タブに出す情報: エージェントの状態・作業ディレクトリ・git 情報（リポジトリ・ブランチ・変更）から2つまで選べる
- Recent agent sessions: 過去のセッションと他のウィンドウで動くエージェントを、タイトル・作業ディレクトリ・相対時刻つきで並べ、選ぶと新しいタブで開き直す
- headless mode: 有効にしたタブはウィンドウが無くてもサイドバーとシステムトレイに出る
- エージェントの検出: インストール済みのエージェント CLI（GitHub Copilot CLI・Claude など）を検出し、新しいタブのメニューにプロファイルを自動で作る
- 未記載: ローカルモデル・管理ポリシー・破壊的変更には記事が触れていない。製品は引き続き experimental。入手は Microsoft Store か GitHub の v0.3 リリース

出典:
- https://devblogs.microsoft.com/commandline/intelligent-terminal-v0-3-a-new-way-to-see-and-manage-your-tabs-and-agents/
