### 2. [破壊的変更+新機能] Claude Code `2.1.316` で、Team / Enterprise のサーバー管理設定が承認プロンプトなしで適用されるようになり、gateway にグループ共有の月次予算が加わった — 「管理設定の変更は開発者の承認を経て入る」前提が、Anthropic から取得した時点で効く前提に変わる

**要点**: Anthropic が 10/31 に Claude Code `2.1.316` を出した。Team / Enterprise ログインで Anthropic の API から取得した管理設定は承認プロンプトなしで適用され、検証できない保存コピーは拒否される。Claude apps gateway ではグループの共有予算と、合致する全ポリシーを重ねる layered モードを設定できる。

**詳細**:

- 管理設定・権限
  - サーバー管理設定: 承認プロンプトなしで適用。検証できない保存コピーは拒否する
  - `autoMode.allow` に `"$defaults"` を含めない管理リストに、`--settings` や `/permissions` 経由で組み込み例外が戻る不具合を直した
  - `--restricted` セッションが、Read の allow ルールに当たる作業ディレクトリ外のファイルをアップロードしていた不具合を直した
- Claude apps gateway
  - `pooled_budget`: グループのメンバーが共有する月次予算を、個人の上限に重ねて設定できる（spend limits admin API）
  - `managed.policy_mode: layered`: 開発者に合致する全ポリシーを、下位から順にマージして適用する（従来は最初の1件のみ）
  - Bedrock upstream の `guardrail.input_tagging`: prompt attacks フィルタに要る入力タグでプロンプトを包む
  - リクエストが名指すすべてのモデルを `availableModels` / `deniedModels` / `models` と照合するよう直した。ブロック対象のモデルは、該当フィールド名つきの 400 を返す
- 環境変数: `CLAUDE_CODE_SUBAGENT_EFFORT`（サブエージェントの既定 effort）、`CLAUDE_CODE_DISABLE_ULTRATHINK`、`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`
- クラウドセッション: Enterprise メンバーが自分のクラウド環境のネットワークシークレットを追加・削除できる。MCP サーバーのフォーム要求をカードで受けられる
- npm は `{stable: 2.1.309, latest: 2.1.316, next: 2.1.316}`。stable が `2.1.308` から1版進んだ。`2.1.315` は 10/30 に npm に publish されたが、changelog に項が無い

- https://code.claude.com/docs/en/changelog
- https://registry.npmjs.org/@anthropic-ai/claude-code
