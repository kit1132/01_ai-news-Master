## 今日のハイライト

### 1. [破壊的変更+新機能] Claude Code 2.1.330 は Enterprise Admin Console の組織にサインインできるようになった — 管理コンソールで決めた設定とクラウドプロバイダー / ゲートウェイが、`claude auth login` だけで端末に届く

**要点**: Anthropic が Claude Code `2.1.330`（11/20）で、Enterprise Admin Console が管理する組織へのサインインを追加した。サインイン後は組織の設定を適用し、組織が指定したクラウドプロバイダーかゲートウェイを使う。配布を `managed-settings.json` だけに頼らない経路が加わった。

**詳細**:
- 管理コンソール側の制約（ドキュメント）: 設定が効くのは開発者がその組織でサインインしたときだけで、コンソールからサインインを強制することはできない。受け付ける設定キーは固定の一覧で、`managed-settings.json` と違って一覧外のキーは無視される
- 同じ版の追加:
  - easel: グラフを描く組み込み mod。Pro / Max と、提供地域の Team / Enterprise の macOS / Linux で動き、自動グラフは `/config` でオフにできる
  - `CLAUDE_CODE_FULL_SIGN_IN_LINK=1`: 短縮リンクがエラーになるときにサインインリンクを全文で出す
  - Self-hosted runner: `--start-dir` / `SELF_HOSTED_RUNNER_START_DIR`、作業指示から登録・初回セッションまでの秒数を出す `/metrics` 2種、Anthropic 管理の git がプラグインのリポジトリを拒否したときの通知
  - `claude plugin install --json`: 結果に `commandPrinted` / `commandFailed` が加わった
- 修正: 長い会話の compact 直後に数分固まる、WebFetch がページによって数分止まるか空の結果を返す、別セッションが使っている worktree を `ExitWorktree` が消す、複数プロセスの同時保存でユーザー設定が消える
- npm: `{stable: 2.1.323, latest: 2.1.330, next: 2.1.330}`（stable の動きはハイライト2）

### 2. [破壊的変更] Claude Code の npm `stable` が 2.1.311 から 2.1.323 に進んだ — stable に固定した組織にも、12版分のプロキシ・サンドボックス・管理設定の変更が一度に届く

**要点**: npm の `stable` タグが 11/21 時点の `2.1.311` から `2.1.323` に進んだ。stable チャンネルに固定した組織は、`ALL_PROXY` だけの構成で組織ポリシーの取得がプロキシを通らなくなり、サンドボックス内の `git worktree` 操作も失敗するようになる。

**詳細**（`2.1.323` の changelog から、何もしないと挙動が変わるもの）:
- プロキシ: 組織設定とポリシーのリクエストは `ALL_PROXY` だけで設定したプロキシを使わない。必要なら `HTTPS_PROXY` を設定する
- 管理設定: `policyHelper` はユーザー設定と `--settings` ファイルの環境変数を受け取らない。必要な値は管理設定の `env` か起動シェルで渡す
- サンドボックス（macOS / Linux）: `git worktree add` / `move` / `remove` は読み取り専用で失敗する。セッション開始時の worktree 以外でのコミットも、プロジェクト内でも失敗する
- MCP: v1 クライアントを削除した。`MCP_SDK_GENERATION=v1` は v2 クライアントの互換モードで動く
- 信頼していないフォルダー: self-hosted runner の `--trust-workspace false` と VS Code の未信頼フォルダーでは、リポジトリ側の設定でフックを止めたりプラグインを切り替えたりできない
- 削除・非推奨: `subagentStatusLine` 設定を削除した（キーが残っていても読み込みは通る）。プラグインの `agent` 設定は非推奨になり、起動時に警告が出る
- 範囲外: 2.1.326 の `max_tokens` 自動再試行と、2.1.329 の予約タスクの再登録は stable にはまだ来ていない
