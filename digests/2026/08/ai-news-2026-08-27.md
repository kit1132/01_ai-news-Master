**要点**: Claude Code が `ANTHROPIC_BASE_URL` 用に設定した認証情報を Anthropic 宛のテレメトリにも載せていた欠陥を、8/25 公開の v2.1.246 で修正した。ゲートウェイ経由の組織は鍵をローテートするかを今日判断する必要がある。

**詳細**: v2.1.246 は60項目超の大型リリースで、修正の記述は「テレメトリとメトリクスのリクエストが第三者ゲートウェイ用の API キーを持って Anthropic へ送られていた／認証情報は自身のホストにしか送られなくなった」。同版には権限系の修正が3件同居する。①`Bash(git * main)` のようにサブコマンドの手前にワイルドカードを置いた allow ルールは、サブコマンドより前に挿入されたオプションにも一致するため起動時に警告するようになった ②末尾に `&&` / `||` が残った不正な Bash コマンドは常に承認を要求するようになった ③`/permissions` に Auto mode タブが加わり、auto mode の分類器ルールを一覧・編集できるようになった。あわせて、自分で作った `.claude/worktrees/` 配下の git worktree が古いバックグラウンドセッション記録に紐づいて掃除されてしまう問題も直っている。⚠️ npm の `dist-tags` は本日 `{stable: 2.1.231, latest: 2.1.246, next: 2.1.247}` で、**`stable` は 8/13 publish の 2.1.231 から14日間動かず `latest` との差は15版**。上記の認証情報修正は stable チャネル固定の組織には届いていない。

### 2. Claude in Chrome が全有料プランで一般提供 — ブラウザ操作の判断が「使えるか」から「どのドメインを許すか」へ移る

**要点**: Anthropic が Claude in Chrome を beta から GA へ移し、全有料プランで提供した。ログイン済みセッションのまま自動承認でブラウザ操作を任せられるので、検討事項は導入可否ではなく許可ドメインの線引きになる。

**詳細**: Chrome Web Store から導入する。ページ閲覧、テキスト入力、リンククリックとページ遷移、フォーム入力と送信、既存のログイン情報の利用に対応し、Claude Code と同じ考え方の**自動承認モード**で自律実行できる。Enterprise では管理者が承認ドメインを制限できる。プロンプトインジェクション耐性は、攻撃ライブラリ（社内の自動攻撃・外部レッドチーマー・実世界の監視から構成）に対する攻撃成功率が **Opus 4.5 の 17.6% から Opus 5 で 3.8%** へ下がり、ツール結果を走査する probe と、アクションをユーザーの要求と突き合わせる分類器を併用すると Sonnet 5 / Opus 5 で 0%、Fable 5 で 0.3% だったとしている。他の Chromium 系ブラウザとモバイルは対象外。

- https://claude.com/blog/claude-in-chrome-generally-available

### 3. OpenAI が WebMCP を公開 — サイト側が「画面を読ませる」のではなく「ツールを出す」前提に変わる

**要点**: OpenAI が実験的オープン標準 WebMCP を公開し、ChatGPT Work と Codex の内蔵ブラウザが対応した。エージェントにスクリーンショットとクリックで操作させる前提から、サイトが同一セッション上でツールを直接提供する前提へ移る。

**詳細**: WebMCP では、ウェブアプリが人向けの UI と並べてエージェント向けのツール（ChatGPT 上では **Site tools**）をページ上で公開し、エージェントは利用者のログイン済みセッションのまま同じ生きたページに対して操作する。Chrome 開発者向けガイドと ChatGPT Learn のドキュメントが同時公開された。協力企業は Google Chrome / Cloudflare / Shopify / Vercel / Render / Netlify。あわせて 8/25 11:00 PT に10日間のハッカソン **WebMCP Challenge** が開始され、賞金総額 $35,000 に Codex Micros・ChatGPT Pro・パートナークレジットが付く。提出締切は **9/4**、受賞発表は 9/23、10チームが各 $3,000 とパートナークレジット約 $18,480 を受け取る。参加要件はコード全体の OSS 公開・3分の動画・説明文の提出。
