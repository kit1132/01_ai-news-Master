# AI News Digest 2026-08-07

## 今日のハイライト

### 1. Kimi K3 が GitHub Copilot に載った — オープンウェイトの採否が管理者の明示判断になった

**要点**: 2.8T のオープンウェイトモデルが Copilot 全面で選べるようになった。Business / Enterprise は既定オフのため、管理者の判断対象が「どのベンダーを許すか」から「オープンウェイトを自組織の統制で許すか」へ移る。

**詳細**: 提供は Pro / Pro+ / Max / Business / Enterprise への段階ロールアウト。利用できる面は VS Code・Visual Studio・Copilot CLI・cloud agent・Copilot app・github.com・GitHub Mobile（iOS / Android）・JetBrains・Xcode・Eclipse。Business と Enterprise では**既定でオフ**で、管理者が Copilot 設定で Kimi K3 ポリシーを有効化するまでメンバーは使えない。課金は provider list pricing に基づく従量課金で、GitHub は Fireworks AI 経由でホストする。GitHub は告知内で「オープンウェイトモデルは自組織のセキュリティ・コンプライアンス・データガバナンス要件に照らして評価してから有効化すること」を明記した。Hugging Face 上の `moonshotai/Kimi-K3` は 2.8T・DL **1.26M**・likes 10.2k でトレンド3位。

- https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/
- https://huggingface.co/moonshotai/Kimi-K3

### 2. Claude Enterprise が skill / plugin を実行前にスキャンできるようになった — 供給経路の検査が組織側に来た

**要点**: 第三者 skill / plugin をアップロード・編集した時点で悪意あるコンテンツを自動検査する beta が出た。skill の安全性の担保が「配布元を信じる」から「組織が実行前に検査する」前提へ変わる。

**詳細**: 8/6 の Claude Release Notes に追加された。対象は Enterprise プランで、組織がスキャンを有効化すると、第三者の skill と plugin がアップロードまたは編集されたタイミングで実行前に検査される。検知時の挙動（自動ブロックか警告か）・脅威分類・件数上限はリリースノートに記載がなく、詳細は別途「Get started with skill and plugin scanning」（`support.claude.com/en/articles/15927065`）に置かれている。⚠️ 7月に beta 公開された **Claude Security プラグイン**（Claude Code のセッション内でコードベースの脆弱性を多エージェントで走査するもの）とは別機能で、本件は skill / plugin そのものの供給経路を対象とする。同日リリースの Claude Code v2.1.223 が権限・サンドボックス迂回4件を修正しており、供給経路と実行権限の両側を締める方向で揃っている。

- https://support.claude.com/en/articles/12138966-release-notes
- https://support.claude.com/en/articles/15927065

### 3. ChatGPT for PowerPoint / Business の無料枠が 8/6 に終了した — 以後は credit pool を消費する

**要点**: Business ワークスペースでの無料利用期間が 8/6 で切れ、従量課金に入った。7/6 GA 以降の「無料で試せる」前提が「included usage を超えると credit pool から引かれる」前提へ変わっている。

**詳細**: ChatGPT for PowerPoint は 7/6 に Business ワークスペース向けに GA となり、PowerPoint 内で編集可能なプレゼンの生成・改訂、デッキ構成やナラティブへの質問、Skills と連携アプリを使った反復ワークフローからのスライド作成ができる。無料期間は 8/6 まで。以後は flexible-pricing に従い、included usage を超えた分が workspace の credit pool から引かれる。課金方式は Workspace Agents や ChatGPT for Excel / Sheets と同じトークンベースで、input トークン・cached input トークン・output トークンに基づき、固定 credit 消費ではない。⚠️ 一次の `help.openai.com` はオリジン403で読めず、期限日と課金方式は二次報道の一致で採っている。

- https://help.openai.com/en/articles/11391654-chatgpt-business-release-notes
- https://www.techtimes.com/articles/320146/20260711/chatgpt-powerpoint-goes-ga-enterprise-teams-have-until-august-6-audit-costs.htm
