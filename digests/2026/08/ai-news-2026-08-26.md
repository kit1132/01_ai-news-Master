### 1. Claude Code に約90項目の v2.1.243 が入り、組織側が握れる範囲が広がった — 単価表示・モデル一覧・サインイン方式が「クライアント任せ」から「組織が指定するもの」へ変わる

**要点**: Anthropic が 8/24 に v2.1.243 を公開し、契約単価・`/model` の並び・API キー無しのサインインを管理設定で指定できるようにした。8/25 の v2.1.245 は Linux の起動クラッシュを直している。

**詳細**: v2.1.243 は約90項目を含む今月最大のリリースで、8/22 の v2.1.240・8/23 の v2.1.241 が2版連続「Bug fixes」だけだった後に出た。組織運用に効く追加は次の4つである。

- `modelPricing`: 組織の**契約済みモデル単価と割引率**を `/cost`・ステータスライン・テレメトリのコスト表示に反映させる管理設定。従来はリスト価格しか出なかった
- `modelPicker`: `/model` ピッカーに出すモデルを順序とラベル付きで curate する設定。Vertex / Bedrock の ID 表記も指定でき、既定ラインナップへの追加と置き換えの両方ができる
- Console アカウントでのキーレスサインイン: `/login` → Anthropic Console に「Sign in with your Console account」が加わり、**API キーの発行を認めていない組織でもサインインできる**ようになった
- `/status` の `Skipped sources`: `managed-settings.json` などが存在するのに優先度の高い管理ソースに負けて適用されていない場合、その一覧が出る

キャッシュと配布まわりも動いた。`promptCacheTtl` / `subagentPromptCacheTtl` が入り、**メイン会話は1時間のプロンプトキャッシュを保ちつつサブエージェントは5分**という組み合わせを API キー利用者とクラウドプロバイダ利用者が指定できる。ネイティブインストールと自動更新のバイナリは zstd 圧縮になり、**Linux x64 で約340MB → 約75MB** に縮んだ。コードのオンデマンド読み込みで**セッションあたり約40〜70MB のメモリ削減**も入っている。

⚠️ 料金表示の扱いが1件変わった。`/model` ピッカーと同梱の `claude-api` skill が、**Sonnet 5 の $2/$10 per Mtok を期間限定プロモではなく標準のリスト価格として表示する**ようになった。試算の前提に「いつか元に戻る価格」を置いていた場合は引き直しになる。

v2.1.245（8/25）は1項目のみで、**glibc 2.44 を積む Linux ディストリビューション**（Arch Linux・CachyOS・Fedora Rawhide）で起動時にクラッシュする不具合を修正した。

### 3. Claude の memory が chat と Cowork で1つになり、中身を開いて直せるようになった — 記憶が「溜まるもの」から「編集して管理するもの」へ変わる

**要点**: Anthropic が 8/25 に memory を chat と Cowork で共有させ、保存項目を Topics 設定で個別に読み・編集・削除できるようにした。Free / Pro / Max は既定オン、Team / Enterprise は管理者が可否を握る。

**詳細**: 従来は chat と Cowork が別々の memory を持っていた。今回の変更で、**Cowork がクラウドでタスクを走らせるときに chat 側で覚えた内容が使え、逆方向も通る**。更新の仕方も変わり、会話が終わってから要約する方式から、会話中に逐次更新する方式になった。

Topics 設定に保存済みの項目が一覧で並び、1件ずつ読み・編集・削除ができる。**1箇所直すと以後の全会話に反映される**（例として「会社の旧名を1ファイルで直せば以降の会話はすべて正しくなる」が挙がっている）。

センシティブ情報の扱いは既定が「取らない」側に置かれた。

- 既定で除外: 健康・人種・民族・宗教的信条・政治・ジェンダーアイデンティティ。**オプトインすれば含められる**が、保存のたびに通知が出て、オプトイン以前に遡って取ることはしない
- 恒久的に除外: 社会保障番号・政府発行 ID・犯罪歴・移民ステータス。オプトインしても対象外
- プラン差: Free / Pro / Max は web・desktop・mobile で既定オン。Team / Enterprise は**管理者が組織として可否を決め、個人側は有効化するまでオフ**

⚠️ 本発表に **Claude Code への言及はない**。統合の対象は chat と Cowork の2面である。

- https://claude.com/blog/claudes-memory-works-everywhere-and-you-decide-whats-in-it
