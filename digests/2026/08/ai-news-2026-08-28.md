### 1. GitHub Copilot の global model policy が GA — 「新モデルは管理者が有効化するまで使えない」前提が反転した

**要点**: GA になった Copilot モデルが既定でオンに変わり、9/1 までに全 enterprise へ順次適用される。管理者が明示的に無効化しない限り新モデルが自動で使える側に回るので、「棚卸ししていないモデルは使われていない」という前提で組んだ運用は引き直しになる。

**詳細**: GitHub が 8/26 に「Global model policy generally available」を公開した。対象は Copilot Business / Copilot Enterprise。8/26 から適用が始まり **9/1 までに段階ロールアウト**が完了する（enterprise ごとに適用時刻が異なる）。管理者は global default policy（既定は有効）を設定でき、個別モデルで上書きできる。モデルの状態は **Enabled / Disabled / Delegate to enterprise teams・apps・organizations / Delegate to default policy** の4種。⚠️ **オープンウェイトモデルとデータ保持を要するモデルは、global の設定にかかわらず既定で無効**。7月に予告されていた変更の GA にあたる（7/29 の default model enablement、7/31 の enterprise teams model policy targeting public preview の続き）。GitHub は将来的に global policy の状態を推論ではなく明示的な選択にし、「Delegate to default policy」を廃止する方向を検討していると書いている。

- https://github.blog/changelog/2026-08-26-global-model-policy-generally-available/
- https://github.blog/changelog/label/copilot/

### 3. Claude Cowork に内蔵ブラウザが載り、拡張機能なしで Claude が自分のブラウザを開くようになった

**要点**: Claude デスクトップアプリが自前のブラウザを持ち、ユーザーの Chrome を触らずにサイト閲覧・フォーム入力・ポータル操作を代行する。コネクタが無い社内システムを「拡張機能を入れずに」自動化できる側に回ったので、Claude in Chrome を入れられない環境でも選択肢ができた。

**詳細**: 8/26 公開。タスクがウェブを必要とするときサイドパネルにブラウザが開き、Claude がページを読み・クリックし・入力する。コネクタの無いポータルの操作、ダッシュボードからの数値抽出、フォーム入力が対象。**Pro / Max / Team は公開週から順次ロールアウト、Enterprise は管理者が当日から組織単位で有効化できる**。macOS / Windows / Linux（beta）対応で、web / モバイルから使う場合もデスクトップアプリが必要。⚠️ **銀行・メール・SSO のサイトは既定で除外**され、使うには明示的な許可がいる。ユーザー自身のブラウザとは分離されており、タブ・ブックマーク・パスワードには触れない。ログイン情報は Chrome / Edge / Firefox からサイト単位でインポートする形。プロンプトインジェクション対策は Claude in Chrome と同等とされ、設定で内蔵ブラウザと Claude in Chrome 拡張のどちらを使うか選べる。Anthropic は信頼できるサイトから始めることを推奨している。⚠️ 8/12 の「Chrome サイドパネルが Cowork セッションになる」更新の続きにあたるが、**別機能**である（あちらは拡張機能側、こちらはデスクトップアプリ内蔵）。
