### 1. Claude API に browser use tool が登場し computer use が GA — ブラウザ操作エージェントが beta ヘッダなしで本番に載る

**要点**: Anthropic が 8/19 に `browser_toolset_20260801`（browser use tool）を公開し、同時に computer use を `computer_toolset_20260801` として GA した。「beta だから本番に載せない」という保留理由が computer use から消え、デスクトップ全体を screenshot で操作する方式に代えて**ページ構造を直接読む**選択肢が加わった。

**詳細**: browser use tool は、自社アプリが持つブラウザを Claude に運転させるクライアント側ツールセットで、実行はすべて自環境で行う。member tool は31本あり、内訳は次のとおり。

- ページ読み取り: `read_page`（アクセシビリティツリーと要素参照）／ `find`（説明文で要素検索）／ `get_page_text`
- フォームとファイル: `form_input` で値を直接セットできる。`file_upload` は既定で無効
- タブ管理: `new_tab` / `list_tabs` / `switch_tab` / `close_tab` の4本
- 診断・スクリプト（任意）: `read_console` / `read_network` / `javascript_exec`
- 従来どおりの座標系操作（クリック11種・キーボード4種・`navigate` / `screenshot` / `zoom`）も揃う

computer use との違いは、**要素参照（`ref_2` 等）でレイアウト変化に耐えること**とタブ・フォームを構造として扱えることにある。対応モデルは Fable 5 / Mythos 5 / Opus 5 / Sonnet 5 / Opus 4.8 で、ZDR 対象（Covered Models を除く）。⚠️ **browser use tool は Claude API 限定**で、Bedrock / Google Cloud / Microsoft Foundry では使えない（computer use の GA 版はこれらで beta 提供）。

computer use の GA 側は、beta ヘッダ不要に加えて①1ターンに複数アクションを返すバッチ実行、②`zoom` の既定有効化、③`configs` による member 単位設定が入った。`display_width_px` などの指定は不要になり、スクリーンショットから自動でスケールする。既存の `computer_20251124` 連携はそのまま動く。

⚠️ セキュリティ側の注意がドキュメントに明記されている。ブラウザは信頼できないページ内容を自環境で扱うため、認証情報を持たない隔離コンテナで動かし、ネットワーク層でドメイン許可リストを敷き、`javascript_exec` と `file_upload` は必要になるまで無効のままにすることが求められる。

⚠️ **本項は 8/19 公開だが、本ダイジェストが同日ブロックから取りこぼしていた分**である（8/20 は Admin API GA のみ、8/21 は Files API / Agent Skills GA までを検出）。同一日付ブロックで**3日連続・毎回違う項目**が落ちており、B-024 に追記した。

### 2. Slack が Slack Code を公開し GitHub Copilot も Slack / Teams に入った — コーディングエージェントの操作面がチャンネルへ移る

**要点**: Slack が 8/20〜8/21 に **Slack Code** を公開し、GitHub も 8/21 に Copilot の Slack / Microsoft Teams 連携を public preview で出した。エージェントの操作面が個人のターミナルからチーム共有のチャンネルへ移り、「誰がどのエージェントに何をさせているか」がレビュー対象になる。

**詳細**: Slack Code は、任意の会話でコーディングエージェントをメンションすると専用の code チャンネルが立ち、会話 / plan / コード差分 / ライブプレビューのタブでチャンネル全員が経過を追える仕組み。ローンチパートナーは **Claude Code・GitHub Copilot・Devin・Vercel Agent・ChatGPT** で、Slack 側は全サブスクリプションで追加費用なし（各エージェントのアクセス権は別途必要）。

GitHub 側の2件は内容が異なる。

- Slack: `@GitHub` にコードや GitHub 上の活動を質問し、issue のトリアージ、障害調査、隔離クラウドサンドボックスでの実装と検証、PR 作成までを任せられる。対象は **Copilot Business / Enterprise**。管理者による cloud agent ポリシー有効化とアプリのインストール・アカウント連携が前提で、消費は既存の Copilot 枠から引かれる

- どちらも issue / PR は Copilot アプリの identity に帰属し、**リポジトリ管理者はエージェント作成 PR のマージ前に追加承認を必須化できる**

## Claude Code / Claude Developer Platform

- **Claude Code が v2.1.238 を公開した（8/20 18:01 UTC）**。前日は npm の `next` にしか出ていなかった版が changelog に掲載され、`latest` へ昇格した。50項目超の大型リリースで、実務に効くのは次の4点
  - `headersHelper`: プラグインマーケットプレイスとカタログエントリで、短命トークン等の HTTP ヘッダをコマンドで都度発行できる。カタログエントリ側はインストール / 更新時のみ実行され、コマンドを表示したうえで `[y/N]` を問う

  - 長時間セッションのメモリ増加を修正した。サブエージェントのツール結果が表示ウィンドウを外れた時点で解放されるようになった
  - `keybindingFlavor` に `"readline"` を指定すると Ctrl+W が Bash と同じく直前の空白まで削除する。既定の `"classic"` は変更なし
- **npm の `dist-tags` は `{stable: 2.1.228, latest: 2.1.238, next: 2.1.239}`**（8/22 実測・`curl` で取得）。`next` の **v2.1.239 は 8/21 17:18 UTC publish で changelog 未掲載**（B-035 が言う npm 先行の6例目）。`stable` は 2.1.228 で据え置き、`latest` との差は **10版に拡大した**
