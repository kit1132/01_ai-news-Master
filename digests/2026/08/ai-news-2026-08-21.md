### 1. Claude API で Files API と Agent Skills が GA — beta ヘッダ前提の見送り理由が消えた

**要点**: Anthropic が 8/19 に Files API と Agent Skills / Skills API を Claude API で GA した。`files-api-2025-04-14` と `skills-2025-10-02` の beta ヘッダが不要になり、「beta だから本番に載せない」という保留理由がなくなった。

**詳細**: GA に伴い、ヘッダなしのリクエストは GA 応答形式で返る。

- ファイル有効期限: アップロード時に `expires_in_seconds` を指定でき、file オブジェクトが `expires_at` を返す
- 一覧のページネーション: `/v1/files` の list に `page` / `next_page` と `ids[]` フィルタが加わった
- Skills のロード: Messages API の `container` パラメータ経由でも beta ヘッダが不要になった
- 互換性: beta ヘッダを送り続けるリクエストは従来形式のまま動くので、既存コードの改修は不要

同日には Claude Enterprise 向け Admin API のユーザー管理エンドポイント（members / invites / groups / custom roles）も GA しており、**8/19 だけで GA が3本**出ている。⚠️ 本ダイジェストは 8/20 分で Admin API の GA しか拾えておらず、Files API と Agent Skills の GA は本日はじめて確定した（同一日付ブロック内の項目取りこぼし＝B-024 の形）。

### 2. Claude Code が v2.1.236 / v2.1.237 を公開 — macOS の read-deny がリネームで迂回できなくなった

**要点**: Claude Code が 8/19 に v2.1.236、8/20 に v2.1.237 を公開した。macOS sandbox で `**/.env` のようなワイルドカード read-deny ルールが**許可読み取り領域の内側でも優先される**ようになり、「deny 対象ファイルをリネームすれば読める」という抜け道が塞がった。

**詳細**: v2.1.236 は大型で、セキュリティ以外の主な追加は次のとおり。

- `ANTHROPIC_DEFAULT_MODEL`: 新規セッションの開始モデルを指定する。`/model` の選択が上書きし、再起動をまたいで保持される点が `ANTHROPIC_MODEL` と違う
- `notify_when_idle`: 同一マシン上の別 Claude Code セッションに「次に idle になったとき1回だけ通知」を依頼できる（opt-in・macOS / Linux）
- auto mode: `Monitor` の allow ルールを auto mode 稼働中は退避し、Monitor コマンドを Bash と同じ経路で審査するようになった。Bedrock / Vertex AI / Foundry とテレメトリ無効時も Claude API と同じ既定（severity スコア付き分類）を使う
- `/usage` に Team / Enterprise メンバー向けの usage-credits 支出行が追加された

v2.1.237 は 2 項目のみで、LLM ゲートウェイ / カスタム base URL 使用時のプロンプトキャッシュ修正と、**Concise 出力スタイル**の追加（`/config` の Output style で選択。前置きと実況を省き結果から書く）。

npm の `dist-tags` は `{stable: 2.1.228, latest: 2.1.237, next: 2.1.238}`（8/21 実測）。**`next` の v2.1.238 は 8/20 18:01 UTC publish で changelog に未掲載**（B-035 が言う npm 先行の5例目）。`stable` は 2.1.227 → 2.1.228 と1版進んだが `latest` との差は **9版に広がった**。

### 3. Grok 4.6 が Amazon Bedrock で GA — xAI の API を通さずに AWS の権限・監査下で使える

**要点**: xAI の Grok 4.6 が 8/19 に Amazon Bedrock で一般提供された。Bedrock が提供される全 AWS リージョンでクロスリージョン推論に対応し、xAI と個別契約せずに既存の IAM / CloudTrail / コスト管理の枠内で Grok を評価できるようになった。
