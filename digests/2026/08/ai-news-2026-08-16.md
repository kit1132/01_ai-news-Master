### 2. ChatGPT が Mac の操作履歴を記憶に変える Computer History を出した — 承認アプリの中身がモデルの文脈になる

**要点**: OpenAI が macOS 版 ChatGPT に Computer History を追加した。承認したアプリとサイトの操作が検索可能なタイムラインと記憶になり、ChatGPT と Codex が参照する。opt-in だが、読ませたい文字列をアプリ側から仕込める入口が増えた。

**詳細**: 公開は 8/13、対象は **ChatGPT Pro / Business / Enterprise**。記録するのは macOS のアクセシビリティ機能が露出する操作イベント（クリック・タイピング・キーボードショートカット・アプリ切替）で、**画面のスクリーンショットではない**。イベントは OpenAI 側のサーバーで処理されて記憶に変換されるが、処理後は保持せず学習にも使わないと同社は説明している。生成された記憶は**ローカルに平文の Markdown ファイル**として置かれ、削除するまで残る。

OpenAI 自身が、アプリやサイトの悪意ある内容による**プロンプトインジェクションの risk が上がる**と警告し、他者とのやりとり中は本人の明示的な同意なく収集しないこと・機微情報を含むアプリを除外することを推奨している。提供対象外の地域は **EEA・スイス・英国**。

位置づけとしては、2026年前半に research preview として動いていた **Chronicle（画面キャプチャ方式）の作り直し**にあたる。キャプチャ画像を撮らない設計に変えたことで保存物は軽くなったが、平文 Markdown がローカルに残る点は変わらない。

⚠️ 一次 `learn.chatgpt.com` はゲートウェイ拒否が継続しており、本項は WebSearch 経由の検出と二次報道の一致による。

### 3. Claude Code v2.1.233 が公開された — stable 固定の環境は脆弱性修正を9版ぶん待つことになる

**要点**: Anthropic が v2.1.233 を公開し、Windows のパス検証バイパス修正と GitLab MR 対応が入った。一方 npm の `stable` タグは v2.1.224 のままで、既定チャンネルに固定した組織にはこの修正が届いていない。

**詳細**: 公開は 8/14 22:20 UTC（GitHub releases）、npm publish は 8/14 18:50 UTC。`code.claude.com/docs/en/changelog` / GitHub releases / npm `latest` の3ソースで最上位が一致した。**前回チェック時点では npm `next` にしか存在せず changelog には未掲載**だった版で、本日 `latest` へ昇格している。

- セキュリティ: Windows の **NT device path が UNC 検証を迂回する**問題を修正
- GitLab: `--worktree` と `claude agents` が **MR の URL を受け付ける**（MR は `!N` 形式で表示）
- apps gateway: opt-in の `forward_user_identity` を追加。サインイン中ユーザーの identity をヘッダで送るので、ゲートウェイ背後のプロキシが**ユーザー単位で費用を按分**できる
- Linux: Bash ツールのコマンドに opt-in の memory cgroup を追加。サンドボックス下のアイドルセッションが CPU を食い続ける問題も修正
- 環境変数 `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` で WebFetch の URL キャッシュ TTL を設定できるようになった
- 修正: MCP v2 接続が `subscriptions/listen` ストリームを開き続ける / 権限プロンプトで Notification hooks が発火しない / 環境シャットダウン時にクラウドセッションが lost 扱いになる / プラグイン・MCP 併用時の同梱 skill エイリアス

npm `dist-tags` の実測は **`{stable: 2.1.224, latest: 2.1.233, next: 2.1.233}`**。前日は `{stable: 2.1.223, latest: 2.1.232, next: 2.1.233}` で、**`stable` は1版しか進まず `latest` との差は9版のまま**である。この9版には本日の NT device path 修正のほか、auto mode の既定化・PowerShell と Windows の権限バイパス修正3件が含まれる。**「最新版で修正済み」と「手元で修正済み」は別物**であり、changelog と GitHub releases だけを見ているとこの差は見えない（→ B-035）。
