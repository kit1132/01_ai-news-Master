### 1. Sonnet 5 の $2/$10 が恒久価格になった — 9/1 の値上げを織り込んだ試算は引き直しになる

**要点**: Anthropic が Sonnet 5 の導入価格 $2/$10 を恒久価格に切り替え、9/1 予定だった $3/$15 への値上げを取り消した。入出力とも50%上がる前提で組んだ費用試算は、据え置き前提へ引き直すことになる。

**詳細**: 公式の pricing ページに注記が入った。「launch 時に 2026年8月31日までの導入価格として告知した $2/$10 は now the standard price であり、2026年9月1日に予定していた $3/$15 への引き上げは実施しない」という文面である。API release notes 側の掲載日は **8/10**、Claude 公式アカウントの告知は 8/11。

現行の Sonnet 5 の単価は次のとおり。

- 通常: 入力 **$2 / MTok**、出力 $10 / MTok
- Batch API（50%割引）: 入力 $1 / MTok、出力 $5 / MTok
- プロンプトキャッシュ: 5分書き込み $2.50、1時間書き込み $4、キャッシュヒット $0.20

比較対象の Sonnet 4.6 / 4.5 は $3/$15 のまま据え置かれているので、**Sonnet 5 は旧世代より安い状態が恒久化した**ことになる。⚠️ 本ダイジェストは 08-01 以降8本にわたり「8/31 で促進価格終了 → $3/$15」を注目スケジュールに載せてきたが、この期限は消滅した。以後の記載から外す。

### 2. Claude の生成物に不可視ウォーターマークが入る — 出力の来歴が既定で残る前提に変わる

**要点**: Anthropic が、Claude の生成テキストへ不可視の機械可読マークを埋め込み、画像等のファイルには C2PA 署名を付ける運用を公表した。API・Claude Code・Cowork を含む全面適用で、オプトアウトの記載はなく、EU 域内に限らず全世界が対象。

**詳細**: EU AI Act Article 50（8/2 発効）の透明性義務に対応する措置で、Anthropic は EU の Code of Practice に署名している。適用範囲は次のとおり。

- 対象プロダクト: Claude Platform（API）／ Claude ／ Claude Code ／ Claude Cowork ／ Claude Tag、および AWS・Google Cloud・Microsoft Foundry 経由の各版
- テキスト: 生成文そのものに信号を織り込む。通常の閲覧では見えず、**コピー&ペーストしても残る**が、大幅に編集すると劣化する
- ファイル: `.svg` / `.png` / `.jpg` に C2PA（Coalition for Content Provenance and Authenticity）準拠の署名付き来歴メタデータを付与する
- 対象モデル: **2026年8月2日以降にローンチする新モデルは launch 時点で対応**。それ以前の既存モデルは対応作業中

Anthropic 自身が限界を明記している点は押さえておく必要がある。マークが検出されても「Claude が処理した可能性がある」ことしか示さず著者性を確定しない。逆にマークが無くても AI 生成でないことにはならない（編集・翻訳・メタデータ除去・旧モデル生成のいずれもあり得る）。検出手段は今後の技術文書で公開するとしている。Article 50 の違反には最大 €15M または全世界年間売上の3%の制裁が定められている。

### 3. Compliance API が Claude Code / Cowork のローカルセッションを返すようになった — 端末上の作業も組織側から読める

**要点**: Anthropic が Enterprise 向けに、利用者の端末で動く Cowork と Claude Code のセッション文字起こしを Compliance API から取得できるようにした（beta）。「ローカル実行なら組織側に残らない」という前提が崩れる。

**詳細**: 8/11 公開。既存の Compliance Access Key と `read:compliance_user_data` スコープでそのまま使え、追加の統合作業は要らない。エンドポイントは3本。

- `GET /v1/compliance/apps/sessions/local`: 組織全体のセッション一覧
- `GET /v1/compliance/apps/sessions/local/{session_id}`: 1セッションのメタデータ
- `GET /v1/compliance/apps/sessions/local/{session_id}/messages`: 文字起こし本体

取得できる内容は、プロンプトと応答、ツール呼び出し（web・MCP）の中身、skills と artifacts の中身、加えて検証済みユーザー資格情報・組織ID・セッションID・タイムスタンプ。カバー範囲は desktop アプリ / web / mobile の Cowork と、CLI / desktop アプリの Claude Code である。**除外されるのは Claude Code on the web、Claude Platform 経由の Claude Code、Bedrock / Vertex AI / Microsoft Foundry 上のセッション**の3系統。

8/3 には claude.ai の web・mobile から始めた Cowork の**リモート**セッションが同 API に入っており、今回はローカル実行側の追加にあたる。これで Enterprise 管理者から見える範囲が、サーバー側セッションから利用者の手元の端末まで広がったことになる。

- https://claude.com/blog/compliance-api-cowork-and-claude-code
