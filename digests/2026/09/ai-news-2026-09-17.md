### 1. Cowork と chat が1つの Claude に統合された — 「どこで作業するか」を選ぶ前提が消えた

**要点**: Anthropic が Cowork と chat を統合し、Claude Docs と Claude Slides をベータ公開した。作業の置き場所を先に決める前提が消え、成果物は編集可能なファイルで返る。Pro / Max から順次展開する。

**詳細**: 9/16 公開。ユーザーは用件を書くだけで、Claude 側がその場の回答で済ませるか、調査・レポート・表計算・プレゼンといった大きい仕事として引き受けるかを判断する。返るファイルは数式が生きた表計算と、PowerPoint で開けるプレゼンを含む。Claude Design は独立プロダクトから会話内の機能になり、単体で使っていた場合は従来どおり動く。

- 対象プラン: Pro / Max へ数週間かけて展開。Team / Free は「近日」。Enterprise は変更の**30日前に管理者へ通知**し、有効化の時期は管理者が選ぶ
- 対象インターフェース: Web・デスクトップ・モバイル
- 既存データ: チャット・プロジェクト・アーティファクト・コネクター・スキルはそのまま引き継がれる
- Claude Docs / Claude Slides / Claude Design の3つはいずれも**有料プランのベータ**。料金改定の記載はない
