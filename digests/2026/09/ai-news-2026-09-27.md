### 1. [破壊的変更+新機能] Claude Code `2.1.283` が npm `latest` に上がり、Bedrock / Vertex 等やテレメトリ無効の環境で権限モード未設定なら auto mode で起動するようになった — 「未設定なら毎回確認」の前提が外れた

**要点**: Anthropic が 9/25 に `2.1.283` の changelog を公開し、npm の `latest` も同版になった。サードパーティプロバイダ経由かテレメトリ無効の対話セッションは、権限モードを決めていないと auto mode で起動する。管理者向けにモデルの許可リストを完全一致で固定する設定も入った。

**詳細**:

- npm `dist-tags`: `{stable: 2.1.274, latest: 2.1.283, next: 2.1.283}`（09-27 実測）。`stable` 固定の組織にはまだ届いていない
- 既定の変更（Changed）:
  - 権限モード: サードパーティプロバイダ利用時かテレメトリ無効時は、未設定なら auto mode で起動する
  - `Skill(anthropic-skills:<name>)` の deny ルールが Claude Desktop プラグインのスキルもブロックする
  - `/ultrareview` がローカルブランチのレビューで未コミットの追跡ファイルを送る場合があると表示する
  - self-hosted runner の git: LFS の `pre-push` をスキップ、書き込み可能なシステム側 `core.hooksPath` を無視、`--configure-git` なしでは署名しない
- 管理設定の追加（Added）:
  - `availableModelsMatch`: `"exact"` にすると `availableModels` に列挙したバージョンだけを許可し、新モデルは列挙するまでブロックする
  - `deniedModels`: 特定モデルをブロックする
  - `/doctor prompt-audit`: CLAUDE.md・skills・agents・commands から旧モデル向けの書き方、古いパス、矛盾する指示を検出する
- セキュリティ寄りの修正: Windows の PowerShell ツールで `rd` / `del` 等により保護フォルダを削除できた問題、サンドボックス内の git credential helper がプロキシのログイン情報を保存していた問題、managed `sandbox` 設定のネスト値が不正だと設定全体が無視されていた問題
- 課金: Code Review が時間制限で止まった不完全なレビューに課金していた問題を直し、以後は課金せず1回再試行する
- `2.1.282` で入れた `claude-ai` 名の予約は取り消した

### 2. [動向] 米 DC 巡回区控訴裁判所が、国防総省による Anthropic の supply-chain risk 指定を 2対1 で適法と判断した — 8月の地裁勝訴で揺らいでいた「軍と請負業者は Claude を使えない」状態が控訴審で固まった
