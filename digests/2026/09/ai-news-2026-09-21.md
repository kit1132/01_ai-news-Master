### 2. Claude Code の自動承認チェックが、環境によっては「無料のサーバー側」から「有料の自前」に戻る — 止まるのは機能ではなく、課金の経路

**要約:**  
Claude Code（`2.1.278` 以降）では、自動承認の安全チェックをサーバー側で行えるとき、そのチェック分は課金しない。サーバー側チェックがセッションに届かないと、従来どおり自前のチェックに戻り、**その分は従来どおり課金**される。届かなくなったあと、チェック対象の操作の前で一度止まり、通知が出る（Enter で続行／Esc でその操作を中止）。一次は「機能は壊れない」と明記している。状態は `/status` の Auto mode server 行（`Enabled` / `Disabled`）。通知にゲートウェイ名が出たら、管理者に「リクエスト／応答を改変せず通す」よう確認を依頼する（ゲートウェイ非対応が既知のときだけ、起動前にサーバー側チェックを切る一時設定がある。詳細は一次）。

**詳細:**  
通知が出るのは Enterprise、Claude API、および Bedrock / Google Agent Platform / Foundry など。原因はゲートウェイがヘッダや未知フィールドを落とすことが多いが、プラットフォーム・リージョン・資格情報がまだサーバー側チェック対象外のときも同じ通知になる。Pro / Max / Team ではこの通知は出ないが、auto mode 自体はこれらのプランでも使う。「通知がない＝今回の変更と無関係」ではない。

- https://code.claude.com/docs/en/auto-mode-classifier-billing
