### 1. Anthropic が Enterprise Frontier Safeguards を発表 — ZDR は「残らない」から「顧客のクラウドに残り Anthropic が読む」へ

**要点**: Anthropic が 9/1 に EFS を発表した。ゼロデータ保持の意味が「Anthropic 側にログが残らない」から「顧客所有クラウドに残り Anthropic の検出ロジックが読む」へ変わり、ZDR 前提の社内審査は引き直しになる。

**詳細**: EFS は、アクティビティログを顧客所有の **AWS S3 / Azure Blob / GCS** に顧客の暗号鍵で書き出し、Anthropic は誤用検出のロジックだけをそこに対して動かす方式とされる。人によるコンテンツ閲覧は行わないと説明されているが、検出のために Anthropic 側が読む余地は残るため、「Anthropic に一切渡らない」という一般的な ZDR の語感とは一致しない。金融・医療・製造・通信・法務・小売・公共の**100社超**と、AWS / Google Cloud / Microsoft Azure との協業で設計したとされる。提供は**今秋から段階的**で、それまでの間、適格顧客は Fable 5 / Fable 5.1 で ZDR を受けられる。⚠️ この暫定措置は GitHub Copilot 側の期限とつながっている——Copilot は 9/1 の Fable 5.1 GA 告知で「適格 enterprise の ZDR 暫定免除は**暦年末まで**、以後は EFS が必要」と明記しており、**12/31 の期限は EFS の展開時期に依存する**。同時期に Anthropic は 7/30 の3件のサイバー評価インシデントに対する追跡投稿も出しており、二次報道はここで**ヒューマンフィードバック経路の分類器欠落**（2025年5月〜2026年4月の11ヶ月、約5万人・約1.33億件のやり取りが生物兵器分類器を通らず、Sonnet 5 の遡及走査で1,197件を高リスク判定、非内部の62件と無作為30件を人手確認して明確な誤用は無し）を併せて報じている。⚠️ **一次（`anthropic.com/news`）はゲートウェイ拒否で未読**。二次は CSO Online / MarkTechPost / The Register / SecurityWeek で一致する。

### 2. Claude Code 2.1.259 が出た — MCP サーバーの配布が各自設定から組織配布へ変わる

**要点**: Claude Code `2.1.259` が `managedMcpServers` と `--permission-prompts none` を追加した。MCP サーバーの用意が利用者ごとの設定から組織による一括配布へ、無人ホストの権限プロンプトが暗黙停止から明示停止へ変わる。

**詳細**: 9/2 21:21 UTC publish。管理設定 `managedMcpServers` により、組織が HTTP / SSE の MCP サーバーを全ユーザーへ配れるようになった。あわせて `allowedMcpServers` の意味が**ユーザーが自分で追加したサーバーだけを統制する**ものへ変更されており、組織配布分は別枠になる。`--permission-prompts none` は無人の headless ホスト向けで、承認待ちで止まる代わりに拒否として進む。⚠️ 修正の中に**リモート / スケジュール実行に直接効くもの**が複数ある: コネクタツールの権限承認をセッション一時停止中に通しても何も起きなくなる不具合、ブラウザ側の MCP サーバーページが消えた後にリモートセッションの起動が60秒かかる問題、`--resume` がペイロードの無い添付エントリで失敗する問題。ほかに `claude plugin validate --json`、GitLab の `glab mr` 系コマンドの認識、カスタムコマンド / スキルの frontmatter `model:` が無視される不具合の修正、複数セッションが `~/.claude.json` を互いに巻き戻す不具合の修正が入った。npm の `dist-tags` は `{stable: 2.1.236, latest: 2.1.259, next: 2.1.259}` で、**`stable` は 23版遅れ**（前日22版差から拡大）。
