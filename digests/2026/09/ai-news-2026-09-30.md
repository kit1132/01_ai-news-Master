### 1. [新機能+仕様] OpenAI が DevDay で GPT-6.1 Sol を出し、同日に Copilot でも GA した — Astra に近い性能を Sol と同じ $2 / $10 で使えるので、上位モデル前提のコスト試算を引き直すことになる

**要点**: OpenAI が `gpt-6.1-sol` を $2 / $10 で公開した。Astra に迫る性能を Astra 標準価格の1/5で出すとしている。GitHub Copilot も同日に GA したので、Pro+ 以上なら今日から選べる。キャッシュ書き込みに新しく課金が付く点は GPT-6 Sol と違う。

**詳細**:

- API 仕様（developers.openai.com・一次）:
  - 料金（1M トークンあたり）: 入力 $2 ／ キャッシュ入力 **$0.10**（GPT-6 Sol は $0.20）／ キャッシュ書き込み $2.50（新設）／ 出力 $10
  - 倍率: Fast モードは2倍。Batch / Flex は50%引き。272K トークン超のリクエストは入力・キャッシュが2倍、出力が1.5倍
  - コンテキスト 1.05M（入力最大 922K）／ 最大出力 128K ／ 知識カットオフ 2026-04-30
  - 対応は Chat Completions / Responses / Batch。Realtime・Fine-tuning・Assistants には対応しない。Responses API で Multi-agent（beta）が使える
- 同日に changelog へ載った API の変更（一次）:
  - Ultrafast: Responses API で `service_tier: "ultrafast"` を指定すると GPT-6 Astra を高速で動かせる。レート制限があり、EU データ保管には対応しない
  - Agents API: OpenAI がホストするブラウザで computer use を実行できるようになった。サイトへのアクセスは承認制
- 提供先: Codex と ChatGPT Work にも同日入った（ChatGPT & Codex changelog 9/29）。GitHub Copilot では Pro+ / Max / Business / Enterprise で GA し、既定で有効になる。Copilot Pro は対象外で、課金はプロバイダ定価の従量課金

### 2. [破壊的変更+新機能] GitHub Copilot CLI の安定版 v1.0.89 が `.claude/rules` を読み込み、Fast プロファイルを廃止した — 同じリポジトリで Claude Code 用に書いたルールが Copilot CLI にも効くようになった

**要点**: GitHub が Copilot CLI v1.0.89 を安定版として出した（9/28）。`.claude/rules` のルールファイルを custom instructions として読むので、Claude Code 向けのルールがそのまま Copilot CLI の挙動を変える。Fast プロファイルは廃止され、保存済みの Fast 設定は Balance で動く。

**詳細**:

- 主な変更（全約35項目）:
  - モデルピッカー: GPT-6 Sol / GPT-6 Luna を追加し、`claude-opus-5.5` に対応した
  - Auto: ルーティング tier を提案するようになった
  - PR 作成: リポジトリの PR テンプレートに従うようになった
  - プラグイン: 直接インストールしたものも有効化・無効化できる。無効として記録済みのものは読み込まれなくなるので、`copilot plugin enable` で戻す
  - 修正: MCP ツールのスキーマで `anyOf` の横に `type` か `properties` があると Gemini モデルが毎回 400 になっていた問題
  - `TGREP_FILE_COUNT_THRESHOLD` でインデックス検索を自動で有効にする条件を設定できる
- pre-release は `v1.0.90-4`（9/29 18:26 UTC）まで進んだ。`-3` で `--mcp-github-auth` が加わり、GitHub 認証を渡す MCP サーバーを承認済みの接続元に限定できる
