### 2. GitHub Copilot アプリにローカルサンドボックスと OpenTelemetry 出力が入り、GPT-6 Luna は Pro でも使える — エージェント実行の制限と監査を Copilot 側で持てるようになった

**要点**: GitHub が 9/22〜9/23 に Copilot アプリへ OpenTelemetry 出力（Enterprise の `managed-settings.json` で設定）とローカルサンドボックス（public preview・既定オフ）を追加した。同時に GPT-6 Sol / Luna を投入し、Luna は Pro でも選べる。

**詳細**:

- ローカルサンドボックス（9/23）: プロジェクト単位または `/sandbox on` で有効化する。制限対象はファイルシステム（読み書き / 読み取り専用 / 拒否フォルダー）・ネットワーク（外向き / ローカル）・資格情報（Git HTTPS・GitHub CLI 認証）。Enterprise の管理設定はプロジェクト設定より厳しく強制でき、OS が強制できない場合はセッションがエラーで失敗する。クラウドサンドボックスとリモートホストのセッションには適用されない
- OpenTelemetry（9/22）: モデルへのリクエストとエージェントが使ったツールを既存の監視基盤へ出力する。**プロンプトと応答の本文は既定で除外**。Enterprise 管理者が `managed-settings.json` の `telemetry` で出力先を指定する
- GPT-6 Sol / Luna（9/22）: Sol は Pro+ / Max / Business / Enterprise、**Luna は Pro も対象**。従量課金。管理者がグローバル既定を切っていない限り新モデルは自動で有効になる

⚠️ サンドボックスの本文には対応 OS とプラン制限が書かれていない。
