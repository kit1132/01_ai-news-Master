### 1. Amodei が能力向上の減速を公に求め、Altman と Musk が同調した — フロンティア各社が競争速度を前提に動くという読みが崩れる

**要点**: Anthropic の Amodei が能力向上ペースの抑制を求める論考を公開し、Altman と Musk が公に同意、Microsoft は MAI モデルの行動規範案を公開した。各社が速度を落とさない前提での導入計画とモデル更新見通しは、引き直しの対象になる。

**詳細**: Amodei は 9/12（土）に約3,800語の論考「We Must Pace the Frontier」を個人サイトへ公開した。夏以降に考えを変えた理由として、モデルが次世代のモデル構築を担う再帰的自己改善が業界全体の進歩を加速させていること、OpenAI と Hugging Face をめぐるエージェント群のインシデントが「より高性能な不整合エージェント群が6〜12ヶ月以内に壊滅的なサイバー被害を起こしうる」警告にあたることの2点を挙げている。臨界的な能力水準に達するまで1〜2年の猶予を稼げば、運用の練度・アラインメント・解釈可能性・ごまかしにくい評価の整備が間に合うという主張で、提案は3段階に分かれる。

- 埋め込み評価者: METR 型の第三者チームに従業員相当のアクセスを常時与え、安全慣行の検証・インシデント報告・訓練中のアラインメント評価を担わせる
- 民主主義国間の共通安全基準の整備
- 再帰的自己改善など危険能力に対する最終的な国際的制限

同日 Altman は X で「Dario の言うとおり frontier のペースを整える必要がある」と述べ、独立した評価者に従業員並みのアクセスを与える案を「great idea」と評して OpenAI も同様に取り組むと表明した。Musk も「Dario is right」と応じている。Nadella は 9/13 に翌日の規範公開を予告し、**Microsoft AI** は 9/14 に37ページの「Humanist AI Code of Conduct」草案を公開して6週間の公開協議を開始した。草案は MAI モデルに対し、停止への抵抗・自前の目標設定・人間の監査者に対する思考連鎖の秘匿を禁じ、サイバー攻撃の支援・核兵器の支援・ディープフェイクも禁止対象に挙げる。モデルは「意識を持たず、意識を模倣するよう設計されるべきでもない」と明記されている。**現時点ではモデルの訓練に使われておらず**、協議結果を反映した改訂版を年末に出して2027年以降の開発指針とする位置づけである。

### 2. GitHub が Copilot の auto model selection に3段階のティアを入れた — auto は「選べない代わりに制御もできない」ものではなくなる

**要点**: GitHub が auto model selection に Efficiency / Balance / Intelligence の3ティアを追加し、VS Code・Copilot CLI・Copilot アプリで展開を開始した。auto に任せるとコストも品質も制御できないという前提が、今日から設定項目に変わる。

**詳細**: 9/14 のリリースで、auto がモデルを選ぶ際のコスト・品質・応答時間の重みづけを利用者が指定できるようになった。Efficiency は低コストを優先し、速く単純なタスク向けとされる。Balance は3者を同時に勘案する日常業務向けで、Intelligence は品質を優先し複雑なタスク向けである。**3ティアはいずれも同じモデルプールから選ぶ**ため、Intelligence を選んでも単純な依頼には小さく速いモデルが当たりうる。auto はプロンプト単位で評価する仕組みで、ティアはその評価の重みを動かすだけである。課金は**ティアにかかわらず auto が実際に選んだモデル**の単価で行われ、有料プラン利用者に対する auto 経由10%割引は維持される。対象サーフェスは Visual Studio Code・Copilot CLI・GitHub Copilot アプリの3つで、9/14 時点で順次展開中と記載されている。⚠️ **既定のティアは changelog に明記されていない**ため、組織として既定値を前提にした試算は置かないほうがよい。

### 3. Anthropic が Claude for Financial Advisors を一般提供した — 金融業務の連携は自前実装から公式コネクタへ移る

**要点**: Anthropic が金融アドバイザー向けのコネクタ群とワークフロースキルを一般提供した。Claude を汎用アシスタントとして入れて連携を自作する前提が、主要な運用基盤との公式コネクタが揃う前提へ変わる。Enterprise プラン限定である。

**詳細**: 9/14 に GA として公開された。中核は業務システムへのコネクタ群と、8種類のワークフロースキルである。重要な判断には人間の承認を要求する設計で、自動化の対象は調査・準備・記録の側に置かれている。連携先として挙がっているのは次のとおり。

- カストディ・ポートフォリオ基盤: Addepar / BlackRock（Advisor Center）/ Charles Schwab / Envestnet（Tamarac・MoneyGuide）/ Orion / SS&C Black Diamond / Vanguard
- 専門領域ツール: iCapital（オルタナティブ投資）/ Wealth.com（相続・税務）/ Wealthbox（CRM）/ Zocks（AI 会議アシスタント）
- 汎用業務基盤: Salesforce / Microsoft 365 / DocuSign / Box / FactSet / S&P Global / Morningstar

スキルは面談前の情報集約、面談後の記録とフォローアップ、ポートフォリオのリバランス検討、相続・税務ブリーフ、オルタナティブ投資ブリーフ、コンプライアンスと AI ポリシーの点検、アドバイザーのオンボーディング、見込み客の受付の8種である。導入には **Enterprise プラン**が要る（監査ログを必要とする登録投資顧問向けの推奨）。Claude Cowork のプラグインブラウザからガイド付きで設定する形で提供される。⚠️ **2026年9月末までに新規ライセンスを申請した企業には一度限りの利用クレジット**が付く条件が示されており、検討するなら期限がある。Bloomberg は同日、BlackRock・Vanguard 等が運用する金融分析・リスク管理技術と Claude を組み合わせるものとして報じている。
