### 3. Claude Cowork がデスクトップアプリに専用ブラウザを内蔵した — ブラウザ操作の前提が「自分の Chrome を貸す」から「Claude 専用の別ブラウザ」へ移る

**要点**: Anthropic が Cowork に組み込みブラウザを載せた。拡張機能なしでサイドパネルにブラウザが開き、**自分のタブ・ブックマーク・パスワードは見えない別プロファイル**になるので、Claude in Chrome で必要だった「自分のセッションを貸す」判断が不要になる。⚠️ 公開は **8/26** で、本ダイジェストは9日遅れの初検出。

**詳細**: タスクがウェブサイトを必要とすると Cowork のサイドパネルにブラウザが開き、Claude がページを読み、クリックし、入力する。フォーム記入、ダッシュボードからの数値抽出、コネクタの無いポータルの操作が対象。**拡張機能もセットアップも不要**で、自分のブラウザからは明示的に選ばない限り何も共有されない。ログインはサイト単位でインポートでき、macOS では Chrome / Edge / Firefox から、Windows / Linux では Firefox から取り込める（銀行・メール・シングルサインオンのサイトは除外）。プロンプトインジェクション対策は Claude in Chrome と同じセーフガードを用いる。対象は Pro / Max / Team で macOS / Windows / Linux のデスクトップアプリに順次展開、**Enterprise は管理者が Organization settings → Cowork → Built-in browser で有効化**する。既に Claude in Chrome を使っている場合はそちらが既定のままで、設定 → Cowork → 優先ブラウザで切り替えられる。⚠️ **同日 8/26 公開の `claude-in-chrome-generally-available` は 08-27 のダイジェストに載っている**ため、これは B-024 の「同一日の2件目以降が落ちる形」が `claude.com/blog` で9日間放置された事例にあたる（B-060 起票の根拠）。
