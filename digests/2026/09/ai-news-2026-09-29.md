### 1. [新機能+仕様] Anthropic が 9/28 に Claude Sonnet 5.5 を公開した — Sonnet 5 と同じ料金で速くなったが、Sonnet 5 前提のリクエストの一部は 400 になる

**要点**: Anthropic が `claude-sonnet-5-5` を $2 / $10 のまま公開した。Terminal-Bench 4.0 は Opus 5.5 を上回る。ただし `thinking: disabled` と強制ツール使用は 400 になるので、モデル ID の差し替えだけでは移行できない。

**詳細**:

- 仕様: 1M context ／ 最大出力 128K（Batch はベータヘッダで 300K）／ $2・$10 per MTok ／ キャッシュ読み $0.20 ／ 知識カットオフ 2026年6月 ／ 退役は 2027-09-28 より前には行わない
- 提供先: Claude API ／ Bedrock ／ Google Cloud ／ Microsoft Foundry ／ Claude Platform on AWS。GitHub Copilot も同日 GA した（下記）
- 公式の比較（Sonnet 5.5 / Sonnet 5 / Opus 5.5）:
  - Terminal-Bench 4.0: **70.6%** / 10.3% / 66.4%
  - OSWorld 2.1: 80.1% / 57.0% / 81.8%
  - FrontierCode 1.1: 46.2% / 42.4% / 54.4%
  - 出力速度は Sonnet 5 比30%超速く、1タスクあたりのコストは最大30%安いとしている
- Sonnet 5 から移行すると壊れる点（5件）:
  - thinking を切るには `"disabled"` ではなく `{"type":"between_tools"}` を送る（`disabled` は 400）
  - `tool_choice` の `any` / `tool`（強制ツール使用）は 400。`auto` と `strict: true` へ移す
  - thinking block は生成したモデルと会話に紐づく。2026-08-31 以降に作成したアカウントでは、履歴を編集して block を再送すると既定で 400
  - Claude API と Google Cloud では `computer_20251124` を受け付けず、`computer_toolset_20260801` が必要（Bedrock は旧ツールも可）
  - advisor tool で Opus 4.8 / Opus 4.7 / Sonnet 5 を advisor に指定すると 400
- エラーにならない変化: ツール呼び出しの間の文章が thinking block で返り、既定の `display: "omitted"` では空になる。`temperature` / `top_p` / `top_k` を既定以外にすると 400。最小キャッシュ長は 512 トークン（Sonnet 5 は 1,024）
- 既定 effort は Claude アプリが medium、API が high。高リスクのサイバー系タスクは Sonnet 5 へフォールバックする
- モデル退役ページの Active は14件から **15件** になった。Haiku 5.5 はまだ無い

### 2. [破壊的変更+新機能] Claude Code 2.1.284 は、権限モード未設定の対話セッションを全プラン・全プロバイダで auto mode で起動する — 「設定しなければ毎回確認される」という前提が無くなった

**要点**: Anthropic が 9/28 の `2.1.284` で、`permissions.defaultMode` を書いていないターミナルと VS Code のセッションの既定を auto mode にした。確認を前提にしていた組織は、managed settings に `defaultMode` を明示しない限り auto で動く。

**詳細**:

- これまでは第三者プロバイダかテレメトリ無効の対話セッションに限っていた auto 既定を、全プラン・全プロバイダに広げた。`permissions.defaultMode` を設定していればそちらが優先される
- 同じ版の他の変更:
  - Sonnet 5.5 を追加し、Anthropic API の既定 Sonnet にした
  - Ultracode を `/effort` の独立トグルにした（Tab または `/effort ultracode on|off`。xhigh を強制しない）
  - auto mode の作業ディレクトリ外読み取り確認に「Yes, but ask again next time」を追加した
  - Claude apps gateway の spend limit を `/usage` と status line にドル額で出す（`rate_limits.spend_limit`）
- セキュリティ関連の修正:
  - `allowManagedPermissionRulesOnly` の下では、プラグインの `allowed-tools` による事前承認を公式か managed 設定が認めたソースに限った
  - 外部から symlink した `.claude/rules` のルールにも外部 import の承認を求めるようにした
  - auto-memory 読み込み時に `MEMORY.md` 内の不可視文字や markup を装ったタグを無害化した
  - `ANTHROPIC_FOUNDRY_RESOURCE` をリソース名以外は拒否するようにした
- npm は `{stable: 2.1.277, latest: 2.1.284, next: 2.1.284}`。**stable は 2.1.274 から 2.1.277 に進んだが、auto 既定化も Sonnet 5.5 も stable 固定の組織にはまだ届いていない**

- https://code.claude.com/docs/en/changelog
