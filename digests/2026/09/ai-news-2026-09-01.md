### 1. インフォスティーラーが Claude のログインセッションを乗っ取った — 2FA を通過した後の状態が丸ごと複製される

**要点**: 盗まれたのはパスワードではなくセッション Cookie で、攻撃者は 2FA を一度も突破せずに有料枠を消費した。Claude アカウントの防御前提が「2FA があれば足りる」から「端末が汚染された時点で認証済み状態ごと持ち去られる」へ変わった。

**詳細**: Anthropic は 2026-08-30 に対象ユーザーへの連絡を開始し、3つの対応を実施している。

- 影響を受けたセッションを強制サインアウトし、盗まれた Cookie を無効化した
- 保存済みの支払い方法を削除し、追加の不正課金を止めた
- 不正と判定した課金を返金した

確認されたマルウェアは Windows 側が Vidar・LummaC2・StealC・RedLine・Acreed、Mac 側が Atomic Stealer（AMOS）で、Mac の被害は少数とされる。Anthropic は Claude 本体・インフラの侵害ではなく利用者端末の感染であると明言している。使っていないのに週次枠が減る挙動が兆候にあたる。影響ユーザー数は公表されていない。⚠️ **一次未読**: `www.anthropic.com` はゲートウェイ拒否が継続し、`support.claude.com` の Release Notes は 8/25 の memory 更新が最上位のままで本件の記載がない。日付・対応内容・マルウェア名は BleepingComputer / SecurityWeek / Help Net Security / Security Affairs の二次一致で採った。
