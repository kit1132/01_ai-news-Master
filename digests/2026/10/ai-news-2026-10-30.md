### 1. [料金] OpenAI が ChatGPT Pro / Business の契約者に、API 組織をつなぐと毎月最大 $500 の API クレジットを付け始めた — 「ChatGPT の席と API の従量は別々に払う」前提が、席の契約に API の月次枠が付く前提に変わる

**要点**: OpenAI が 10/28 に、ChatGPT Pro と Business の対象者が自分の API 組織をリンクすると、毎月最大 $500 の無料 API クレジットを受け取れるようにした。Business は有料席の数に応じてワークスペースでプールされる。枠は月ごとに失効し、繰り越せない。

**詳細**:

- 付与額（月額・上限 $500）
  - Pro: プランのティアに応じて $100 / $200 / $500
  - Business: Standard 席1つにつき $20、Premium 席1つにつき $100 をワークスペースでプール
- 条件: 初回は課金期間の残りで按分し、毎月の付与は課金サイクルの終了で失効する。ChatGPT のアカウントが API 組織の所有者である必要がある（フォーラムの公式回答以外の補足を含む）
- 手順: `chatgpt.com/settings/billing` で請求し、ChatGPT または Codex の「OpenAI Developers」プラグインで API キーを作る
- API changelog の 10/28 の項にも同じ内容が載った。Anthropic は 10/7 に Max / Team へ月次 API クレジットを付けており、席に API 枠を付ける形が2社に揃った

- https://community.openai.com/t/claim-up-to-500-in-api-credits-using-your-chatgpt-pro-or-business-subscription
- https://developers.openai.com/api/docs/changelog

### 2. [新機能+仕様] Anthropic が Usage and Cost Analytics API を beta で出し、従来の Usage and Cost API と Enterprise Analytics API の利用・コスト系4エンドポイントを legacy にした — 「コストの集計は API キーとワークスペース単位」前提が、リクエストの背後のユーザーやサービスアカウント単位で引ける前提に変わる

**要点**: Anthropic が 10/29 に、Claude Console と Claude Enterprise の組織のトークン利用量とコストを返す Usage and Cost Analytics API を beta で出した。モデル・ワークスペース・API キー・利用者で絞り込みと集計ができる。旧 API は legacy になったが、引き続きサポートされ、退役日は示されていない。

**詳細**:

- 新 API: beta ヘッダー `analytics-usage-cost-2026-08-24`、エンドポイントは `/v1/organizations/analytics/usage` と `/v1/organizations/analytics/cost`

- 同じ release notes の 10/28 の項で、第一者の Claude API の Messages API と Token Counting API のリクエスト上限が **32MB から 128MB** に上がった
- release notes の RSS は 160 item（前回 158）。増えたのは 10/28 と 10/29 の2項で、既存の日付への追記は無かった
