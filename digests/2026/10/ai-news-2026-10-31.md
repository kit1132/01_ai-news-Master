## 今日のハイライト

### 1. [破壊的変更+新機能] Claude Code `2.1.314` で `FORCE_HYPERLINK=false` の意味が反転し、作業ディレクトリ外への書き込みを全モードで拒否する設定が加わった — 「書き込み先の制限は permission mode と deny ルールで組む」前提が、1キーで全モード共通に固定できる前提に変わる

**要点**: Anthropic が 10/30 に Claude Code `2.1.314` を出した。`permissions.blockWritesOutsideWorkingDirectories` を入れると、Write / Edit / NotebookEdit が作業ディレクトリ外のパスを permission mode に関係なく拒否する。`FORCE_HYPERLINK=false` はこれまでと逆にハイパーリンクを無効にする。

**詳細**:

- 権限・管理設定
  - `permissions.blockWritesOutsideWorkingDirectories`: 作業ディレクトリ外への Write / Edit / NotebookEdit を全モードで拒否する
  - Claude apps gateway: upstream に `groups`（IdP グループで振り分け。フェイルオーバー時も適用）、Bedrock upstream に `guardrail_trace`（発火した guardrail フィルタを本文なしで記録）が加わった
  - 管理者がモデルの effort に上限を掛けた組織で "Invalid effort level" が毎ターン出る不具合を直し、effort を下げて再試行するようにした
  - リモート管理設定だけに置いた `forceRemoteSettingsRefresh` が、保存コピーの期限切れ後に効かず、ポリシー無しで起動できた不具合を直した
- 挙動の変更
  - `FORCE_HYPERLINK=false`（`no` / `off` も）がハイパーリンクを有効ではなく無効にする
  - `claude -p` は起動失敗時に終了コード0・無出力で終わっていたが、エラーを出して1で終わる
  - VS Code と Claude Desktop の Code タブで、20万トークン超の会話を放置すると要約し、プロンプトキャッシュ切れの次メッセージで要約を使う（idle compaction）
- npm は `{stable: 2.1.308, latest: 2.1.314, next: 2.1.314}`。`2.1.313` は publish されていない

- https://code.claude.com/docs/en/changelog
- https://registry.npmjs.org/@anthropic-ai/claude-code

### 2. [破壊的変更+新機能] Orca `v1.4.245` でプラグインが既定で有効になり、Mac の computer use が既定でバックグラウンド実行になった — 「Orca はエージェントを並べる器でコードは走らせない」前提が、承認したプラグインにマシンの全権を渡す前提に変わる

**要点**: Stably AI が 10/30 に Orca `v1.4.245` を出した。プラグインが既定で有効になり、インストール時にレビュー画面が開き、コードを実行するプラグインは同意を求める。承認したプラグインはコンピューター全体にアクセスできる。

**詳細**:

- エージェント連携
  - Codex: macOS / Linux で Codex の貼り付け推定を切り、スマホなど別クライアントから送ったプロンプトが送信されるようにした。Orca 管理アカウントの履歴を `~/.codex` に見せる設定（既定オン）を追加した
  - Claude: プランを承認するとプランモードを抜ける
  - Mac の computer use: 既定でバックグラウンド操作。従来の前面操作は `--restore-window` で求める
- 既定の変更: 新しいターミナルは新しいホストで動く。同時実行ターミナル数の上限は各マシンのシステム上限に合わせる。チャット名は既定でエージェントとアカウントで付く
- ⚠️ `v1.4.244` へ戻すと Source Control の AI 操作のモデル・effort 設定が消え、再更新でも戻らない

- https://github.com/stablyai/orca/releases
