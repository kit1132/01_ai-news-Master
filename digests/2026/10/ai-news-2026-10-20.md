### 2. [破壊的変更+セキュリティ] GitHub が Copilot CLI `v1.0.100` で、サンドボックスからのローカルネットワーク接続を既定で許可した — サンドボックス内のコマンドが localhost や社内ネットワークに届く前提に変わった

**要点**: GitHub が 10/19 に Copilot CLI の安定版 `v1.0.100` を出した。サンドボックスから localhost とプライベートネットワークへの接続が既定で許可になり、セマンティックコード検索も既定オンになった。サンドボックスで社内サービスから切り離していたつもりの環境では、前提が変わる。

**詳細**:

- 既定の変更
  - サンドボックス: ローカルネットワーク接続を既定で許可。`/sandbox` を現在のセッションだけで有効にもできる
  - セマンティックコード検索: オンラインのセッションで既定オン
  - セッション: `/sessions`・`/session`・`/resume` が統合 Sessions ブラウザに変わった
  - プラグイン: 組み込みの browser プラグインが `browser-use` に改名（設定は引き継がれる）。信頼済みリポジトリのプラグインはチャット前に自動でインストール・更新される
  - 権限: Skill の `allowed-tools` で曖昧なスコープなしルールは、自動許可ではなく確認を求めるようになった
- 追加: `--disable-client-telemetry`（テレメトリ送信の停止）、`-p` とパイプ入力向けの `--trust-folder`、`.github/instructions` のパス別指示の自動適用、管理設定がモデル選択を上書きしたときの通知
- 削除されたフラグはリリース本文に書かれていない。安定版は `v1.0.98`（10/14）以来5日ぶりで、その間の pre-release 6版の変更がまとまっている

- https://github.com/github/copilot-cli/releases
