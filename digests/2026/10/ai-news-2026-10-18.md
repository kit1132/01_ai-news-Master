## 今日のハイライト

### 1. [破壊的変更+新機能] Anthropic が Claude Code `2.1.302` で fork サブエージェントを `claude -p` / Agent SDK / デスクトップ / VS Code の既定にした — ターミナル以外でもサブエージェントが既定で fork・バックグラウンド実行になる

**要点**: Anthropic が 10/16 公開の `2.1.302` を npm の `latest` に上げた。これまでターミナルだけだった fork サブエージェントとバックグラウンド実行が、非対話実行・SDK・IDE でも既定になる。サードパーティプロバイダーの権限モード既定も変わり、自動実行スクリプトの挙動前提が変わる。

**詳細**:

- 既定の変更
  - fork サブエージェント: `claude -p`・Agent SDK・デスクトップ・VS Code で既定オン。`CLAUDE_CODE_FORK_SUBAGENT=0` で無効化できる（`claude mcp serve` では提供しない）
  - サブエージェントの実行: デスクトップと VS Code はメイン会話のサブエージェントを常にバックグラウンドで走らせる（Claude が選ばない）
  - 権限モード: サードパーティプロバイダー上の `claude -p` / Agent SDK で権限モード未指定なら `default` で始まる（テレメトリ無効時や新規インストール時）。`--permission-mode auto` は従来どおり
  - prompt / agent フック: 同じイベントの同時実行を12件までに制限した
- 追加: `CLAUDE_CODE_AUTO_MODE_MODEL`（クライアント側 auto mode 分類器のモデル指定）、`/config` の Idle compaction 切替、`/design-sync` に claude.ai/design の 12/14 閉鎖の告知
- 修正: MCP 仕様 2026-07-28 を名乗るサーバーが `resultType` / `ttlMs` / `cacheScope` を省くとツールが0件になる問題、128MB 超の画像を Read が丸ごと読み込む問題、クレジット課金モデルでプロンプト候補がクレジットを消費する問題
- npm は `{stable: 2.1.292, latest: 2.1.302, next: 2.1.302}`

- https://code.claude.com/docs/en/changelog
- https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md

### 2. [新機能] Cursor が cloud agent に Environments API（ベータ）と300リポジトリ対応を入れた — クラウド実行環境を API で作り、大規模モノレポ群をまとめて扱える

**要点**: Cursor が 10/16 に、cloud agent が動くクラウド環境をプログラムから作成・管理する Environments API をベータ公開した。1環境あたり最大300リポジトリを扱え、大きな環境の読み込みは5倍速くなった。手作業だった環境準備をコードで管理できるようになる。

**詳細**:

- Canvases: cloud agent が作業の一部としてインタラクティブなキャンバスを作り、リンクでチームに共有できる
- Environments API: cloud agent の実行環境を API で作成・管理する（ベータ）
- 規模: 環境あたり最大300リポジトリ、大規模環境の読み込みが5倍速
- フォーラム Announcements は 10/12 の The X Subscription が最上位のままで、新モデルの提供告知は無い

- https://cursor.com/changelog/cloud-agent-canvases-and-environments

### 3. [破壊的変更+新機能] Stably AI が Orca `v1.4.229` で Hermes の自動化サポートを外した — 共有スキルを20エージェントへ広げ、SSH ホストの CLI 制御は明示許可制になった

**要点**: Stably AI が 10/17 に Orca `v1.4.229` を Latest にした。Hermes を使う自動化は動かなくなり、既存 SSH ホストではエージェントからのワークスペース操作やブラウザ制御に設定のオンが要る。

**詳細**:

- 破壊的変更
  - Hermes 自動化: サポートを削除した
  - SSH ホスト: 既存ホストは保存済みの CLI 制御設定を保つ。エージェントにワークスペース管理やデスクトップブラウザ制御を許すには Settings → SSH Hosts → Advanced Connection の「Allow this host's orca CLI to control Orca」をオンにする
- 共有スキル: さらに20エージェントへインストールできるようになり、`orca skills install` が SSH・ヘッドレスホストでも動く
- 実験的ネイティブチャット: ターンごとの編集をインラインでレビューでき、Claude の `/goal` と Codex のコンテキスト使用量を表示する
- 権限: 「Ask for approval」より広い権限を持つ古いホストではチャットを実行しない。権限要求の質問を自動回答しない
- `v1.4.228` は GitHub に出ていない（`v1.4.227` から `v1.4.229` へ飛んだ）

- https://github.com/stablyai/orca/releases/tag/v1.4.229
