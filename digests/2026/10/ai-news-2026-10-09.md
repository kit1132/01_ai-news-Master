### 1. [廃止+新機能] Anthropic が単体の Claude Design を 12/14 に閉じ、Docs / Slides / Design を Free を含む全プランで正式提供にした — 単体版のチャットとコメントは移行されない

**要点**: Anthropic が claude.ai/design の単体サイトを 12/14 で閉じると告知した（10/8）。Design は会話の中の機能に一本化され、単体版のチャット・プロジェクトへのコメント・公開リンクは閉鎖とともに失われるため、「別 URL で使い続けられる」前提が期限付きに変わった。

**詳細**:

- 単体版の閉鎖: 12/14 まで claude.ai/design で動く。デザインシステムは Artifacts ページの「Migrate team design systems」で組織分を一括移行でき、元データは閉鎖まで単体版に残る。プロジェクトは閉鎖まで単体版で動くが、チャットとコメントは移行対象外で、単体版プロジェクトの公開リンクも止まる
- 正式提供: Docs / Slides / Design のベータ表記を外し、Free を含む全プランで使えるようにした。Artifacts の CMEK 対応、管理者による Artifact テンプレートの選択、組織外やリンクを知る全員への共有（管理者が許可した場合）、PowerPoint / PDF 書き出しと Google Slides への直接出力、モバイルでの編集が入った。これまでの作成数は4,500万件超としている
- Claude Dashboards（有料プランでベータ）: BigQuery / Databricks / Snowflake / Redshift / ClickHouse や Salesforce などのコネクタに自然文で問い合わせ、データの変化に合わせて更新されるダッシュボードを作る。数値ごとに裏のクエリと最終更新時刻を表示し、Amplitude / Grafana / Hex / Mixpanel / Sigma などへ送れる
- Claude Motion（Team / Enterprise でベータ）: 文字・グラフ・図形・画像をコードでアニメーションにし、MP4 で書き出す。動画生成モデルは使わない

- https://claude.com/resources/articles/dashboards-and-motion

### 2. [仕様] Anthropic が Usage Policy を改定し、11/12 に発効させる — 物理的に動くハードウェアに Claude をつなぐ用途に停止手段と安全状態が必須になる

**要点**: Anthropic が2026年版の Usage Policy を公開した（10/8・発効 11/12）。大半は既存ルールの明文化だが、自律的に物理動作する機器への接続に「有資格の操作者が観察・停止できること」「切断時に安全状態を保てること」が加わり、ロボットや装置制御の用途は運用設計の要件が明示された。

**詳細**:

- 新設: 偽装・人工的な拡散を扱う「Do Not Engage in Deceptive Campaigns or Artificial Activity」節。選挙・詐欺・プライバシー・偽情報の各節に散っていた規定を統合し、政治・商用を問わず適用する
- 選挙節を「Do Not Undermine Democratic Processes」に改名し、個別化した投票・選挙運動ターゲティングの一律禁止を外した。欺瞞や個人データの悪用は他節で引き続き禁止される
- 武器: 誘導・制御ソフトウェアや部品、ドローンなど自律移動体の武装も禁止対象と明記した
- 監視・法執行: 同意のない追跡、捜査・逮捕・起訴の対象の決定や推奨、監視ツールの構築・改良を禁止と明記した。同意済みの追跡（不正監視）・コンテンツモデレーション・報道・法務調査は許可される
- 高リスク用途: 健康・法的権利・金融などに影響する場合の「有資格者による human in the loop」と「AI 利用の告知」の要件は変わらず、対象と対象外の一覧に書き直した
- モデルへの持続的で目的のない虐待的行為を禁止に加えた。執行は主に Claude が会話を終える機能による

- https://www.anthropic.com/news/2026-usage-policy-update

### 3. [新機能] OpenAI が ChatGPT の既定モデルを GPT-6 に切り替え、回答に図表やボタンを組み込む Intelligent UI を入れた — Free / Go にも GPT-6 Luna が届いた

**要点**: OpenAI が ChatGPT で GPT-6 と Intelligent UI の全世界展開を始めた（10/7）。Plus / Pro / Business / Enterprise は GPT-6 Sol、Free / Go は 10/8 から GPT-6 Luna になり、全プランの ChatGPT の基準モデルが GPT-5.6 世代から GPT-6 世代へ移った。

**詳細**:

- Intelligent UI: GPT-6 が質問に応じて文章・図表・ボタン・フォーム・対話型の要素を組み合わせて回答を組み立てる。ネイティブ部品のライブラリとコンパイラで、生成と同時に画面を段階表示する

- 展開: 10/7 に Plus / Pro / Business / Enterprise（GPT-6 Sol）、10/8 に Free / Go（GPT-6 Luna）
- API の `chat-latest` は 10/7 にこのモデルへ更新済み（前日掲載）
