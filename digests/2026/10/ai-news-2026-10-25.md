### 3. [新機能] GitHub が Copilot 使用量メトリクス API に、Claude Code・Codex・OpenCode など外部ツールからのモデル利用をツール別に返す `totals_by_client` を加えた — IDE テレメトリを送らないツールの利用も数えられる

**要点**: GitHub が 10/23 に、Copilot をモデル提供元として使う外部ツールのリクエスト・トークンをサーバー側で数え、ツール別に返すようにした。これまで `totals_by_ide` に出なかった利用が見えるので、どのツールに Copilot の枠が使われているかを組織が実数で把握できる。

**詳細**:

- 対象レポート: enterprise / organization / enterprise-user / organization-user の1日版と28日版。28日版は各 `day_totals` に入る
- 1件の中身
  - `client`: `opencode` / `claude_code` / `codex` / `zed` / `copilot_cli` / `github_app` / `cloud_agent` / `code_review` / `vscode` / `jetbrains`。未知のものは `other`
  - `request_count` / `session_count` / `token_usage`（入力・出力・1リクエスト平均）
  - `totals_by_model`: モデル別の内訳と `model_selection_mode`（`user_selected` / `auto` / `product_selected`）
- 閲覧権限: enterprise owner・billing manager・organization owner と、View Copilot Metrics 権限を持つカスタムロール。Copilot usage metrics ポリシーが有効であること
- 10/22 の「組織のスキル・エージェント・MCP サーバーを名前で返す」変更（10-24 既報）に続く拡張で、Claude / Codex のエージェントアプリが GitHub 上で起こしたジョブ数（agent app activity）とは別の指標である

## Claude 製品 / Anthropic

- [仕様] Anthropic が 10/23 に、Claude Duet の安全設計を公表した。承認しても実行しない操作と、「今後は確認しない」が効かない操作を明記している
  - 承認しても実行しない操作: 証券の売買、口座間の送金などの銀行操作、他人のアカウントへのアクセス
  - 毎回確認する操作: 支払い・送金、注文の削除、アカウント作成。承認後もモデルの外にある別のチェックが各操作を検証する
  - 機密情報の分類器: 認証情報・カード番号・政府発行 ID は頼まれても送らず、健康・財務の情報は明示の承認があるときだけ送る
  - 認証情報: パスワードはアプリ内のフォームで使い捨ての鍵で暗号化して渡し、サインイントークンは外部プロキシがリクエスト時にだけ差し込む。ブラウザは別の VM で動き、エージェントは Cookie を読めない
  - データ保持: 会話履歴とメモリは削除・リセットするまで残る。接続アプリを切っても、それまでに得た情報はメモリをリセットするまで残る。学習への利用と管理者設定には触れていない
  - 対象は従来どおり米国の Pro / Max（ウェイトリスト）
  - https://claude.com/resources/articles/claude-duet-safety-privacy-and-security
- [据え置き] `www.anthropic.com/news` は 10/22 の2本、`/research` は 10/23 の UK AISI 事案の分析が最上位のままで、`support.claude.com` のリリースノートも 10/21 の Claude Duet が最上位である
