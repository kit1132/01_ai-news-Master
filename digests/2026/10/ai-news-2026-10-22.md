## 今日のハイライト

### 1. [破壊的変更] Anthropic が Claude API の新バージョン `2026-10-21` と、それを既定で送る SDK のメジャー版を出した — SDK を上げるだけで `temperature` が 400 になり、API キーの送り方とライセンスも変わる

**要点**: Anthropic が 10/21 に API バージョン `2026-10-21` を公開し、Python 2.0.0・TypeScript 1.0.0 などの新 SDK がこれを既定で送るようにした。これまで `2023-06-01` 固定で SDK を上げても壊れなかったが、今後はメジャー版を上げるとリクエストの形と認証ヘッダーが変わる。

**詳細**:

- 新 SDK / CLI: Python 2.0.0、TypeScript 1.0.0、C# 13.0.0、Go 2.0.0（モジュールパスは `/v2`）、Java 3.0.0、PHP 1.0.0、Ruby 2.0.0、`ant` CLI 2.0.0。旧版は `anthropic-version: 2023-06-01` を送っていた
- Messages API の破壊的変更（`2026-10-21` 指定時）
  - `temperature` / `top_p` / `top_k`: 既定値を送っても 400。Sonnet 4.6 など他の値を受け付けるモデルで `temperature` を下げていた処理は、その効果を失う。続けたいリクエストは `2023-06-01` に残す
  - `assistant` メッセージ直下の `document` ブロックと、`user` メッセージの `text` ブロックに付けた `citations` は 400
- Admin API / Enterprise Analytics API: 改名済みフィールドの旧名を返さなくなる（`roles` → `role_ids`、`actor.email` → `actor.email_address` など）。API キーの `workspace_id` は消え、`scope` を読む
- SDK 側だけの変更: API キーを `X-Api-Key` ではなく `Authorization: Bearer` で送る。`X-Api-Key` を読むプロキシやゲートウェイは直す必要がある。Text Completions と tool runner のクライアント側 compaction も削除された
- ライセンス: 新版から MIT ではなく Apache 2.0（旧版は MIT のまま）
- Bedrock では `2026-10-21` は Claude 4.7 以降でしか使えない。旧モデルを Bedrock で呼ぶなら SDK を上げない
- `2023-06-01` の提供終了日は書かれていない

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/api/migration-2026-10-21
- https://platform.claude.com/docs/en/about-claude/model-deprecations

### 2. [破壊的変更+セキュリティ] Claude Code `2.1.305` で `allowedMcpServers` の絞り込みが緩み、許可リストに無い stdio サーバーが更新後に読み込まれるようになった — 許可リストだけで止めていた組織は `deniedMcpServers` が要る

**要点**: Anthropic が 10/20 の Claude Code `2.1.305` で、`managed-mcp.json` の stdio サーバーのうち `${VAR}` を `env` だけで使うものを `allowedMcpServers` で絞らないよう変えた。許可リストから外したつもりのサーバーが更新だけで動き出すので、止めるには拒否リストへの明記が必要になった。

**詳細**:

- 同じ版の管理設定まわりの変更
  - `allowManagedPermissionRulesOnly` を設定した組織では、Claude Desktop がパス指定でマウントしたプラグインの `allowed-tools` が効かなくなる
  - `sandbox.allowNestedUserNamespaces`: Linux のサンドボックス内で user namespace を作れるようにする（Chromium・rootless podman 向け）。changelog 自身が「サンドボックスのファイル保護を回避できる」と書いている
- `2.1.304` の不具合修正: Vertex・Bedrock などで、エンドポイントやゲートウェイがツール検索を拒否すると全リクエストが失敗していた。今はツール検索なしで再送する
- その他: 無人リトライ（`CLAUDE_CODE_RETRY_WATCHDOG`）がリセット前に解除された利用上限に気づく `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`、Code Review の再レビューが未解決の blocking 指摘を残したまま LGTM で始まらないようにする変更
- `2.1.306`（10/21 02:28Z）はクラウドセッションの `claude -p` が「Not logged in」になる不具合などの修正2件
- npm: `stable` は `2.1.304` のまま、`latest` / `next` は `2.1.306`

- https://code.claude.com/docs/en/changelog
- https://registry.npmjs.org/@anthropic-ai/claude-code
