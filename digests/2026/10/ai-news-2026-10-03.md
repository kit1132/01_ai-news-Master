### 2. [新機能] GitHub が Copilot CLI と Copilot app に computer use と dynamic workflows をパブリックプレビューで入れた — Copilot が API の無い GUI アプリを直接操作し、複数エージェントの段取りをコードで組めるようになった

**要点**: GitHub が 10/1 に、Copilot が macOS / Windows のデスクトップアプリを画面読み取りとクリック・入力で操作する computer use と、複数エージェントの並列実行をコードで組む dynamic workflows を出した。Copilot の作業範囲がリポジトリと端末の外へ広がり、組織の管理設定で止めるかどうかの判断が要る。

**詳細**:

- computer use（パブリックプレビュー）:
  - 有効化: CLI は `/computer on`、Copilot app は Settings > Computer Use
  - 操作前にユーザーの承認が要る。組織の管理設定で無効にできる
- dynamic workflows（パブリックプレビュー・全 Copilot プラン）:
  - 独立したタスクを並列に走らせ、段階間で構造化した結果を受け渡す
  - 有効化: app は設定不要。CLI は `--experimental` または `/experimental on`
- Copilot CLI は安定版 `v1.0.91` のままで、pre-release が `v1.0.92-2`（10/2）まで進んだ（カテゴリ別まとめ参照）

- https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps
- https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app
