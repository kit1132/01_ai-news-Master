### 2. [新機能] Anthropic が Claude Managed Agents で dynamic workflows をベータ提供した — エージェントが多数のサブエージェントを段階実行するプログラムを自分で書いてサーバー側で回す

**要点**: Anthropic が Managed Agents のエージェントに、ワークフロー（複数エージェントを段階的に走らせて結果をまとめるプログラム）を書かせ、サーバーがバックグラウンドで実行する dynamic workflows をベータで出した（10/9）。数百文書のレビューのような分割作業を、呼び出し側でオーケストレーションを組まずに任せられるようになった。

**詳細**:

- 有効化: `managed-agents-2026-04-01` ベータヘッダーのもと、エージェントの `multiagent` フィールドを `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}` にする
- 起動条件はシステムプロンプトで指示する。実行状況はセッションのイベントストリームの `workflow_run.*` イベントで追う
- GitHub が 10/1 に Copilot CLI / Copilot app へ入れた dynamic workflows（10/3 掲載）と同じ発想を、Anthropic はホスト型エージェント側に置いた

- https://platform.claude.com/docs/en/release-notes/overview

### 3. [料金+新機能] GitHub が Copilot code review の費用を組織負担に切り替えられる設定と、レビューを依頼できる人を絞る設定を出した — 既定のままだと依頼者の枠が尽きた時点でレビューが失敗する

**要点**: GitHub が Copilot code review に、Copilot ライセンスを持つメンバーのレビュー費用を誰が払うかを選ぶ組織設定と、組織が付与したライセンスの持ち主だけにレビュー依頼を限る設定を加えた（10/8）。既定は従来どおり依頼者の枠消費で、組織負担にするには AI Credits の従量課金を有効にする必要がある。

**詳細**:

- 「Choose how members with a Copilot license are billed」（組織設定 > Copilot > Policies）
  - Member（既定）: 依頼したメンバーの Copilot 枠を使う。枠が尽きるとレビューは失敗する
  - Organization: リポジトリを所有する組織に課金し、メンバーの枠を減らさない。AI Credits の従量課金の有効化が必須で、予算上限も設定できる
- 「Only allow Copilot code review to be triggered by authorized users」: オンにすると、組織またはエンタープライズが付与したライセンスの持ち主だけがレビューを依頼できる。外部の個人ライセンスは使えない。組織オーナーとリポジトリ管理者が設定でき、組織レベルでオンにするとリポジトリ管理者は外せない
- いずれも既定の挙動は変えない（オプトイン）

- https://github.blog/changelog/2026-10-08-copilot-code-review-new-organization-billing-options-and-controls
