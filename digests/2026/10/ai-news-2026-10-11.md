### 1. [廃止+破壊的変更] Google が Gemini API の `gemini-3.7-flash` と `gemini-3.5-flash` を deprecated にし、呼び出しを新モデルへ自動で振り替え始めた — モデル ID を固定していても、応答するモデルは既に変わっている

**要点**: Google が Gemini API changelog で、`gemini-3.7-flash` を `gemini-3.8-flash` へ、`gemini-3.5-flash` を `gemini-3.6-flash` へ自動ルーティングすると告知した（10/8）。旧 ID を指定し続けても失敗はしないが、評価済みのモデルとは違うモデルが応答する状態に変わった。

**詳細**:

- `gemini-3.7-flash`: deprecated。全リクエストを `gemini-3.8-flash` に自動で振り替える
- `gemini-3.5-flash`: deprecated。全リクエストを `gemini-3.6-flash` に自動で振り替える。移行先として `gemini-3.8-flash` も案内している
- 同じ 10/8 エントリの3項目目が、昨日掲載した Deep Research 旧版の 10/23 停止である。昨日はこの1項目しか拾えておらず、2モデルの廃止は本日はじめて確認した
- GitHub Copilot も 10/19 に Gemini 3.7 Flash をモデル選択から外す（3.8 Flash へ移行）

- https://ai.google.dev/gemini-api/docs/changelog

### 2. [新機能] Anthropic が Claude Code `2.1.296` を changelog に載せ、ワークフローの全エージェントを1つのモデルで動かす `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` などを加えた — managed settings で止めたはずのフックが、ターンを止めていなかった不具合も直った

**要点**: Anthropic が Claude Code `2.1.296` で、ワークフローのモデル指定、サブエージェント単位の自動圧縮、Claude Desktop の Code タブへのゲートウェイ方針の適用を加えた。managed settings の `PreToolUse` フックが `"continue": false` で拒否しても、ツール呼び出しを止めるだけでターンを終えていなかった不具合も直した。npm は `{stable: 2.1.287, latest: 2.1.296, next: 2.1.296}`。

**詳細**:

- `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`: ワークフローの全エージェントを1つのモデルで動かす。ほかのサブエージェントは各自のモデルのまま
- `autoCompactWindow`: サブエージェントの frontmatter と `--agents` 定義に追加。メイン会話より早く自動圧縮できる
- Claude apps gateway の `managed.policies[]` に `code` キー: `cli` と同じ設定を Claude Desktop の Code タブにも掛ける
- `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`: 529（過負荷）時のリトライの最大待機を延ばす
- 修正: `BASH_ARGV0` に代入してから使う一部のコマンドを Bash の権限チェックが自動承認していた不具合を直し、承認を求めるようにした。UTF-8 でないファイル（Shift-JIS など）を Edit が編集すると非 ASCII 文字が全部置き換わっていた不具合も直し、こうした編集は拒否するようにした

- https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
