### 2. [新機能] Anthropic が Claude Code `2.1.288` を changelog に載せ、npm の `latest` に上げた — 応答途中の API タイムアウトでターンが落ちなくなった

**要点**: Anthropic が 10/2 に `next` へ出していた `2.1.288` の変更内容を changelog に載せ、`latest` に昇格させた。非対話セッションとサブエージェントは応答途中のタイムアウトで止まらず部分応答から続行するので、長時間の無人実行が途中で失敗する前提が変わる。

**詳細**:

- 追加:
  - Ctrl+C で消したプロンプトを、空のプロンプトで ↑ を押すと貼り付けた文字・画像ごと戻せる
  - MCP サーバーがツール呼び出し中に追加の OAuth スコープを求めたとき、再認証を促す
  - `/code-review` に `--max-findings <n>|all` を追加した（`default` を渡すまで次回以降も引き継ぐ）
  - `gh` の無いクラウドセッションに組み込みの `gh api` を入れた
  - 構造化出力を拒むゲートウェイ向けに `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` を追加した
- 修正: 応答途中の API タイムアウト（部分応答から続行・thinking のみの応答は再試行）、最後の応答がトークン使用量 0 を返したときに自動 compact せず「Prompt is too long」で落ちる問題、`--resume` で直前の compact が戻したファイルが落ちる問題
- Bash の権限判定で、算術評価される `BASHPID` 代入を黙って通していたのを確認対象にした
- dist-tags は `{stable: 2.1.285, latest: 2.1.288, next: 2.1.288}`
