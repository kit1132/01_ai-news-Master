## 今日のハイライト

### 1. [破壊的変更+新機能] Anthropic が Claude Code 2.1.287 で Mods を入れ、Bedrock / Vertex / Foundry で Opus 4.7 以降と Fable を 1M コンテキスト既定にした — プラグインが本体の挙動そのものを書き換えられるようになり、クラウド経由の既定コンテキストが 200K から 1M に変わった

**要点**: Anthropic が Claude Code `2.1.287`（10/1 publish）で、TypeScript 関数で本体の挙動を変える Mods を出した。同じ版で Bedrock・Vertex AI・Foundry・Claude apps gateway の Opus 4.7 以降と Fable が `[1m]` 指定なしで 1M コンテキストになった。200K 前提で組んだ社内設定は見直しが要る。

**詳細**:

- Mods（10/1 ブログ）:
  - できること: プロンプトの書き換え、ツール呼び出しのブロック・書き換え・再試行、権限リクエストの承認・拒否、ツール出力の秘密情報の伏字化、UI の追加・置き換え
  - 実行環境: サンドボックスなしで、Claude Code と同じマシン権限で動く。Team / Enterprise では組み込みの `sec-default` が最初に読み込まれ、危険な操作を制限する。配布はプラグイン経由で、管理者は管理コンソールか managed settings でマーケットプレイスを制御する
  - 組み込み: `/diff` が Mod になり、無効化や差し替えができる。サイドエージェントが見落としを指摘する `You should know` も同梱（`/plugin enable cc-plugin-you-should-know@builtin`）
- 既定の変更（`2.1.287`）:
  - 1M コンテキスト: `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で 200K に戻せる
  - MCP: 2025-11-25 プロトコルのサーバーからの URL プロンプト（サインイン等）に対応した。更新後に接続できなくなったサーバーは、MCP 設定に `"bareElicitationCapability": true` を足す
  - `alwaysLoad: false` の MCP サーバーは全ツールが tool search の後ろに回る
  - リポジトリにコミットされた symlink 経由で機密ファイルや作業ツリー外へ書くシェル操作は、書き込み先を示して人の承認を待つ
- 前日未読だった `2.1.286`（9/30 publish）の主な変更: API リクエストの再試行上限が1回のモデル呼び出し単位になり、既定設定で最大14リクエストになった。`--bare` はコマンドラインで指定した MCP サーバーだけに接続する。Claude apps gateway の支出メーターが 1 時間キャッシュ書き込みを 5 分料金で数えていた不具合を直した
- npm の dist-tags は `{stable: 2.1.285, latest: 2.1.287, next: 2.1.287}`。`stable` が `2.1.280` から前進した

### 2. [新機能] GitHub が Copilot CLI の安定版を v1.0.90 → v1.0.91 と2版進め、解析しきれる読み取り専用パイプラインを明示承認なしの審査に回すようにした — シェル承認の対象が「コマンド単位」から「解析できるかどうか」へ変わった

**要点**: GitHub が Copilot CLI `v1.0.90`（9/30）で GPT-6.1 Sol を安定版に入れ、`v1.0.91`（10/1）で読み取り専用と解析しきれるシェルパイプラインを実行証拠の審査に回すようにした。解析できないパイプラインは従来どおり明示承認が要る。

**詳細**:

- `v1.0.90`（9/30 21:38 UTC）:
  - モデル選択に GPT-6.1 Sol
  - `--mcp-github-auth`: MCP サーバーの接続元ごとに GitHub 認証を絞る
  - パスアクセスの承認で、セッション内に限った読み取り専用ディレクトリ許可を選べる
- `v1.0.91`（10/1 17:25 UTC）:
  - `copilot sandbox ca`: プロキシ CA の確認・作成・信頼・ローテーション・削除。Windows の無人セットアップに対応し、`/sandbox ca install` は `create` と `trust` に改名した
  - Windows で Node / npm のソケットが EACCES で拒否されたときに、サンドボックスのネットワークを迂回する設定を加えた
  - 終了時に未送信のテレメトリを送り切ってから終わる
