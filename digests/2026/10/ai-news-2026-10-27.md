### 1. [料金+新機能] OpenAI が GPT-6.1 Terra を API・ChatGPT Work・Codex に出した — GPT-5.6 Terra より API 単価が半分で、computer use つきの中位モデルの試算を引き直すことになる

**要点**: OpenAI が 10/26 に `gpt-6.1-terra` を API と ChatGPT Work / Codex に出した。API の Standard 単価は入力 $1 / 出力 $5（100万トークンあたり）で、OpenAI は GPT-5.6 Terra 比で50%安いとしている。Copilot から GPT-5.6 Terra が外れる 11/16 の前に、中位モデルの乗り換え先が決まった。

**詳細**:

- API（モデルページ・料金ページで確認）
  - Standard: 入力 $1.00 / キャッシュ入力 $0.05 / 出力 $5.00。キャッシュ書き込みは 30分保持 $1.25、12時間保持 $2.50
  - Batch / Flex は Standard の50%（$0.50 / $2.50）、Fast は2倍（$2.00 / $10.00）。272K トークンを超えるプロンプトはリクエスト全体が入力2倍・出力1.5倍、地域内処理は10%増し
  - コンテキスト 1,050,000（最大入力 922,000）、最大出力 128,000、知識カットオフ 2026-06-01。`reasoning.effort` は `none`〜`max`。ツール呼び出しは Responses API のみ
  - 対応ツール: `computer_use` / `mcp` / `hosted_shell` / `apply_patch` / `skills` / `web_search` ほか。ファインチューニングは非対応
  - 並び: `gpt-6-astra` $10 / $50、`gpt-6.1-sol` $2 / $10、`gpt-6.1-terra` $1 / $5、`gpt-6-luna` $0.10 / $0.50
- ChatGPT / Codex: Plus / Pro / Business / Enterprise / Edu の ChatGPT Work と Codex で選べる（Chat タブには出ない）。デスクトップアプリと Web の ChatGPT Work では「Advanced」のモデル一覧から選び、Work はモバイルでも使える。UAE の推論レジデンシーは非対応で、Enterprise はワークスペースの提供状況と管理者設定による
- OpenAI の主張: Agents' Last Exam で GPT-5.6 Terra を大きく上回り、GPT-6 Astra と同等の成績を1トークンあたり10分の1の価格で出し、Astra / GPT-6.1 Sol より平均3倍以上速く終える。ChatGPT Work / Codex の利用枠も GPT-5.6 Terra より長く持つ

### 2. [破壊的変更] Google が Gemini API の Generate Content API で、有料ティアの新規プロジェクトのリクエスト保存を既定オンにした — 新しく作るプロジェクトでは、何もしないとリクエストがログとして残る

**要点**: Google が 10/26 に、有料ティアで新しく作るプロジェクトの `generateContent` / `streamGenerateContent` / `batchGenerateContent` を既定で `store=true` にした。既存プロジェクトは今の設定のままだが、新規プロジェクトはオプトアウトしない限り保存される前提に変わった。

**詳細**:

- 対象: 有料ティアの新規プロジェクトの Generate Content API 3種。Interactions API の既定に合わせた
- 既存プロジェクト: 現在の設定を維持する
- オプトアウト: リクエストごとに `store=false` を付けるか、AI Studio の Logs and Datasets ダッシュボードの Settings で Generate Content API のログを切る

- https://ai.google.dev/gemini-api/docs/changelog
- https://ai.google.dev/gemini-api/docs/logs-datasets#configure-logging
