**詳細**:

### 3. [新機能] GitHub が Copilot のローカルサンドボックスを GA にした — CLI / Copilot アプリ / VS Code のエージェント実行を OS レベルで縛れる

**要点**: GitHub が、Copilot が手元で実行するツールやコマンドのファイル・ネットワーク・認証情報へのアクセスをポリシーで制限する機能を一般提供にした（10/7）。追加料金なしで、管理側が強制した設定は開発者が緩められないので、エージェントの自律実行を許す前提が「信頼するか」から「境界内で動かすか」に変わった。

- 制御できるもの: 読み書きできるディレクトリ、インターネットとローカルネットワーク、Git と GitHub CLI の認証情報。対応していればローカル MCP と言語サーバーにも掛かる
- Copilot CLI 安定版 `v1.0.93`（10/7）で `/sandbox` と `--sandbox` が全ユーザーに開放された
