### 2. [新機能] Anthropic が Claude Code の Code Review を GA にした — research preview の PR レビューが、Team / Enterprise の管理者が有効化する正式機能になった

**要点**: Anthropic が 10/15 に、GitHub の PR を複数エージェントでレビューしてインライン指摘を付ける Code Review を research preview から外し、Team / Enterprise で GA にした。多くのレビューが約3倍速くなり、リポジトリごとに深さを選べる。

**詳細**:

- 速度: 多くのレビューが約20分から6〜10分に短縮された
- レビューの深さ: Quick / Standard（既定）/ Deep を組織既定とリポジトリ単位で選ぶ。深いほど高コスト
- 導入: 管理者が Claude Code 設定で有効化し、GitHub App を入れて対象リポジトリを選ぶ。開発者側の設定は不要で、新しい PR に自動で走る
- クレジット: 対象の Enterprise 組織は 2027-01-15 までに $10,000 以上の Code Review クレジットを請求でき、請求から30日で失効する
- 使えない構成: Zero Data Retention・HIPAA 構成・CMEK の組織。モデルの選択肢は無い

- https://claude.com/resources/articles/code-review-is-now-generally-available
- https://code.claude.com/docs/en/code-review
