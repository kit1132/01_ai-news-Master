## 今日のハイライト

### 1. [料金+新機能] GitHub が code scanning アラートの agentic autofix を GA にした — 修正案の生成だった Autofix が、Copilot が検証まで回して draft PR を出す有料の作業に変わった

**要点**: GitHub が 10/15 に、code scanning のアラートを Copilot に割り当てると、Copilot が修正を書き、CodeQL を再実行して解消を確かめてから draft PR を出す機能を GA にした。有効にすると無料の「Generate Fix」ボタンが「Assign to Copilot」に置き換わり、AI Credits と Actions 分数を消費する。

**詳細**:

- 対象: GitHub Enterprise Cloud（データレジデンシー版を含む）の GitHub Code Security / GitHub Advanced Security 利用者
- 使い方
  - 単体: 既定ブランチで見つかったアラートを1件ずつ割り当てる。PR や他ブランチだけで見つかったアラートは割り当てられない
  - 一括: セキュリティアラート一覧かセキュリティキャンペーンから最大25件を選び、1本の PR にまとめて直させる
  - REST API: Update a Code Scanning Alert で `assignees` に `["copilot-swe-agent[bot]"]` を指定する
- 課金: Code Security 予算の AI Credits と GitHub Actions 分数を消費する。enterprise の請求画面「AI usage」の「Advanced Security」に計上され、SKU 単位の予算を設定できる。単価の記載は無い
- 有効化の3段: enterprise 管理者が Advanced Security ポリシーの「Agentic autofix」を有効化 → org / リポジトリ管理者が Code Security 設定で有効化 → Copilot の請求方法を設定

- https://github.blog/changelog/2026-10-15-agentic-autofix-for-code-scanning-alerts-general-availability

### 2. [新機能] GitHub が HydraFusion の使うモデルと手順を変え、難しい作業向けの HydraFusion Max を追加した — モデルを選ばずに任せる枠に、Claude Opus 5.5 と GPT-6 系の4モデルが入った

**要点**: GitHub が 10/14 に、複数モデルを組み合わせて1つの回答を返す research preview の HydraFusion を更新し、推論の深さを上げた Max を加えた。VS Code・Copilot アプリ・Copilot CLI で、Pro / Pro+ / Business / Enterprise の preview 機能を有効にした利用者が使える。

**詳細**:

- モデル: Claude Opus 5.5 / GPT-6 Astra / GPT-6.1 Sol / GPT-6 Luna から、ワークフローに応じて選ぶ。組織のモデルポリシーに従う
- 推論の深さ: 各モデルの既定ではなく段階ごとに決める（下書きは medium、レビューは high）
- Cascade: 最初の結果を判定する段を挟み、必要なときだけ修正を依頼する
- Critique: テキストの要約より、ワークスペースを実際に調べるツールに頼るようにし、批評役のモデルを並列に走らせる
- Max: 同じ構成で、念入りさが要る箇所の推論を深くする。通常版はトークンを抑える側に寄せる
- premium request の倍率・料金の記載は無い

- https://github.blog/changelog/2026-10-14-hydrafusion-updates-and-new-max-option
