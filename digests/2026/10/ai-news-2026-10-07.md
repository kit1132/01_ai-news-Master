### 1. [新機能] Claude が Google ドキュメント / スプレッドシート / スライドの中で直接編集できるようになった — 有料全プランで 10/6 から公開ベータ

**要点**: Anthropic が Claude for Google Workspace アドオンと、Docs / Sheets / Slides のコネクタを公開ベータで出した（10/6）。Pro / Max / Team / Enterprise が対象で、Google ファイルは「Claude に貼って読ませるもの」から「Claude がその場で書き換えるもの」に変わった。

**詳細**:

- アドオン: ファイル横のサイドバーで Claude を開き、選択範囲を読んで直接編集するか、承認カードとして修正案を出す
- コネクタ: Claude のチャットからリンクを渡すか新規作成を頼むと、Google ファイルを作成・編集する
- できること: Docs は文の修正・見出しの書式・提案カード、Sheets は数式・ピボット・Python でのデータ整形、Slides はデッキのテーマに合わせたスライド作成と要素の重なり検出
- 編集の承認: 既定は「Ask before edits」（都度承認）。「Accept all edits」で自動適用に切り替えられる
- 管理: Team / Enterprise はオーナーがコネクタを有効にする必要がある。Enterprise は Compliance API・顧客管理の暗号鍵・OpenTelemetry の監査エクスポートに対応する

- https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides

### 2. [セキュリティ+新機能] Anthropic が Cyber Verification Program を3段階に作り直し、Project Glasswing を統合した — 防御用途なら審査数日で一般モデルの攻撃系ブロックが外れる

**要点**: Anthropic が、一般提供モデルでは大半が遮断されるサイバー作業を、審査済みの組織に段階的に開放する CVP の拡張版を出した（10/6）。Mythos は Glasswing 参加組織だけのものから、Specialized Access 階層として申請で入れる枠に変わった。

**詳細**:

- Defense Access: SOC・インシデント対応・マルウェア解析・脆弱性の検証。企業や自治体の防御チーム、OSS メンテナー、脆弱性報告の実績がある個人も対象で、審査は数日
- Red Team Access: 許可された対象へのペネトレーションテストとレッドチーミングを追加する。組織限定で審査は数週間（審査中は Defense Access に入る）。ランサムウェア展開など物理被害・大規模混乱につながる操作は引き続き遮断される
- Specialized Access: 航空・電力網・通信・銀行間送金などの安全系を試験する組織向け。米国政府と共同で審査する。Glasswing の既存参加組織はここへ移り、現行モデルは再審査不要
- 対象モデル: Opus 5.5 / Sonnet 5.5 / Mythos 5.1 と今後のモデル
- データ保持: 参加には悪用監視のためのデータ保持が必須。今秋提供予定の Enterprise Frontier Safeguards（EFS）までは、ZDR で Fable 5.1 / Mythos 5.1 を使う組織に限り ZDR のまま CVP を使える
- 評価: CyScenarioBench（10課題×5回）で、CVP なしは全件が初回プロンプトで遮断、Defense Access は50件中46件が途中で遮断、Red Team Access は遮断0件で34件成功（安全装置なしの 67.6% と同等）
- Glasswing の成果として、参加組織が 4〜7月に検証済み脆弱性を少なくとも129,000件見つけ、うち33,000件超が critical / high とした
- 同日、Claude ブログに Comcast と Booz Allen が Mythos でエクスプロイトチェーンを探す事例が出た

- https://www.anthropic.com/news/cyber-verification-program
- https://claude.com/resources/articles/how-comcast-booz-allen-use-claude-mythos-to-secure-their-codebases

### 3. [料金] OpenAI が API の利用ティアを5段階から3段階に減らし、最上位 Grow の条件を累計 $1,000 から $500 に下げた — 既存の有料組織は自動で新ティアへ移る

**要点**: OpenAI が API の有料ティアを Build / Launch / Grow の3つに統合した（10/6）。累計 $500 の支払いで月 $200,000 枠の最上位に入れるので、レート制限の引き上げ待ちが前提だった小規模組織の試算が変わる。

- Free は対象地域の利用者で月 $100 まで
- 有料ティアの組織は自動で移行し、操作は不要。モデル別の RPM / TPM は Astra / Sol / Terra / Luna ごとに異なる
- 前日 10/5 には、API の組織設定から BAA に同意して HIPAA 対応を有効にできる画面内フローも追加された
