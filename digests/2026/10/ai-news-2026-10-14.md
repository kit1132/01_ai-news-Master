### 3. [セキュリティ+料金] Anthropic が蒸留攻撃への対策を公表し、安全策で応答前に止めたリクエストも 9/24 から課金していると明かした — 誤検知でも課金される前提に変わった

**要点**: Anthropic が 10/12 に蒸留（他社モデルを作るための出力抜き取り）対策をまとめた。Sonnet 5.5 以上に2段の分類器を入れ、8/31 以降に作った API アカウントでは Fable 5.1 / Opus 5.5 の過去コンテキストを編集できない。対象分野で応答前にブロックされたリクエストも 9/24 から課金しており、誤検知率は0.1%未満とされる。

**詳細**:

- 対策の内訳
  - 分類器: Sonnet 5.5、Opus 5 / 5.5、Fable 5 / 5.1 で稼働する。9月の報告にあった手口と、推論の翻訳やタグ書き出しといった新しい回避手口も検知する
  - 推論の可視性: Sonnet 5.5 の推論トランスクリプトは、リクエストを出した組織だけが読める
  - Preserved thinking: 8/31 以降に作成された API アカウントは、Fable 5.1 / Opus 5.5 の過去コンテキストを編集できない。この推論は安全策の弱い旧モデルにも読ませない。Anthropic は一部の開発者に統合の更新が必要になると書いている
  - アカウント措置: 抜き取りを繰り返すアカウントは利用上限を絞り、停止もする。数万アカウントを停止し、多くはキャンペーン開始から2時間以内に止めたとしている
- 効果: 蒸留側が得るデータは約90〜99%減り、抜き取られた推論トークンは10〜100倍以上減った。完全な推論で学習したモデルは SWE-bench Verified 80.4%、要約で学習したモデルは 71.8% だった
- 利用規約の変更は書かれていない

  - 内容クラス: `prompts` / `responses` / `toolArguments` / `toolOutput` / `policyDetail` を個別に有効化できる。いずれも既定は無効
  - 対象は Copilot CLI、Copilot app、Agent Host を使う VS Code。管理設定の値はローカル設定や環境変数より優先される
  - https://github.blog/changelog/2026-10-12-client-telemetry-user-attribution-and-configurable-capture

  - Autopilot は preToolUse フックの「ask」を権限ダイアログで止まらず拒否として扱う
