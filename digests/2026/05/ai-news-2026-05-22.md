## Anthropic / Claude

### Anthropic、Stainless を $300M+ で買収（5/19-20 公表）※新規・要監視
- **対象**: Stainless（Alex Rattray、2022 創業）。Anthropic を含む各社の **公式 SDK・CLI・MCP サーバを自動生成**してきたインフラスタートアップ
- **戦略狙い**: MCP 普及（Salesforce / Zoom 等が実装）に伴い、SDK/MCP の生成パイプラインを**競合（OpenAI / Google / Cloudflare / Replicate / Runway）から取り上げる**動き。The Register / Tekedia は「使うためでなく敵に使わせないための買収」と評価
- **9/1 で Stainless プラットフォーム閉鎖**: OpenAI（Python/Node/Java/Go/Ruby 各クライアントが Stainless 生成）は代替ツール構築を迫られる。**既存生成 SDK の所有権・改修権は顧客に残る**と Anthropic が明言
- 影響: Anthropic 公式 SDK の更新サイクル高速化・MCP コネクタ自動生成が期待される一方、競合 API クライアントの長期サポート不透明化
- ソース: [Anthropic 公式](https://www.anthropic.com/news/anthropic-acquires-stainless), [InfoWorld](https://www.infoworld.com/article/4172947/anthropic-acquires-stainless-to-strengthen-claudes-developer-tooling.html), [The Register](https://www.theregister.com/ai-ml/2026/05/20/anthropics-stainless-steal-tightens-grip-on-ai-dev-tooling/5243053), [The AI Insider](https://theaiinsider.tech/2026/05/19/anthropic-acquires-sdk-startup-stainless-for-over-300m-cutting-off-key-tool-used-by-openai-and-google/)

### Claude Code v2.1.146（5/21）※新規
- **`/simplify` → `/code-review` リネーム**: effort level 引数対応（例: `/code-review high`）。コードレビュー用途の slash command として位置付け直し
- **Auto mode の挙動修正**: ユーザーまたは skill が `AskUserQuestion` を明示的に要求した場合は Auto mode でも抑制せず、確認プロンプトを表示
- **Windows PowerShell ツール修正**: winget / Microsoft Store 経由で `pwsh` をインストールした環境で「command line is invalid」エラーが出る問題を修正
- **MCP pagination 修正**: `resources/list` / `resources/templates/list` / `prompts/list` で 2 ページ目以降のアイテムが欠落する問題を修正
- その他: Windows Terminal でのフルスクリーン strobing、auto-updater のステータスライン表示、Windows worktree が NTFS junction を辿って main repo に侵入する問題、`/background` が skill/custom slash command のみの入力を拒否する問題、バックグラウンドセッションで権限が再プロンプトされる問題、`forceLoginOrgUUID`/`forceLoginMethod` の managed-settings policy 未強制、GNOME Terminal の右クリック/ミドルクリック paste、`CLAUDE_CODE_SUBAGENT_MODEL` の子プロセス伝播、大規模 diff レンダリング性能、auto-updater のネットワーク失敗時 retry — など多数修正
- ソース: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## OpenAI / ChatGPT

### ChatGPT Ads Manager — US セルフサーブ全面開放（5/21）※新規
- **CPC ビディング追加**: 既存の CPM モデルに加え、コストパーフォーマンス志向の広告主向けに cost-per-click を提供
- **計測強化**: measurement pixel + Conversions API を同時ローンチ。第三者計測対応も予告
- **最低出稿額の撤廃**: 当初 $200K だった最低スポンサーシップを段階的にゼロへ。SMB/スタートアップにも開放
- **業界エージェンシー統合**: Dentsu / Omnicom / Publicis / WPP / Adobe / Criteo / StackAdapt と連携。広告売上目標は 2026 年 $2.5B、2030 年 $100B
- ソース: [OpenAI](https://openai.com/index/new-ways-to-buy-chatgpt-ads/), [Digiday](https://digiday.com/marketing/openai-opens-up-chatgpt-ads-manager-to-the-u-s-while-promising-third-party-measurement-cpa-bidding/), [Search Engine Journal](https://www.searchenginejournal.com/openai-launches-self-serve-ads-manager-for-chatgpt/573971/), [PPC Land](https://ppc.land/openai-opens-chatgpt-ads-manager-to-all-us-businesses-with-cpc-bidding/)

## 開発ツール

### Cursor 3.5 — Automations 大幅拡張（5/20）※新規
- **Agents Window 内に Automations を統合**: 従来は `cursor.com/automations` のみで管理だったが、エージェントと同じワークスペースから作成・運用可能に
- **マルチリポ Automations**: 1 つの automation に複数リポを attach 可能。エージェントが複数リポにまたがるコンテキストを扱う / 横断的にタスクを deliver / test / verify
- **リポなし Automations**: リポ未指定でも automation を作成可能。Marketplace に 5 つの no-repo テンプレート追加（例: 未読 DM とキー Slack channel を要約する Slack digest agent）
- **プロモ価格**: 新規作成 automation のエージェント実行を **7 日間 50% オフ**
- ソース: [Cursor Changelog 5/20](https://cursor.com/changelog/05-20-26), Releasebot
