## Anthropic / Claude（最重要）

- **Claude Opus 4.8 リリース（5/28）** ※新規（前回 4.7 から 41 日）
  - **コーディング**: SWE-Bench Pro **69.2%**（Opus 4.7 64.3% / GPT-5.5 58.6%。+10.6pt リード）
  - **コンピュータ操作**: OSWorld-Verified **83.4%**（GPT-5.5 78.7%）
  - **Super-Agent**: 全ケース end-to-end 完走したのは Opus 4.8 のみ。GPT-5.5 と同コストで上回る
  - **「honesty」改善**: 進捗の不確実性を申告するようになり、根拠の薄い主張をしにくくなった
  - **価格据置**: $5/M 入力、$25/M 出力（Opus 4.7 と同じ）
  - **Fast Mode 3× 値下げ**: $10/M 入力、$50/M 出力（旧 Fast Mode 比）
  - 「agentic coding / 多分野推論 / agentic computer use / 知識労働 / agentic 財務分析」全方位で改善
  - 同日新機能: **Dynamic Workflow**（複数サブエージェントの並列実行）、Effort コントロールパネル
  - 提供範囲: 本日より全環境（Claude.ai / API / Bedrock / Vertex / Foundry）
- **Mythos クラスを「数週間以内」に一般展開予定** — Opus 4.8 で先行投入したセーフガードを Mythos 用に磨き込んでから順次解放（Project Glasswing で得た知見ベース）。「現時点でいかなる企業も Mythos の悪用を防ぐ十分なセーフガードを持たない」と明言

## Claude Code（Opus 4.8 連動の大型 2 連発）

- **v2.1.154（5/28）** ※新規
  - **Opus 4.8 既定で `/effort xhigh`**（難しいタスクに高 effort を割り当て）
  - **Dynamic Workflows**: 「数十〜数百エージェントを背景でオーケストレーションするワークフローを作って」と頼める。`/workflows` で一覧
  - **Fast Mode 価格**: Opus 4.8 fast mode は **標準の 2× 価格で 2.5× の速度**（旧コストから値下げ）
  - **Lean system prompt をデフォルト化**（Haiku / Sonnet / Opus 4.7 以前を除く）
  - 選択肢プロンプトは「本当に分岐が必要な時」だけに抑制
  - `/simplify` は cleanup-only（reuse / simplification / efficiency / altitude）に整理し fix まで適用
  - **`/effort` のラベル**: 「Speed / Intelligence」→「Faster / Smarter」
  - `claude agents`: 入力欄で **`! <command>`** とすると background session としてシェル実行 → attach/detach 可。`/logout` はサインアウトに変更（旧: background 化）
  - `←←`（agents view）が **Bedrock / Vertex / Foundry / テレメトリ無効環境でも動作**
  - **Chrome**: `/chrome → "Select browser…"` で接続済みブラウザを選択
  - **Plugins**: `defaultEnabled: false` 宣言可。`/plugin` の Discover に「カレントディレクトリ向け」のサジェストピン
  - Streaming tool execution が常時 ON（Bedrock/Vertex/Foundry/テレメトリ無効でも）
  - stdio MCP に `CLAUDE_CODE_SESSION_ID` / `CLAUDECODE=1` 環境変数
  - `claude mcp list/get` は未承認 `.mcp.json` を **「⏸ Pending approval」表示**（自動接続しない）
  - `/claude-api` skill を **Opus 4.8 対応 + マイグレーション手順に更新**
  - **セキュリティ**: auto-mode 分類器がデータ持出（特にレポジトリ一括転送）検知強化。`HOME` 末尾スラッシュでも `rm -rf $HOME` がブロックされなかった脆弱性 fix
  - 廃止予告: `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE`（6/1 削除予定）
  - バグ修正: 1M コンテキストで background-agent 完了通知が「out of context」誤発火 / 背景 session が `[blocked]`/`[running]` で停留 / subagents が worktree-isolation を素通り / 孤立した `claude --bg-pty-host` プロセスが macOS で 100% CPU / VS Code でターミナル描画破損 / `--bg` プラン名に `[Image #N]` プレースホルダ混入 / API 400（effort 未対応モデル + `CLAUDE_CODE_ALWAYS_ENABLE_EFFORT`）/ Windows update 失敗時の表示改善 / auto mode が `bypass-permissions` を要求してしまう など
- **v2.1.153（5/28）** ※新規
  - github/git プラグインマーケットプレース: **`skipLfs` で LFS スキップ**可能
  - **ステータスラインコマンドに `COLUMNS` / `LINES` 環境変数**（端末幅対応の出力に）
  - `claude agents` の dispatch 入力で **ネイティブスラッシュコマンド + バンドルスキルを autocomplete**
  - `claude agents` PR 列: 1 件なら `PR #N`、複数なら `N PRs`
  - **`claude doctor` に直近 update 結果**を表示
  - MCP / コネクタの認証要求通知を **1 メッセージに統合**
  - macOS: background agents が「Claude Code」として Privacy & Security に出現、アップグレード越しに権限永続化
  - 重要バグ修正: stateful MCP の `tools/list` 再接続ループ、**カスタム API ゲートウェイがユーザの Anthropic OAuth トークンを受け取ってしまう問題**、subagent frontmatter の MCP が `--strict-mcp-config` 等を無視、Windows PowerShell インストーラが失敗を成功扱い、`claude update` が configured release channel を無視、トランスクリプトパス resume 時の数 GB メモリ膨張、stream-json でセッションマーカ残留、`file://` リンクが non-clickable、Windows IME/CJK / tmux / 256色 / Remote Control ゾンビ / VS Code shutdown 各種、`/model` 選択を新セッションのデフォルト保存（`s` でカレントセッションのみ切替）
