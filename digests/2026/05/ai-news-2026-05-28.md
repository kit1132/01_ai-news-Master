## Claude Code（今日の新規・最重要）

- **v2.1.152（5/27）** ※新規（前回把握は v2.1.150 / 5/23、2連続停滞から復帰）
  - **`/code-review --fix`**: レビュー指摘をワーキングツリーに直接適用。`/simplify` は `/code-review --fix` を呼ぶ形に統合
  - **スキル/スラッシュコマンドの `disallowed-tools`**: frontmatter で有効中にツールを剥奪可能
  - **`/reload-skills`**: 再起動なしでスキルディレクトリを再スキャン。`SessionStart` フックが `reloadSkills: true` を返すと同一セッション内で再スキャン、`hookSpecificOutput.sessionTitle` でセッションタイトル設定も可能
  - **`MessageDisplay` フック新設**: アシスタントメッセージの表示テキストを変換/非表示にできる
  - **Auto モードの opt-in 同意が不要に**（デフォルト有効化方向）
  - **`--fallback-model` 自動切替**: プライマリモデルが利用不可のとき設定済みフォールバックへ自動切替
  - 管理者向け `pluginSuggestionMarketplaces`（組織マーケットプレースの allowlist）、`/usage` が大型セッションファイルもストリーミング読込で内訳表示、Vim NORMAL モードの `/` で逆方向履歴検索（Ctrl+R 相当）、OTEL `app.entrypoint` 属性（`OTEL_METRICS_INCLUDE_ENTRYPOINT=true`）
  - バグ修正多数: egress proxy 有効な Remote セッションでのリモート MCP 失敗、`cache_creation_input_tokens` が 0 報告される問題、model/login 切替後にセッションが stale thinking-block signature でスタックする問題 など
- ソース: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)
