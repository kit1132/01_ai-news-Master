## OpenAI / Codex

### Codex Appshots & Goal Mode GA（5/21-22）※新規
- **Appshots（macOS）**: 両 Command キーを同時押しで、フォアグラウンドアプリのウィンドウを **スクリーンショット + 取得可能テキスト** として Codex セッションに即座に添付。長い説明・コピペ不要で「いま見ているもの」を Codex に渡せる
- **Goal Mode が GA**: Codex アプリ / IDE 拡張 / CLI 全てで一般提供化。**目標と成功基準を定義すると、Codex が数時間〜数日にわたって達成まで動き続ける**。途中で確認・操舵・一時停止可能
- ChatGPT Business 向けには **共有プラグイン**（ワークスペース全体で再利用）、新管理者向けアダプション分析も追加
- ソース: [9to5Mac](https://9to5mac.com/2026/05/21/codex-for-mac-updated-with-new-appshots-feature-that-instantly-gives-chat-context/), [Digit.in](https://www.digit.in/news/general/openai-upgrades-codex-with-appshots-goal-mode-and-more-developer-focused-tools.html), [Codex Changelog](https://developers.openai.com/codex/changelog), [OpenAI Devs (X)](https://x.com/CodexReleases/status/2057528216542154961)

### Codex が「ロック中の Mac」でも動作（5/22）※新規・要監視
- **Computer Use プラグイン経由で、Mac の画面がオフ・ロック中でも Codex が macOS アプリを操作可能**。スマホから Codex にタスク投入 → 自宅/オフィスの Mac で実行という非同期ワークフローが現実化
- セキュリティ: タスク中のみ Mac を一時的にアンロック、ローカル物理アクセスはブロック継続。キーボード/マウス入力検知時は即時ロック復帰＋リモートアクセス一時停止
- 必要権限: Screen Recording + Accessibility 許可
- **制限**: Terminal アプリ・Codex 自身・システム管理プロンプトは自動操作不可。**EEA/UK/スイス では利用不可**（規制対応）
- ソース: [MacRumors](https://www.macrumors.com/2026/05/22/codex-use-mac-apps-when-locked/), [Macworld](https://www.macworld.com/article/3147024/openai-codex-can-now-run-with-locked-macbooks.html), [Digital Trends](https://www.digitaltrends.com/computing/you-can-now-send-codex-tasks-from-your-phone-even-when-your-mac-is-locked/), [OpenAI Devs (X)](https://x.com/OpenAIDevs/status/2057536706778378692)

### OpenAI、SEC に IPO 用 S-1 を機密提出（5/22）※新規・要監視
- **5/22 に SEC に confidential S-1 提出**。引受は Goldman Sachs、Morgan Stanley、JPMorgan Chase
- **想定上場時期**: Q4 2026（Labor Day〜Thanksgiving 期間）。**想定評価額は最大 $1T**（直近私募評価額 $852B）

- 背景: Musk 元共同創業者との法的紛争で OpenAI 側が勝訴したことで IPO 障害が除去された
- ソース: [Fortune](https://fortune.com/2026/05/22/openai-ipo-filing-1-trillion-may-finally-answer-these-big-questions/), [CNBC](https://www.cnbc.com/2026/05/20/openai-ipo-filing.html), [Crypto Briefing](https://cryptobriefing.com/openai-confidential-ipo-filing-goldman-sachs/), [AI Weekly](https://aiweekly.co/alerts/openai-files-confidential-ipo-with-goldman-morgan-stanley)

## 業界動向

- **OpenAI の IPO 機密提出 + Anthropic の SpaceX 月額 $15B 開示**: AI フロンティア企業が **「年間 $10B+ コンピュート支出が当然」** のフェーズに突入。資本市場（IPO）と物理インフラ（GPU/データセンター）の同時調達がボトルネック化
