## Anthropic / Claude

### Code with Claude London — 16 new features 発表（5/19-20）※新規詳細
- 「Bring Your Own Compute」: Claude Managed Agents のコード実行先として **Cloudflare / Daytona / Modal / Vercel** を first-class サポート（従来は Anthropic 管理サンドボックスのみ）
- **Auto Mode / Background Sessions**: スケジュール時刻・GitHub webhook・外部 API からトリガーで Claude Code セッションを自動起動。リモートコンピュート上で人間の起動操作なしに実行
- **Work Tree Isolation**: 同一リポジトリで複数 Claude Code セッションを実行する際、各セッションが独自サブディレクトリにクローンされ、エージェント同士のファイル上書き衝突を回避
- **Auto Memory**: セッション中にコーディングスタイル・アーキテクチャ判断・プロジェクト固有パターンを自動メモし `memory.md` に保存。次回セッションで自動参照
- Claude Code レート上限倍増 / Opus API レート増（5/6 SF 既報の London 再強調）
- ソース: [Anthropic - 16 features](https://inaiwetrust.com/p/16-claude-features-that-change-how-you-build-ai), [What's new in Claude Code session](https://claude.com/code-with-claude/session/ldn-whats-new-in-claude-code), [Code with Claude London](https://claude.com/code-with-claude/london)

### Anthropic × KPMG グローバルアライアンス（5/19 公表）※新規

### Claude Code v2.1.144 / v2.1.145（5/19）※新規
- **v2.1.145**: `claude agents --json` でライブセッション一覧をスクリプト出力（tmux-resurrect / status bar / session picker 連携用）、`/plugin` Discover/Browse 画面が**インストール前にコマンド・エージェント・スキル・hook・MCP/LSP サーバを表示**、OTEL に `agent_id`/`parent_agent_id` 追加、Bash 環境変数代入経由の権限プロンプト**バイパス脆弱性を修正**、Read tool が token 上限超過時にハードエラーではなく "PARTIAL view" 通知付き先頭ページ返却

## Google / Gemini（I/O 2026 続報）

### Antigravity 2.0 詳報 — CLI / SDK / Managed Agents in Gemini API（5/19）
- **Antigravity CLI が Gemini CLI を完全置換**: 単一エージェント基盤に統合
- **Antigravity SDK**: Google 内部プロダクトを支えるのと同じエージェントハーネスにプログラマブルアクセス。Gemini モデル最適化、任意インフラでホスト可能
- **Managed Agents in Gemini API**: 単一 API 呼び出しで隔離 Linux 環境上に推論・ツール使用・コード実行可能なエージェントを起動。Gemini 3.5 Flash 上で動作、Interactions API / Google AI Studio から利用可
- **Antigravity 2.0 デスクトップアプリ**: 既存 Antigravity IDE と別の独立アプリ。並列エージェントオーケストレーションに特化
- ソース: [Google Blog - Managed Agents](https://blog.google/innovation-and-ai/technology/developers-tools/managed-agents-gemini-api/), [MarkTechPost](https://www.marktechpost.com/2026/05/19/google-launches-antigravity-2-0-at-i-o-2026-a-standalone-agent-first-platform-with-cli-sdk-managed-execution-and-enterprise-support/), [TechCrunch](https://techcrunch.com/2026/05/19/google-launches-antigravity-2-0-with-an-updated-desktop-app-and-cli-tool/)
