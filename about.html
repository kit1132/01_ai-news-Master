このサイトについて

ChatGPT や Copilot をはじめ、AI の新機能や発表は毎日のように出てきます。 このサイトは、それを毎朝自動で集めて日本語で短くまとめたものです。 追っているのは開発ツール・Microsoft・業界動向の3分野。 どの項目にも公式発表へのリンクが付くので、気になったものはその場で元の情報にあたれます。

5つのタブの読み分け

上部のタブは「まとめ」と「元ソース」の2群に分かれています。 1日1回だけ見るなら「今日のまとめ」だけで足ります。 特定の分野を深く追いたいときに元ソース側を開いてください。

タブ扱う範囲更新こんな時に見る
今日のまとめ 下の3ソースを1本に統合した当日分 毎朝 7:00 まず最初に開く場所
今週のまとめ 直近1週間の流れと帰結 毎週月曜 3:00 週明けの振り返り、数日空いたとき
開発ツール Claude / OpenAI / Google / Cursor などの AI 開発ツール（26 ソース） 毎朝 4:10 使っているツールの変更を追う
Microsoft M365 Copilot / Copilot Studio / Power Platform（24 ソース） 毎朝 6:10 Microsoft 案件の情報収集
業界 市場データ・調査・資金調達・規制の動向（18 ソース） 毎朝 5:10 提案資料の根拠を探す

左上の ☰（スマートフォン）または左側の一覧から、過去の日付にさかのぼれます。

1日の流れ

3つの元ソースが先に生成され、それをまとめたものが 7:00 に出ます。時刻はすべて日本時間です。

  • 4:10「開発ツール」を生成
  • 5:10「業界」を生成
  • 6:10「Microsoft」を生成
  • 7:003つを統合して「今日のまとめ」を生成
  • 月曜 3:00直近1週間分をまとめて「今週のまとめ」を生成

情報源

分野ごとに 18〜26 の情報源を毎朝巡回しています。中心になるのは次のような一次情報です。

  • 公式のリリースノート・変更履歴（Claude Code Changelog、Microsoft 365 Copilot Release Notes など）
  • 企業の公式ブログ・発表（Anthropic、OpenAI、Google、Microsoft など）
  • 調査機関・公的機関のレポート（総務省 情報通信白書、Similarweb、IDC、a16z など）
  • 技術メディア・開発者コミュニティ（一次情報が取得できない場合の補完として）

掲載する項目には必ず出典 URL を付けています。数値や仕様を引用するときは、 その URL から原文にあたれます。

どう作られているか

収集から記事の執筆までを Claude Code のスケジュールタスクが自動で行っています。 毎朝決まった時刻に各サイトを巡回し、前回からの差分を抽出して、日本語のダイジェストに書き起こし、 公開までを人手を介さずに済ませています。

読むときの注意

ダイジェストは自動生成です。 要約の過程で細部が落ちたり、解釈が入ったりすることがあります。

提案資料への引用や、意思決定の根拠に使う場合は、 各項目の出典 URL から原文を確認してください。 特に数値・料金・提供開始日は、原文が更新されている可能性があります。

情報源が一時的に取得できなかった日は、その分の項目が欠けることがあります。 「特筆事項なし」と書かれている場合は、実際に更新がなかったことを意味します。
