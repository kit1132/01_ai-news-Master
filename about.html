このサイトについて

AI の新機能や公式発表を、毎朝自動で集めて日本語で短くまとめたサイトです。 1日1回見るなら「今日のまとめ」だけで足ります。 どの項目にも出典へのリンクが付くので、気になったものはその場で原文にあたれます。

集めている情報

毎朝追っているのは、次の3分野です。今日のまとめは、この3つを1本にしています。

分野対象どんな更新
開発ツール Claude、ChatGPT、Gemini、GitHub Copilot、Cursor、Grok、Devin、MCP、オープンウェイト 公式のリリースノートと製品発表。新機能、仕様変更、提供開始
業務 Copilot Microsoft 365 Copilot、Copilot Studio、Power Platform、共有リンクや監査などの管理変更 Word / Excel / Teams の機能追加、ライセンス、テナントへの展開
市場・規制 Apple、資金調達、市場シェア、各国の規制、調査レポート 数字、発表日、調査の要点

5つのソースの読み分け

左の一覧は親子になっています。 「今日のまとめ」「今週のまとめ」の左の三角（▸）で枝だけ開閉できます（本文は変わりません）。名前を押すとそのまとめ本文へ進み、下に分野（開発ツール / 業務 Copilot / 市場・規制）がぶら下がります。 「カテゴリ別まとめ」はまず12の話題の目次です。話題を選ぶと、右は月、その中は週です。週を開くと、その週の更新が日付ごとに出ます。左の日付はその日へジャンプします。Cursor と xAI は同じ話題です。 今日のまとめ・今週のまとめ・カテゴリでは、右の先頭に短い一文の概要と、いま見ている日付（または週／話題名）が出ます。左の日付一覧では土＝青・日＝赤です。 1日1回だけ見るなら「今日のまとめ」だけで足ります。 開発ツール、業務 Copilot、市場・規制のどれかだけ深く追いたいときは、開いている日付（または週）の左で、その分野を開いてください。

左上の ☰（スマートフォン）または左側の一覧から、過去の日付にさかのぼれます。

画面の見方

初めて開いたときはホームです。読み始める場所は「今日のまとめ」です。 見出しを押すと節の開閉ができます。ページ内検索をするときは、右上の すべて開く を先に押してください（閉じている節は検索に出ません）。

  • 今日のハイライトは、各件が 要点（何が変わったか）と 詳細（根拠と数字）の2段です。 カテゴリ別の項目は箇条書きで、ハイライトより短くまとめています。
  • 項目の下に並ぶ小さなラベルは出典のドメインです。押すと公式ページへ飛びます。
  • 表示は左の一覧の下でライト / システム / ダークを切り替えられます。選択は次回も残ります。

今日のまとめは毎朝、今週のまとめは週のはじめに更新されます。

情報源

分野ごとに公式・調査・メディアなどの情報源を毎朝巡回しています。中心になるのは次のような一次情報です。

  • 公式のリリースノート・変更履歴（Claude Code Changelog、Cursor Changelog、Microsoft 365 Copilot Release Notes など）
  • 企業の公式ブログ・発表（Anthropic、OpenAI、Google、Microsoft、xAI など）
  • 調査機関・公的機関のレポート（総務省 情報通信白書、Similarweb、IDC、a16z など）
  • 技術メディア・開発者コミュニティ（一次情報が取得できない場合の補完として）

掲載する項目には必ず出典 URL を付けています。数値や仕様を引用するときは、 その URL から原文にあたれます。

読むときの注意

ダイジェストは自動生成です。 要約の過程で細部が落ちたり、解釈が入ったりすることがあります。

提案資料への引用や、意思決定の根拠に使う場合は、 各項目の出典から原文を確認してください。 「要点」は何が変わったかの要約で、数字・料金・提供開始日は「詳細」と原文側が正です。 特に数値は、原文が更新されている可能性があります。

情報源が一時的に取得できなかった日は、その分の項目が欠けることがあります。 「特筆事項なし」と書かれている場合は、実際に更新がなかったことを意味します。
